# 155. Min Stack
Problem : [HERE](https://leetcode.com/problems/min-stack/description/)

>[!TIP]
>LeetCode 第 155 題「Min Stack」是一道經典的設計資料結構的題目，目標是設計一個支援以下操作的堆疊（stack）：
>
>1. `push(x)`：將元素 x 推入堆疊。
>2. `pop()`：移除堆疊頂端的元素。
>3. `top()`：取得堆疊頂端的元素。
>4. `getMin()`：取得堆疊中的最小元素。
>
>### 🎯 解題思路
>
>為了讓 `getMin()` 操作在 **常數時間 O(1)** 完成，我們需要額外的資料結構來追蹤目前堆疊中的最小值。
>
>#### 方法一：使用兩個堆疊
>
>- **主堆疊（stack）**：儲存所有的元素。
>- **輔助堆疊（minStack）**：儲存每個狀態下的最小值。
>
>##### 操作邏輯：
>
>- `push(x)`：
>  - 將 x 推入主堆疊。
>  - 如果 minStack 為空或 x 小於等於 minStack 的頂端，則也推入 minStack。
>- `pop()`：
>  - 如果主堆疊頂端元素等於 minStack 頂端，則兩者都 pop。
>- `top()`：
>  - 回傳主堆疊頂端元素。
>- `getMin()`：
>  - 回傳 minStack 頂端元素。
>
>#### ✅ 範例程式碼（C++）
>
>```cpp
>class MinStack {
>private:
>    std::stack<int> stack;
>    std::stack<int> minStack;
>
>public:
>    MinStack() {
>        // 初始化時兩個堆疊都是空的
>    }
>
>    void push(int val) {
>        stack.push(val);
>        // 如果 minStack 為空或 val 小於等於目前最小值，則也推入 minStack
>        if (minStack.empty() || val <= minStack.top()) {
>            minStack.push(val);
>        }
>    }
>
>    void pop() {
>        if (stack.top() == minStack.top()) {
>            minStack.pop();
>        }
>        stack.pop();
>    }
>
>    int top() {
>        return stack.top();
>    }
>
>    int getMin() {
>        return minStack.top();
>    }
>};
>```
>
>### 🧠 時間與空間複雜度
>
>- **時間複雜度**：所有操作都是 O(1)
>- **空間複雜度**：O(n)，因為需要額外的 minStack 儲存最小值
>
>---


```CPP
class MinStack {
private: 
    stack<int> stk;
public:
    MinStack() {        
    }
    
    void push(int val) {
        stk.push(val);
    }
    
    void pop() {
        stk.pop();
    }
    
    int top() {
        return stk.top();
    }
    
    int getMin() {
        int ans = INT_MAX;
        stack<int>temp = stk;
        while(!temp.empty()){
            if(temp.top() < ans) ans = temp.top();
            temp.pop();
        }
        return ans;
    }
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */
```
