# 1769. Minimum Number of Operations to Move All Balls to Each Box
Problem : [HERE](https://leetcode.com/problems/minimum-number-of-operations-to-move-all-balls-to-each-box/description/)

>[!TIP]
>前後遍歷的核心原理是**累積操作次數的分解**，通過分兩次遍歷（一次從左到右，一次從右到左），我們可以在 O(n) 的時間內累計並計算每個位置的最小移動操作次數，而不需要針對每個位置重複計算所有球的距離。
>
>---
>
>### 詳細解釋
>
>#### **1. 從左到右的遍歷**
>我們從左到右進行累計操作次數。假設有變量：
>- `count`：到目前為止的球的總數（累積的 `'1'` 數量）。
>- `moves`：從左邊累計的總操作次數。
>
>遍歷過程中，我們可以做以下操作：
>1. **累計操作次數到當前位置：**
>   - 把 `moves`（從左側累積的操作次數）加到 `answer[i]` 中。
>2. **更新累積球數和操作次數：**
>   - 如果當前位置有球（`boxes[i] == '1'`），增加 `count`。
>   - 增加的總操作次數為 `moves += count`，因為所有左邊的球需要再向右多移動 1 步。
>
>這樣，我們能以線性方式累積左側的操作次數。
>
>---
>
>#### **2. 從右到左的遍歷**
>第二次遍歷從右到左，過程和左到右類似，但這次我們計算右側的操作次數：
>1. **累計操作次數到當前位置：**
>   - 把 `moves`（從右側累積的操作次數）加到 `answer[i]` 中。
>2. **更新累積球數和操作次數：**
>   - 如果當前位置有球（`boxes[i] == '1'`），增加 `count`。
>   - 增加的總操作次數為 `moves += count`，因為所有右邊的球需要再向左多移動 1 步。
>
>---
>
>#### **為什麼能加速？**
>這種方法的關鍵在於**避免重複計算**：
>- 暴力解法需要針對每個位置計算到所有其他位置的距離，導致時間複雜度為 \(O(n^2)\)。
>- 前後遍歷則是通過累積方式記錄左側和右側的操作次數，避免了內層循環，將時間複雜度降低到 \(O(n)\)。
>
>---
>
>### 運作範例
>
>#### 輸入：`boxes = "110"`
>1. 初始化變量：
>   ```python
>   answer = [0, 0, 0]
>   count = 0
>   moves = 0
>   ```
>
>#### 第一次遍歷（左到右）：
>- i = 0:
>  - `answer[0] += moves = 0`，結果為 `[0, 0, 0]`
>  - `count += 1`（因為 boxes[0] = '1'）
>  - `moves += count = 1`
>
>- i = 1:
>  - `answer[1] += moves = 1`，結果為 `[0, 1, 0]`
>  - `count += 1`（因為 boxes[1] = '1'）
>  - `moves += count = 3`
>
>- i = 2:
>  - `answer[2] += moves = 3`，結果為 `[0, 1, 3]`
>  - `count 不變`（因為 boxes[2] = '0'）
>  - `moves 不變`
>
>#### 第二次遍歷（右到左）：
>- i = 2:
>  - `answer[2] += moves = 3`，結果為 `[0, 1, 3]`
>  - `count 不變`（因為 boxes[2] = '0'）
>  - `moves 不變`
>
>- i = 1:
>  - `answer[1] += moves = 3`，結果為 `[0, 1, 3]`
>  - `count += 1`（因為 boxes[1] = '1'）
>  - `moves += count = 1`
>
>- i = 0:
>  - `answer[0] += moves = 1`，結果為 `[1, 1, 3]`
>  - `count += 1`（因為 boxes[0] = '1'）
>  - `moves += count = 3`
>
>#### 最終輸出：
>`answer = [1, 1, 3]`
>
>---
>

```CPP
class Solution {
public:
    vector<int> minOperations(string boxes) {
        int n = boxes.size();
        vector<int> left(n, 0), right(n, 0), res(n, 0);
        int count = (boxes.at(0) == '1' ? 1 : 0);

        for (int i = 1; i < n; i++) {
            left[i] = left[i - 1] + count;
            count += (boxes.at(i) == '1' ? 1 : 0);
        }

        count = (boxes.at(n-1) == '1' ? 1 : 0);

        for (int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1] + count;
            count += (boxes.at(i) == '1' ? 1 : 0);
        }

        for (int i = 0; i < n; i++) {
            res[i] = left[i] + right[i];
        }

        return res;
    }
};
```
