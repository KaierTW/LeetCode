# 1593. Split a String Into the Max Number of Unique Substrings
Problem : [HERE](https://leetcode.com/problems/split-a-string-into-the-max-number-of-unique-substrings/description/)

>[!TIP]
>### 思路
>這是一道回溯類型的問題，主要思想是要找到字串的所有可能分割方式並確保每個子字串都是唯一的。可以使用回溯（backtracking）的方法來解決，通過遞歸遍歷每一個可能的分割點，同時用一個集合來存儲已經分割出的子字串。如果當前子字串不在集合中，就將其加入集合，繼續嘗試下一步的分割。最終，當遍歷完字串時，返回已經分割出的子字串的數量。
>
>### 解法
>一個典型的回溯算法步驟：
>
>1. 初始化一個集合來存儲唯一的子字串。
>2. 遍歷字串，從當前索引處嘗試分割成不同長度的子字串。
>3. 如果該子字串不在集合中，將其加入集合並遞歸處理剩下的字串。
>4. 遞歸返回時，移除該子字串以恢復狀態，並嘗試其他可能性。
>5. 返回最大可能的分割數。
>
>你可以用回溯（backtracking）的方式來實現這道題。下面是一個C++的解法，詳細步驟包括檢查每次分割出的子字串是否是唯一的，並且遞歸地處理剩餘的字串。當遞歸遍歷到字串的結尾時，更新最大唯一子字串的數量。
>
>### 解法思路
>1. **初始化資料結構**：
>    - `unordered_set<string> seen` 用來記錄已經分割出的子字串，保證它們是唯一的。
>
>2. **回溯算法**：
>    - `backtrack` 函數是遞歸的核心，它從字串的某個起始位置開始嘗試分割，並確保每次分割出的子字串是唯一的。
>    - 每當處理完一個子字串時，繼續處理剩下的部分，並記錄當前最大分割數。
>    - 使用回溯的方式恢復到之前的狀態，嘗試其他可能性。
>
>3. **時間複雜度**：
>    - 由於回溯會遍歷所有可能的分割方式，時間複雜度是指數級的，具體為 \(O(2^n)\)，其中 \(n\) 是字串的長度。
>
>這個實現方式可以高效解決這類問題，並保證子字串的唯一性。
>






```CPP
class Solution {
public:
    int maxUniqueSplit(string s) {
        unordered_set<string> ans;
        return findString(0 , s , ans);
    }

    int findString(int start , const string& s , unordered_set<string> ans){
        // 當遍歷到字串的末尾，返回 0
        if(start == s.size()) return 0;

        int maxSpilt = 0;
        string currentString;

        for(int i = start ; i < s.size() ; i++){
            // 構建當前的子字串
            currentString += s[i];

            if (ans.find(currentString) == ans.end()) {
                ans.insert(currentString);  // 將該子字串加入集合
                maxSpilt = max(maxSpilt, 1 + findString(i + 1, s, ans));  // 遞歸處理剩下的字串並更新最大分割數
                ans.erase(currentString);  // 回溯，移除子字串
            }
        }
        return maxSpilt;
    }
};
```
