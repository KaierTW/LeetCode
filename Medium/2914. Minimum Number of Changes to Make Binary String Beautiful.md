# 2914. Minimum Number of Changes to Make Binary String Beautiful
Problem : [HERE](https://leetcode.com/problems/minimum-number-of-changes-to-make-binary-string-beautiful/description/)

>[!TIP]
>因為是要偶數長度的字串，所以兩個一組檢查，i就是直接+2跳

```CPP
class Solution {
public:
    int minChanges(string s) {
        int count = 0;
        for(int i = 0 ; i < s.size() - 1 ; i += 2){
            if(s[i] != s[i + 1]) count++;
        }
        return count;
    }
};
```
