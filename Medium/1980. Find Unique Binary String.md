# 1980. Find Unique Binary String
Problem : [HERE](https://leetcode.com/problems/find-unique-binary-string/description/)

>[!TIP]
>
>### 題目背景：
>題目要求我們找到一個長度為 `n` 的二進制字符串，這個字符串不在給定的 `nums` 陣列中出現。
>
>### 解題思路：
>1. **反對角線法**：
>    - 我們利用「反對角線法」來構建不在 `nums` 中的唯一二進制字符串。
>    - 方法很簡單：對於每個字符串 `nums[i]`，我們只檢查其第 `i` 個位置並將其反轉。也就是說，如果 `nums[i][i]` 是 `0`，我們就將其變為 `1`；如果是 `1`，則變為 `0`。
>
>2. **為什麼有效**：
>    - `nums` 是一個長度為 `n` 的二進制字符串陣列，因此每個字符串都有唯一的反對角線。
>    - 我們反轉這些反對角線上的位，這意味著我們生成的結果字符串 `result` 在每一個 `i` 位上都與 `nums` 中的每個字符串不同。
>    - 這保證了 `result` 與 `nums` 中的所有字符串都至少有一位不同，從而確保 `result` 不會出現在 `nums` 中。
>
>### 具體步驟：
>1. 初始化結果字符串 `result` 為空字符串。
>2. 遍歷 `nums` 陣列中的每個字符串，對每個 `i` 執行以下操作：
>   - 檢查 `nums[i][i]` 的值。
>   - 如果是 `0`，則在 `result` 中添加 `1`；如果是 `1`，則在 `result` 中添加 `0`。
>3. 返回生成的結果字符串 `result`。
>
>### 總結：
>這種方法利用了每個字符串的獨特反對角線來保證生成的字符串與所有給定的二進制字符串不同。這樣的設計非常高效，只需要一個 `for` 迴圈即可完成。
>


```CPP
class Solution {
public:
    string findDifferentBinaryString(vector<string>& nums) {
        string ans;
        for(int i = 0 ; i < nums.size() ; i++){
            ans.push_back((nums[i][i] == '0') ? '1' : '0');
        }
        return ans;
    }
};
```
