# 380. Insert Delete GetRandom O(1)
Problem : [HERE](https://leetcode.com/problems/insert-delete-getrandom-o1/)

>[!TIP]
>這道題目要求我們設計一個數據結構，支持以下操作，且每個操作的平均時間複雜度為 $$O(1)$$：
>1. **插入元素**：如果元素不在集合中，插入該元素並返回 `true`；否則返回 `false`。
>2. **刪除元素**：如果元素在集合中，刪除該元素並返回 `true`；否則返回 `false`。
>3. **隨機返回一個元素**：從集合中隨機返回一個元素，每個元素被返回的概率應該相同。
>
>### 解題思路
>為了實現這些操作，我們可以使用兩個數據結構：
>1. **動態數組（vector）**：用來存儲元素，支持 $$O(1)$$ 時間複雜度的隨機訪問。
>2. **哈希表（unordered_map）**：用來存儲元素及其在動態數組中的索引，支持 $$O(1)$$ 時間複雜度的插入和刪除操作。
>
>### 具體實現
>1. **插入操作**：
>   - 如果元素已經存在於哈希表中，返回 `false`。
>   - 否則，將元素添加到動態數組的末尾，並在哈希表中記錄該元素及其索引。
>
>2. **刪除操作**：
>   - 如果元素不在哈希表中，返回 `false`。
>   - 否則，將要刪除的元素與動態數組的最後一個元素交換，然後刪除最後一個元素。更新哈希表中最後一個元素的新索引，並刪除要刪除元素的哈希表記錄。
>
>3. **隨機返回元素**：
>   - 使用 `rand()` 函數生成一個隨機索引，並返回動態數組中對應的元素。
>
>### 代碼示例
>以下是使用 C++ 的代碼示例：
>
>```cpp
>#include <iostream>
>#include <vector>
>#include <unordered_map>
>#include <cstdlib> // for rand()
>
>class RandomizedSet {
>public:
>    RandomizedSet() {}
>
>    bool insert(int val) {
>        if (valToIndex.find(val) != valToIndex.end()) {
>            return false;
>        }
>        vals.push_back(val);
>        valToIndex[val] = vals.size() - 1;
>        return true;
>    }
>
>    bool remove(int val) {
>        if (valToIndex.find(val) == valToIndex.end()) {
>            return false;
>        }
>        int lastElement = vals.back();
>        int idx = valToIndex[val];
>        vals[idx] = lastElement;
>        valToIndex[lastElement] = idx;
>        vals.pop_back();
>        valToIndex.erase(val);
>        return true;
>    }
>
>    int getRandom() {
>        int randomIndex = rand() % vals.size();
>        return vals[randomIndex];
>    }
>
>private:
>    std::vector<int> vals;
>    std::unordered_map<int, int> valToIndex;
>};
>
>int main() {
>    RandomizedSet randomizedSet;
>    randomizedSet.insert(1);
>    randomizedSet.insert(2);
>    randomizedSet.insert(3);
>    std::cout << "Random element: " << randomizedSet.getRandom() << std::endl;
>    randomizedSet.remove(2);
>    std::cout << "Random element: " << randomizedSet.getRandom() << std::endl;
>    return 0;
>}
>```

```CPP
class RandomizedSet {
public:
    set<int> randomSet;

    RandomizedSet() {
        
    }
    
    bool insert(int val) {
        if(randomSet.find(val) == randomSet.end()){
            randomSet.insert(val);
            return true;
        }
        else{
            return false;
        }
    }
    
    bool remove(int val) {
        if(randomSet.find(val) != randomSet.end()){
            randomSet.erase(val);
            return true;
        }
        else{
            return false;
        }
    }
    
    int getRandom() {
        int randomIndex = rand() % randomSet.size();
        auto it = randomSet.begin();
        advance(it, randomIndex);
        return *it;
    }
};
```
