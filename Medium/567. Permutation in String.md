# 567. Permutation in String
Problem : [HERE](https://leetcode.com/problems/permutation-in-string/description/)

>[!TIP]
>這題是在 LeetCode 上的一道經典題目：**567. Permutation in String**。題目的目的是給定兩個字串 `s1` 和 `s2`，需要判斷 `s2` 是否包含 `s1` 的某個排列。
>
>### 題目描述：
>給定兩個字串 `s1` 和 `s2`，請檢查 `s2` 中是否包含 `s1` 的某個排列。如果是，返回 `true`；否則返回 `false`。換句話說，檢查 `s2` 是否包含與 `s1` 的字母相同、順序可以不同的一個子字串。
>
>### 解題思路：
>
>這題可以使用滑動視窗（Sliding Window）和字符計數的技巧來解決，基本思路如下：
>
>1. **滑動視窗的概念：**
>   - 由於排列是字符位置的調換，我們需要檢查 `s2` 的某個子字串是否是 `s1` 的排列。
>   - 所以，我們可以使用滑動視窗大小等於 `s1` 的長度，在 `s2` 中滑動這個視窗，然後每次檢查這個視窗中的子字串是否是 `s1` 的排列。
>
>2. **字符計數：**
>   - 我們可以用一個頻率表來記錄 `s1` 中各個字符出現的次數，並維護一個與 `s1` 長度相同的滑動視窗，檢查 `s2` 中這個滑動視窗對應的子字串的字符頻率是否和 `s1` 相同。
>
>### 演算法步驟：
>
>1. 先檢查 `s1` 長度是否大於 `s2`，如果是，直接返回 `false`。
>2. 創建兩個頻率表（hashmap 或陣列），一個用來儲存 `s1` 中各個字符的頻率，另一個用來儲存 `s2` 當前滑動視窗中各個字符的頻率。
>3. 使用滑動視窗技術遍歷 `s2`：
>   - 每次移動滑動視窗時，將一個新字符加入視窗，並從視窗中移除一個字符。
>   - 每次都檢查兩個頻率表是否相等，如果相等，返回 `true`。
>4. 如果遍歷完 `s2` 都沒有找到匹配的子字串，則返回 `false`。
>
>### 時間和空間複雜度分析：
>- **時間複雜度**：O(n)，其中 `n` 是 `s2` 的長度。主要的開銷是滑動窗口每次更新字符頻率表，這可以在常數時間內完成。
>- **空間複雜度**：O(1)，因為我們只用到了固定大小的頻率表（最多 26 個字符）。
>
>這個解法使用了滑動窗口和頻率表的優化，使得能夠在線性時間內解決問題。

```CPP
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        int len_s1 = s1.size();
        int len_s2 = s2.size();
        if(len_s1 > len_s2) return false;

        vector<int>arr_s1(26 , 0) , arr_s2(26 , 0);

        for(int i = 0 ; i < len_s1 ; i++){
            arr_s1[s1[i] - 'a']++;
            arr_s2[s2[i] - 'a']++;
        }
        
        if(arr_s1 == arr_s2) return true;

        for(int i = len_s1 ; i < len_s2 ; i++){
            arr_s2[s2[i - len_s1] - 'a']--;
            arr_s2[s2[i] - 'a']++;

            if(arr_s1 == arr_s2) return true;
        }
        return false;
    }
};
```
