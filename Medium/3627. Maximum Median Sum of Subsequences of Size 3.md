# 3627. Maximum Median Sum of Subsequences of Size 3
Problem : [HERE]()

>[!TIP]
>排序nums, 然後每次都從後面挑倒數第二個數 這樣就會是中位數

```CPP
class Solution {
public:    
    long long maximumMedianSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        long long ans = 0;
        int len = nums.size();
        int times = len / 3;
        for(int i = 0 ; i < times ; i++) {
            ans+= nums[len - 2 * (i + 1)];
        }
        return ans;
    }
};
```
