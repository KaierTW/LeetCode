# 236. Lowest Common Ancestor of a Binary Tree

>## 🧠 解題思路：Lowest Common Ancestor of a Binary Tree
>
>我們要找的是兩個節點 `p` 和 `q` 在一棵二元樹中的「最近公共祖先」。
>
>### 思考方式：
>
>1. **遞迴遍歷整棵樹**，從根節點開始。
>2. 如果當前節點是 `nullptr`，就回傳 `nullptr`。
>3. 如果當前節點是 `p` 或 `q`，就回傳當前節點。
>4. 否則就遞迴往左子樹和右子樹找：
>   - 如果左右子樹都找到了 `p` 或 `q`，那麼當前節點就是最近公共祖先。
>   - 如果只有一邊找到了，就把那一邊回傳上去。
>
>---
>
>## 🧾 C++ 範例程式碼
>
>```cpp
>class Solution {
>public:
>    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
>        // 如果 root 是空的，或是 root 就是 p 或 q，直接回傳 root
>        if (root == nullptr || root == p || root == q) {
>            return root;
>        }
>
>        // 遞迴往左子樹和右子樹找
>        TreeNode* left = lowestCommonAncestor(root->left, p, q);
>        TreeNode* right = lowestCommonAncestor(root->right, p, q);
>
>        // 如果左右子樹都找到了，表示 p 和 q 分別在左右兩邊，root 就是最近公共祖先
>        if (left != nullptr && right != nullptr) {
>            return root;
>        }
>
>        // 否則就回傳找到的那一邊（可能是左邊或右邊）
>        return left != nullptr ? left : right;
>    }
>};
>```
>
>---
>
>### ✅ 時間與空間複雜度
>
>- **時間複雜度**： $$O(n)$$，其中 $$n$$ 是樹的節點數，因為每個節點最多訪問一次。
>- **空間複雜度**： $$O(h)$$，其中 $$h$$ 是樹的高度，用於遞迴堆疊。
>
>---
>


```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // 如果 root 是空的，或是 root 就是 p 或 q，直接回傳 root
        if(root == NULL || root == p || root == q) return root;
        // 遞迴往左子樹和右子樹找
        TreeNode* left = lowestCommonAncestor(root -> left, p, q);
        TreeNode* right = lowestCommonAncestor(root -> right, p, q);

        
        // 如果左右子樹都找到了，表示 p 和 q 分別在左右兩邊，root 就是最近公共祖先
        if (left != NULL && right != NULL) {
            return root;
        }
        // 否則就回傳找到的那一邊（可能是左邊或右邊）
        else return left != NULL ? left : right;

    }
};
```
