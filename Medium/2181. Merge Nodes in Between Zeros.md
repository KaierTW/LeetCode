# 2181. Merge Nodes in Between Zeros
Problem : [HERE](https://leetcode.com/problems/merge-nodes-in-between-zeros/submissions/1309575598/?envType=daily-question&envId=2024-07-04)

>[!TIP]
>要建立一個新的ans的link list，如果題目的node的val不是0的話就要把它加總起來
>
>然後加到新的ans裡面

```C
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */

struct ListNode* ansNodes(int sum){
    struct ListNode* ans = malloc(sizeof(struct ListNode));
    ans -> val = sum;
    ans -> next = NULL;
    return ans;
}

struct ListNode* mergeNodes(struct ListNode* head) {
    struct ListNode* temp = head -> next;
    struct ListNode* ansHead = NULL;
    struct ListNode* ans = NULL;
    int sum = 0;
    while(temp != NULL){
        if(temp -> val != 0) {
            sum += temp -> val;
        }
        else {
            if(ansHead == NULL) {
                ansHead = ansNodes(sum);
                ans = ansHead;
            }
            else {
                ans -> next = ansNodes(sum);
                ans = ans -> next;
            }            
            sum = 0;
        }
        temp = temp -> next;
    }
    return ansHead;
}
```
