# 3.  Longest Substring Without Repeating Characters

Problem : [HERE](https://leetcode.com/problems/longest-substring-without-repeating-characters/description/)

> [!TIP]
> 設定左邊邊界和右邊邊界，左邊邊界先固定，右邊邊界往右找
```C
int lengthOfLongestSubstring(char* s) {
    int length = strlen(s);
    if(length == 0) return 0;    
    int count = 0;    
    int ans = 0;
    int* check = calloc(95 , sizeof(int));
    for(int i = 0  ; i < length ; i++){
        memset(check , 0 ,  95 * sizeof(int));
        count = 0;
        *(check + (s[i] - ' ')) = 1;
        for(int j = i + 1 ; j < length ; j++){
            if(*(check + (s[j] - ' ')) == 1) break;
            else {
                *(check + (s[j] - ' ')) = 1;
                count++;
            }
            if(count > ans) ans = count;
        }
    }
    return ans + 1;
}
```

>[!TIP]
>1. 使用 `unordered_map` 來記錄每個字符最後出現的位置。
>2. 使用兩個指針 `left` 和 `right` 來表示滑動窗口的左右邊界。
>3. 當遇到重複字符時，更新 `left` 指針到重複字符的下一個位置。
>4. 更新 `maxLen` 為當前窗口的大小。
>
>這樣可以高效地找到不包含重複字符的最長子字串的長度。

```CPP
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> charMap;
        string temp;
        int left = 0, maxLen = 0;
        for(int right = 0 ; right < s.size() ; right++){
            temp.push_back(s[right]);
            if(charMap[s[right]] == 0) {                
                charMap[s[right]] = 1;                                
                if(temp.size() > maxLen) maxLen = temp.size();                
            }
            else{                                
                while(left < right){                    
                    if(s[left] == s[right]){
                        temp.erase(0, 1);
                        left++;
                        break;
                    }
                    else{
                        temp.erase(0, 1);
                        charMap[s[left++]] = 0;
                    }                                                            
                }
            }            
        }
        return maxLen;
    }
};
```
