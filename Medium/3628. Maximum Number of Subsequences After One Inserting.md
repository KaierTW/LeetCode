# 3628. Maximum Number of Subsequences After One Inserting
Problem : [HERE](https://leetcode.com/problems/maximum-number-of-subsequences-after-one-inserting/description/)

>[!TIP]
>
>### 🧠 Hint 1（中文解釋）：
>
>> 預先計算下列陣列：
>>
>> * `preL[i]`：表示從開頭到第 `i` 位為止（不含 `i`）有多少個 `L`。
>> * `preLC[i]`：表示從開頭到第 `i` 位為止（不含 `i`）有多少組 `"LC"`。
>> * `sufT[i]`：表示從第 `i` 位（含）到結尾有多少個 `T`。
>> * `sufCT[i]`：表示從第 `i` 位（含）到結尾有多少組 `"CT"`。
>
>👉 這是為了之後在嘗試插入一個字元時，可以快速知道插入前後字串中潛在的 `"LCT"` 子序列組數。
>
>---
>
>### 🧠 Hint 2（中文解釋）：
>
>> 計算一個 `base` 值：
>>
>> * `base = Σ preLC[i] * sufT[i]`
>> * 遍歷每個位置 `i`，在該位置的右邊還有幾個 `T`，前面有幾個 `"LC"`，相乘表示能構成多少個 `"LCT"` 子序列。
>
>👉 `base` 就是**原始字串**中，不插入任何字元時能夠組成的 `"LCT"` 數量總和。
>
>---
>
>### 🧠 Hint 3（中文解釋）：
>
>> 嘗試在字串的每個位置 `i` 插入一個字元（`'L'`、`'C'` 或 `'T'`）：
>>
>> * 插入 `'L'` 的增益（gain）：`sufCT[i]`，因為你可能讓 `"LCT"` 組成。
>> * 插入 `'C'` 的增益：`preL[i] * sufT[i]`，因為你可能夾在 `'L'` 和 `'T'` 中間。
>> * 插入 `'T'` 的增益：`preLC[i]`，因為你可能接在 `"LC"` 之後形成 `"LCT"`。
>>
>> 然後取最大的：
>>
>> ```cpp
>> max(base, base + gain)
>> ```
>
>👉 最後回傳能夠使 `"LCT"` 出現次數最多的插入位置與字元。
>
>---
>
>### 📌 解題小總結（中文）：
>
>1. 預先用 prefix/suffix 技巧統計 `L`, `LC`, `T`, `CT` 的出現數量。
>2. 算出原本沒有插入任何字元的 `LCT` 數量 (`base`)。
>3. 嘗試在每個位置插入 `'L'`、`'C'` 或 `'T'`，根據對 `LCT` 數量的提升來選擇最大增益。
>4. 回傳 `base` 或 `base + gain` 中較大值。
>


```CPP
class Solution {
public:
    long long numOfSubsequences(string s) {
        int n = s.size();
        long long count_L = 0, count_LC = 0, count_LCT = 0, count_T = 0, count_CT = 0;
        vector<long long> v_L(n), v_LC(n), v_LCT(n), v_T(n), v_CT(n);
        for(int i = 0 ; i < n ; i++) {
            if(s[i] == 'L') count_L++;
            else if(s[i] == 'C') count_LC += count_L;
            else if(s[i] == 'T') count_LCT += count_LC;
            v_L[i] = count_L;
            v_LC[i] = count_LC;
            v_LCT[i] = count_LCT;
        }
        for(int i = n - 1 ; i >= 0 ; i--){
            if(s[i] == 'T') count_T++;
            else if(s[i] == 'C') count_CT += count_T;
            v_T[i] = count_T;
            v_CT[i] = count_CT;
        }
        
        // 插入L
        long long insert_L = count_LCT + count_CT;
        // 插入T
        long long insert_T = count_LCT + count_LC;
        // 插入C
        long long insert_C = 0;
        for(int i = 0 ; i < n ; i++){            
            insert_C = max(insert_C, count_LCT + (v_L[i] * v_T[i]));
        }
        return (long long)max(insert_L, max(insert_T, insert_C));
    }
};
```
