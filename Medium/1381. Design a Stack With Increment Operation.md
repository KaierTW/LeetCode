# 1381. Design a Stack With Increment Operation
Problem : [HERE](https://leetcode.com/problems/design-a-stack-with-increment-operation/description/)

>[!TIP]
>題目 **1381. Design a Stack With Increment Operation** 讓我們設計一個自定義的堆疊（Stack），此堆疊需要支援三種操作：
>
>1. **push(x)**: 將 `x` 壓入堆疊。
>2. **pop()**: 移除並返回堆疊頂端的元素。如果堆疊為空，返回 -1。
>3. **increment(k, val)**: 增加堆疊中前 `k` 個元素的值，每個元素都增加 `val`。如果堆疊中元素少於 `k` 個，則對所有元素進行增加。
>
>### 題目描述：
>設計一個支援這三種操作的堆疊，並且每個操作的時間複雜度要合理，不能過於複雜。
>
>### 例子:
>```plaintext
>輸入：
>["CustomStack", "push", "push", "pop", "increment", "increment", "pop", "pop", "pop"]
>[[3], [1], [2], [], [2, 100], [3, 100], [], [], []]
>
>輸出：
>[null, null, null, 2, null, null, 201, 101, -1]
>
>解釋：
>CustomStack customStack = new CustomStack(3); // 初始化容量為3的堆疊
>customStack.push(1);                          // 堆疊變為 [1]
>customStack.push(2);                          // 堆疊變為 [1, 2]
>customStack.pop();                            // 返回 2，堆疊變為 [1]
>customStack.increment(2, 100);                // 堆疊變為 [101]
>customStack.increment(3, 100);                // 堆疊變為 [201]
>customStack.pop();                            // 返回 201，堆疊變為 []
>customStack.pop();                            // 返回 -1，因為堆疊為空
>customStack.pop();                            // 返回 -1，因為堆疊為空
>```
>
>### 操作說明：
>1. **push(x)**: 若堆疊未滿（即元素數量小於容量），將 `x` 推入堆疊。
>2. **pop()**: 若堆疊不為空，移除並返回堆疊頂部的元素，若為空則返回 -1。
>3. **increment(k, val)**: 對堆疊中前 `k` 個元素，每個增加 `val`，如果堆疊長度小於 `k`，則對所有元素增加。
>
>### 解題思路：
>- 需要一個數組來儲存堆疊的內容，並追蹤當前堆疊的大小。
>- `increment` 操作可能會涉及多個元素，因此要合理設計以便避免逐一操作每個元素導致效能低下。
>
>### 可能的實現方法：
>- 可以用一個數組來模擬堆疊，`push` 和 `pop` 都是 O(1) 操作。
>- 對於 `increment` 操作，可以直接更新數組的前 `k` 個元素（這會是 O(k) 的操作）。
>


```CPP
class CustomStack {
public:
    vector<int> stack;
    int index;
    CustomStack(int maxSize) {
        stack.resize(maxSize);
        index = 0;
        cout << "Stack Size : " << stack.size() << endl;
    }
    
    void push(int x) {
        if(index < stack.size()){
            cout << "Push : " << x << " Index : " << index << endl;
            stack[index++] = x;            
        }
    }
    
    int pop() {                
        return (index - 1) == -1 ? -1 : stack[--index];
    }
    
    void increment(int k, int val) {
        cout << "Increment" << endl;
        for(int i = 0 ; i < min(k , static_cast<int>(stack.size())) ; i++){
            stack[i] += val;
            cout << "Increment Val : " << stack[i] << endl;
        }
    }
};

/**
 * Your CustomStack object will be instantiated and called as such:
 * CustomStack* obj = new CustomStack(maxSize);
 * obj->push(x);
 * int param_2 = obj->pop();
 * obj->increment(k,val);
 */
```
