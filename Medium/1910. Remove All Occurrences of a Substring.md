# 1910. Remove All Occurrences of a Substring
Problem : [HERE](https://leetcode.com/problems/remove-all-occurrences-of-a-substring/description/)

>
>### 解題思路
>
>1. **理解題目**：
>   - 給定一個字串 `s` 和一個子字串 `part`，我們需要從 `s` 中移除所有出現的 `part`，直到 `s` 中不再包含 `part`。
>
>2. **使用 `std::string::find` 和 `std::string::erase` 方法**：
>   - `find` 方法可以用來找到 `part` 在 `s` 中的起始位置。
>   - `erase` 方法可以用來移除從指定位置開始、長度為 `part.length()` 的子字串。
>
>3. **迴圈處理**：
>   - 使用一個迴圈來不斷搜尋並移除 `part`，直到 `find` 返回 `std::string::npos`，表示 `part` 不再存在於 `s` 中。
>
>### 具體步驟
>
>1. 初始化一個變數 `pos` 來存儲 `part` 在 `s` 中的起始位置。
>2. 使用 `while` 迴圈來不斷搜尋 `part`：
>   - 如果 `find` 找到 `part`，則使用 `erase` 移除該子字串。
>   - 如果 `find` 返回 `std::string::npos`，則跳出迴圈。
>3. 返回處理後的字串 `s`。
>
>### 解釋
>
>- **`find` 方法**：在每次迴圈中，`find` 會搜尋 `part` 在 `s` 中的起始位置。如果找到，返回位置索引；如果找不到，返回 `std::string::npos`。
>- **`erase` 方法**：一旦找到 `part`，`erase` 會從找到的位置開始，移除長度為 `part.length()` 的子字串。
>- **迴圈**：這個過程會重複進行，直到 `part` 不再存在於 `s` 中。



```CPP
class Solution {
public:
    string removeOccurrences(string s, string part) {
        string ans;
        for(char c : s){
            ans.push_back(c);
            if(c == part.back() && ans.size() >= part.size()){
                auto pos = ans.rfind(part);
                if(pos != string::npos){
                    ans.erase(pos, part.size());
                }
            }
        }
        return ans;
    }
};
```
