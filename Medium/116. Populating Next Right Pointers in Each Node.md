# 116. Populating Next Right Pointers in Each Node
Problem : [HERE](https://leetcode.com/problems/populating-next-right-pointers-in-each-node/description/)

>[!TIP]
>![image](https://github.com/user-attachments/assets/1af604ca-c887-4492-a018-5f1ac94b0fae)
>
>這題的意思是說，Node的struct比原先的還多了一個next指標，目的是用來記錄node旁邊的node
>
>所以現在要開始找，首先找左邊的node，因為這是一顆完美的樹，所以左邊的node的旁邊 一定會有node，也就是右邊
>
>接下來要處理右邊的部分，因為右邊的旁邊有可能會是空的，如果是空的就是NULL
>
>那要怎麼判斷右邊的旁邊是不是空的呢，要從現在當前的node判斷
>
>如果當前的node是有next的，那就表示他旁邊有節點
>
>旁邊有節點的意思就是說當前node的右邊，旁邊一定也有node
>
>因為當前node的旁邊是有節點，而且這是一顆完美的樹，所以左右兩邊高度是一樣的
>
>那麼當前的node有旁邊的節點，表示他下面也有節點
>
>所以也就可以讓當前node的右邊的next指到當前node的next的左邊
>
>以上繞口令完畢XDD


```CPP
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* left;
    Node* right;
    Node* next;

    Node() : val(0), left(NULL), right(NULL), next(NULL) {}

    Node(int _val) : val(_val), left(NULL), right(NULL), next(NULL) {}

    Node(int _val, Node* _left, Node* _right, Node* _next)
        : val(_val), left(_left), right(_right), next(_next) {}
};
*/

class Solution {
public:
    Node* connect(Node* root) {
        if(root == NULL) return NULL;
        if(root -> left != NULL) root -> left -> next = root -> right;
        if(root -> right != NULL && root -> next != NULL) root -> right -> next = root -> next -> left;
        connect(root -> left);
        connect(root -> right);
        return root;
    }
};
```
