# 114. Flatten Binary Tree to Linked List
Problem : [HERE](https://leetcode.com/problems/flatten-binary-tree-to-linked-list/description/)

>[!TIP]
>先按照Preorder的方式把節點都記錄起來
>
>Preorder就是 節點→左邊→右邊
>
>記錄起來之後就開始重新排列，把左邊都用成NULL，然後連結右邊

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void addLink(TreeNode* node , vector<TreeNode*>& ans){
        if(node == NULL) return;
        ans.push_back(node);
        addLink(node->left , ans);
        addLink(node->right , ans);        
    }
    void flatten(TreeNode* root) {
        if(root == NULL || (root -> left == NULL && root -> right == NULL)) return;
        vector<TreeNode*> ans;
        addLink(root , ans);
        for(int i = 1 ; i < ans.size() ; i++){
            root -> left = NULL;
            root -> right = ans[i];
            root = root -> right;
        }
    }
};
```

>## ✅ 題目說明（再複習）
>
>將一棵二元樹「原地」轉換成「單向 Linked List」
>滿足 **先序遍歷順序**，並把所有 left pointer 設為 `NULL`。
>
>### 範例：
>
>原樹：
>
>```
>    1
>   / \
>  2   5
> / \   \
>3   4   6
>```
>
>flatten 後：
>
>```
>1
> \
>  2
>   \
>    3
>     \
>      4
>       \
>        5
>         \
>          6
>```
>
>---
>
># ✅ 解題思路整理
>
>### 方式一：用 Queue 先存，再連（你寫的方式）
>
>* 做一次 pre-order traversal，所有節點用 queue 存起來
>* 再一個個接起來
>* **空間複雜度：O(n)**，**簡單但不原地**
>
>### 方式二：**原地修改 + Morris Traversal 思想**（面試推薦）
>
>#### Morris Traversal 是什麼？
>
>* 是一種**不使用遞迴或 stack** 來做遍歷的技巧
>* 利用樹的空指標（通常是右子樹的 null）來暫時儲存返回資訊
>* 在這題，我們利用它來直接把左子樹的最後一個節點接到右子樹，再將左子樹移到右邊
>
>---
>
># ✅ 原地修改 Morris Traversal 解法
>
>### 🔧 程式碼：
>
>```cpp
>class Solution {
>public:
>    void flatten(TreeNode* root) {
>        TreeNode* curr = root;
>
>        while (curr) {
>            if (curr->left) {
>                // 找左子樹的最右節點（predecessor）
>                TreeNode* pred = curr->left;
>                while (pred->right) {
>                    pred = pred->right;
>                }
>
>                // 將目前節點的右子樹接到 pred 的右邊
>                pred->right = curr->right;
>
>                // 把左子樹搬到右邊
>                curr->right = curr->left;
>                curr->left = nullptr;
>            }
>
>            // 移動到下一個節點（往右）
>            curr = curr->right;
>        }
>    }
>};
>```
>
>---
>
>## ✅ Morris 解法逐步說明
>
>### 對於每個節點 curr：
>
>1. **如果 curr 有左子樹：**
>
>   * 找 curr 左子樹的 **最右節點 pred**
>   * 把 curr 的右子樹接到 pred->right 上
>   * 然後 curr->right 改成 curr->left（也就是把左子樹搬到右邊）
>   * 清空 curr->left（變成 linked list 的形狀）
>
>2. **然後 curr 往右移動**（下一個節點）
>
>---
>
>### 以這棵樹為例：
>
>```
>    1
>   / \
>  2   5
> / \   \
>3   4   6
>```
>
>* curr = 1，有左子樹 2，找 2 的最右節點是 4
>
>  * 4->right = 5
>  * 1->right = 2，1->left = null
>
>此時變成：
>
>```
>1
> \
>  2
> / \
>3   4
>       \
>        5
>         \
>          6
>```
>
>下一步 curr = 2，繼續做一樣的事…
>

>## ✅ 小結：三種方法比較
>
>| 方法                   | 時間   | 空間   | 是否原地 | 備註                 |
>| -------------------- | ---- | ---- | ---- | ------------------ |
>| 1. queue + pre-order | O(n) | O(n) | ❌    | 簡單直覺，適合新手          |
>| 2. 遞迴 + prev pointer | O(n) | O(h) | ❌    | 用遞迴，空間是 call stack |
>| 3. Morris Traversal  | O(n) | O(1) | ✅    | 面試加分，技巧稍進階         |
