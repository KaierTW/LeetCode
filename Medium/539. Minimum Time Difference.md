# 539. Minimum Time Difference
Problem : [HERE](https://leetcode.com/problems/minimum-time-difference/description/)

>[!TIP]
>這題是要你找出一組時間點之間的最小時間差（以分鐘為單位）。你可以將所有的時間轉換成分鐘，排序後再計算相鄰時間點之間的差值，最後還要記得考慮跨日的情況。這是一個經典的模擬問題，核心步驟如下：
>
>### 具體解法
>1. **轉換時間格式**：將時間點（"HH:MM"）轉換為以分鐘為單位的整數，這樣方便計算時間差。
>2. **排序時間**：將所有時間轉換成分鐘後進行排序。
>3. **計算相鄰時間差**：計算排序後每對相鄰時間的時間差，記錄最小的時間差。
>4. **考慮跨日情況**：由於時間點可以跨過午夜，最後還需要比較第一個和最後一個時間點（跨過午夜）的時間差。
>
>### 解題步驟：
>
>1. 將時間格式 "HH:MM" 轉換為分鐘數，公式為：
>
>   minutes = HH * 60 + MM
>
>2. 將所有時間點轉換為分鐘，然後排序。
>3. 計算相鄰時間的差，並找出最小的時間差。
>4. 別忘了比較跨日的時間差，即 `1440` 分鐘減去最後一個時間與第一個時間之間的差值。
>
>
>### 解法解析：
>
>1. **時間轉換**：函數 `TimeToMinute` 將時間從 `HH:MM` 格式轉換為總分鐘數。比如 `"23:59"` 會變成 `23 * 60 + 59 = 1439`。
>2. **排序**：將所有轉換好的分鐘值放入 `vector` 中並進行排序，方便後續計算相鄰時間點的差。
>3. **計算最小差值**：遍歷相鄰的時間點，計算它們的差值，並更新最小的時間差。
>4. **處理跨日**：最後一個時間與第一個時間的跨日情況要特別處理，差值為 `1440` 分鐘減去兩者之間的差值。
>
>### 時間複雜度：
>- **時間複雜度**：主要由排序操作主導，為  O( n log n )，其中 ( n ) 是時間點的數量。
>- **空間複雜度**：額外的空間用於儲存分鐘數，因此是 ( O(n) )。
>
>### 小結：
>- 核心是將時間轉換為分鐘並排序，這樣便於計算相鄰時間點的差值。
>- 別忘了處理跨日的特殊情況。


```CPP
class Solution {
public:
    int TimeToMinute(string time){
        int hour = stoi(time.substr(0 , 2)); // substr取子字串，從index 0開始往後取兩位
        int minute = stoi(time.substr(3 , 2)); // substr取子字串，從index 3開始往後取兩位
        return hour * 60 + minute;
    }
    
    int findMinDifference(vector<string>& timePoints) {
        vector<int> intTimePoints;        
        for(string timePoint : timePoints){            
            intTimePoints.push_back(TimeToMinute(timePoint));
        }
        sort(intTimePoints.begin() , intTimePoints.end());
        int minTime = INT_MAX;
        for(int i = 1 ; i < intTimePoints.size() ; i++){
            minTime = min(minTime , intTimePoints[i] - intTimePoints[i - 1]);
        }
        //If cross the day
        int crossDay = 1440 - intTimePoints.back() + intTimePoints.front();
        return min(minTime , crossDay);
    }
    
};
```
