# 2924. Find Champion II
Problem : [HERE](https://leetcode.com/problems/find-champion-ii/description/)

>[!TIP]
>這是一個典型的圖論問題，目標是從一個有向無環圖（DAG）中找出唯一的「冠軍」節點。如果存在唯一的節點，其入度為 0 且可以到達圖中所有其他節點，那麼該節點就是冠軍；否則，返回 -1。
>
>讓我們一步步解析解題思路：
>
>
>### **解題思路**
>1. **圖的基本性質**
>   - 冠軍節點必須是所有其他節點的祖先（即可以通過有向路徑到達其他所有節點）。
>   - 冠軍節點的入度應該是 0，因為沒有其他節點可以擊敗它。
>
>2. **步驟**
>   - 構建圖：使用鄰接表來表示圖。
>   - 計算每個節點的入度。
>   - 確認是否有且僅有一個入度為 0 的節點，並檢查該節點是否可以到達圖中的所有其他節點。
>
>3. **判斷冠軍性質**
>   - 如果有多個入度為 0 的節點，則不可能有唯一的冠軍，直接返回 -1。
>   - 使用深度優先搜索（DFS）或廣度優先搜索（BFS）檢查該節點是否可以到達所有其他節點。
>
>### **時間複雜度與空間複雜度**
>- **時間複雜度**：
>  - 構建圖和計算入度需要 \(O(m)\)，其中 \(m\) 是邊數。
>  - BFS 遍歷需要 \(O(n + m)\)，因此總計是 \(O(n + m)\)。
>- **空間複雜度**：
>  - 鄰接表和訪問集合需要 \(O(n + m)\) 的空間。
>


``CPP
class Solution {
public:
    int findChampion(int n, vector<vector<int>>& edges) {
        vector<int> teamCount(n, 0);
        for(auto edge : edges){
            teamCount[edge[1]]++;
        }
        vector<int> ans;
        for(int i = 0 ; i < n ; i++){
            if(teamCount[i] == 0) ans.push_back(i);
        }
        return (ans.size() == 1) ? ans[0] : -1;
    }
};
```
