>## ❶ 題目目標
>
>給定一個整數陣列 `nums`，你要找出一個**子序列**（不需連續），使得其**任意相鄰兩數的和，其奇偶性都一致**，並求這樣的子序列最大可能長度。
>
>---
>
>## ❷ 奇偶性加法規則
>
>| 數字1 | 數字2 | 和 | 奇偶性 |
>| --- | --- | - | --- |
>| 偶   | 偶   | 偶 | ✅ 同 |
>| 奇   | 奇   | 偶 | ✅ 同 |
>| 偶   | 奇   | 奇 | ✅ 同 |
>| 奇   | 偶   | 奇 | ✅ 同 |
>
>### 但問題是：**你不能混合這些方式！**
>
>因為 `(奇 + 奇) = 偶`，但 `(奇 + 偶) = 奇`，你不能在同一子序列裡混用。
>
>---
>
>## ❸ 可行的四種合法子序列類型
>
>| 類型     | 元素結構               | 每對和 | 說明        |
>| ------ | ------------------ | --- | --------- |
>| 全偶數    | \[2, 4, 6, ...]    | 偶   | 偶 + 偶 = 偶 |
>| 全奇數    | \[1, 3, 5, ...]    | 偶   | 奇 + 奇 = 偶 |
>| 交錯（偶起） | \[偶, 奇, 偶, 奇, ...] | 奇   | 偶 + 奇 = 奇 |
>| 交錯（奇起） | \[奇, 偶, 奇, 偶, ...] | 奇   | 奇 + 偶 = 奇 |
>
>---
>
>## ❹ 解法流程（C++ 演算法精華）
>
>```cpp
>int maximumLength(vector<int>& nums) {
>    int allEven = 0, allOdd = 0;
>    int prevEven = 0, prevOdd = 0;
>
>    for (int num : nums) {
>        if (num % 2 == 0) {
>            allEven++;
>            prevEven = prevOdd + 1;
>        } else {
>            allOdd++;
>            prevOdd = prevEven + 1;
>        }
>    }
>
>    return max({allEven, allOdd, prevEven, prevOdd});
>}
>```
>
>---
>
>## 🧠 每個變數代表的意思
>
>| 變數         | 意義                             |
>| ---------- | ------------------------------ |
>| `allEven`  | 所有偶數的個數（也就是全偶子序列最大長度）          |
>| `allOdd`   | 所有奇數的個數（全奇子序列最大長度）             |
>| `prevEven` | 目前能達到的\*\*交錯子序列（以偶數結尾）\*\*最大長度 |
>| `prevOdd`  | 目前能達到的\*\*交錯子序列（以奇數結尾）\*\*最大長度 |
>
>---
>
>## 🧪 例子：`nums = [2, 1, 4, 3]`
>
>| i | num | 奇/偶 | allEven | allOdd | prevEven | prevOdd | 說明     |
>| - | --- | --- | ------- | ------ | -------- | ------- | ------ |
>| 0 | 2   | 偶   | 1       | 0      | 1        | 0       | 偶起始    |
>| 1 | 1   | 奇   | 1       | 1      | 1        | 2       | 交錯：偶→奇 |
>| 2 | 4   | 偶   | 2       | 1      | 3        | 2       | 交錯：奇→偶 |
>| 3 | 3   | 奇   | 2       | 2      | 3        | 4       | 交錯：偶→奇 |
>
>所以最後答案為：
>
>```cpp
>max(allEven, allOdd, prevEven, prevOdd) = max(2, 2, 3, 4) = 4
>```
>
>→ 有效的子序列：\[2, 1, 4, 3]，每一對和都是奇數（3, 5, 7）
>

>* **空間複雜度：** `O(1)` — 只用幾個變數儲存狀態

>
>## 🎯 最終答案
>
>```cpp
>return max({allEven, allOdd, prevEven, prevOdd});
>```
>
>這就是合法子序列最大長度！
>
>---
>



```CPP
class Solution {
public:
    int maximumLength(vector<int>& nums) {
        int allEven = 0, allOdd = 0;
        int prevEven = 0, prevOdd = 0;

        for (int num : nums) {
            if (num % 2 == 0) {
                allEven++;
                prevEven = prevOdd + 1;
            } else {
                allOdd++;
                prevOdd = prevEven + 1;
            }
        }

        return max({allEven, allOdd, prevEven, prevOdd});
    }
};
```
