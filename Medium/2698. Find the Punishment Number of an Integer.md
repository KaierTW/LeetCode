# 2698. Find the Punishment Number of an Integer
Problem : [HERE](https://leetcode.com/problems/find-the-punishment-number-of-an-integer/description/)

>[!TIP]
>
>這題目要求找到一個正整數的懲罰數。具體來說，給定一個正整數 \( n \)，返回其懲罰數。懲罰數的定義如下：
>
>1. 在範圍 \( 1 \leq i \leq n \) 的所有整數 \( i \) 中，找到符合條件的所有數字。
>2. 每個符合條件的數字 \( i \) 滿足：數字 \( i \) 的平方的十進制表示可以被劃分為連續的子字符串，這些子字符串的整數值之和等於 \( i \)。
>
>### 範例
>
>- **範例1：**
>  ```plaintext
>  輸入：n = 10
>  輸出：182
>  解釋：
>  有三個符合條件的數字 i 在範圍 [1, 10] 內：
>  - 1 因為 \( 1 * 1 = 1 \)
>  - 9 因為 \( 9 * 9 = 81 \)，而 81 可以被劃分為 8 和 1，和等於 9
>  - 10 因為 \( 10 * 10 = 100 \)，而 100 可以被劃分為 10 和 0，和等於 10
>  因此，10 的懲罰數為 \( 1 + 81 + 100 = 182 \)
>
>- **範例2：**
>  ```plaintext
>  輸入：n = 37
>  輸出：1478
>  解釋：
>  有四個符合條件的數字 i 在範圍 [1, 37] 內：
>  - 1 因為 \( 1 * 1 = 1 \)
>  - 9 因為 \( 9 * 9 = 81 \)，而 81 可以被劃分為 8 和 1
>  - 10 因為 \( 10 * 10 = 100 \)，而 100 可以被劃分為 10 和 0
>  - 36 因為 \( 36 * 36 = 1296 \)，而 1296 可以被劃分為 1, 29 和 6，和等於 36
>  因此，37 的懲罰數為 \( 1 + 81 + 100 + 1296 = 1478 \)
>
>### 解題思路
>
>1. **迭代每個數字 i**：從 1 到 n 迭代每個數字 i。
>2. **計算平方**：計算每個 i 的平方。
>3. **判斷是否可被劃分**：檢查平方數字是否可以被劃分為連續的子字符串，這些子字符串的整數值之和等於原數字 i。
>4. **累加懲罰數**：將所有符合條件的數字的平方累加起來，得到懲罰數。
>
>這段代碼使用了深度優先搜索（DFS）來檢查平方數是否可以被劃分為連續的子字符串，並確保這些子字符串的和等於原數字。

>### 檢查是否可以被劃分的邏輯
>
>假設我們要檢查數字 `i` 是否符合條件：
>1. 首先計算數字 `i` 的平方 `i * i`。
>2. 將平方數轉換為字符串形式，以便我們可以按子字符串進行操作。
>3. 使用遞歸方法，從字符串的左側開始，不斷劃分子字符串，並累加這些子字符串的整數值。
>4. 如果在劃分的過程中，某次累加的值等於數字 `i`，那麼這個數字符合條件。
>
>### 遞歸方法的詳細步驟
>
>下面是遞歸方法的具體實現步驟：
>1. **起始條件**：如果起始位置等於字符串的長度，則檢查累加和是否等於目標值（即數字 `i`）。
>2. **遞歸劃分**：從當前起始位置開始，逐步劃分子字符串並轉換為整數值，將這個整數值累加到目前的和中，然後遞歸檢查剩餘部分。
>3. **回溯**：如果遞歸找到符合條件的劃分，則返回 `true`，否則繼續嘗試其他劃分。

>### 遞歸檢查的概念
>
>我們的目的是要檢查數字 `i` 的平方能否被劃分為若干個連續的子字符串，這些子字符串的整數值之和等於原數字 `i`。這樣的檢查是一個典型的遞歸問題，因為我們需要不斷地將字符串劃分並檢查每個部分。
>
>### 遞歸函數的工作原理
>
>假設我們有數字 `i`，我們要檢查其平方 `i * i` 的字符串表示是否可以劃分為若干子字符串，使得這些子字符串的整數值之和等於 `i`。
>
>以下是遞歸函數 `isValid` 的詳細步驟：
>
>1. **基礎條件**：當起始位置 `start` 等於字符串的長度時，檢查當前累計和 `sum` 是否等於目標值 `target`（即原數字 `i`）。如果是，返回 `true`，表示找到了符合條件的劃分；否則返回 `false`。
>
>2. **遞歸劃分**：從當前起始位置 `start` 開始，不斷增加子字符串的長度，並計算這個子字符串的整數值。將這個整數值累加到當前的 `sum` 中，然後遞歸檢查剩餘的部分。
>   - 使用 `substr(start, i - start + 1)` 來獲取從 `start` 到 `i` 的子字符串，並使用 `stoi` 將其轉換為整數值。
>   - 遞歸調用函數 `isValid(s, target, i + 1, sum + part)` 檢查剩餘的部分。如果遞歸找到符合條件的劃分，則返回 `true`。
>

>### 總結
>
>遞歸檢查的核心是將字符串不斷劃分，並檢查每個子字符串的整數值之和是否等於目標值。這樣的遞歸方法可以有效地解決劃分問題。
>


```CPP
class Solution {
public:
    bool checkPunishment(const string&s, int target, int start, int currentSum){
        if(s.size() == start) return target == currentSum;
        for(int i = start ; i < s.size() ; i++){
            // 從start的位置到i的位置的數字
            int part = stoi(s.substr(start, i - start + 1));
            printf("Start: %d, Target: %d, Location: %d, Part Number: %d\n", start, target, i, part);
            if(checkPunishment(s, target, i + 1, currentSum + part)){
                return true;
            }
        }
        return false;
    }
    int punishmentNumber(int n) {
        int ans = 0;
        for(int i = 1 ; i <= n ; i++){
            if(checkPunishment(to_string(i * i), i, 0, 0)) ans += i * i;
        }
        return ans;
    }
};
```
