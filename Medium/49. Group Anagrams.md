# 49. Group Anagrams
Problem : [HERE](https://leetcode.com/problems/group-anagrams/description/)

>[!TIP]
>解題思路如下：
>
>1. **使用哈希表**：我們可以使用哈希表（`unordered_map`）來存儲每個字串的排序版本作為 key，並將所有與該排序版本相同的字串存儲在對應的 value 列表中。
>
>2. **排序字串**：對於每個字串，我們將其字母排序，這樣所有的字母相同但順序不同的字串（即字母異位詞）都會有相同的排序版本。
>
>3. **插入哈希表**：將排序後的字串作為 key，原始字串作為 value 插入到哈希表中。如果 key 已存在，則將原始字串添加到對應的列表中。
>
>4. **返回結果**：最後，哈希表中的所有 value 列表就是我們需要的字母異位詞分組。
>
>我們首先對每個字串進行排序，然後使用排序後的字串作為 key 將原始字串插入到哈希表中。
>最後，我們將哈希表中的所有 value 列表返回，這些列表就是字母異位詞分組


```CPP
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        vector<vector<string>> ans;
        unordered_map<string, vector<string>> uom_strs;
        for(string str : strs){
            string temp = str;
            sort(temp.begin(), temp.end());
            uom_strs[temp].push_back(str);
        }
        for(const auto& pair : uom_strs){
            ans.push_back(pair.second);
        }
        return ans;
    }
};
```
