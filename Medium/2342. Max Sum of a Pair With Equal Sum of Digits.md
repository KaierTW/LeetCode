# 2342. Max Sum of a Pair With Equal Sum of Digits
Problem : [HERE](https://leetcode.com/problems/max-sum-of-a-pair-with-equal-sum-of-digits/description)

>[!TIP]
>
>這題目要求我們找到一對數字，使它們的數字和相等，並且它們的總和最大。以下是解題思路：
>
>### 解題思路
>
>1. **計算數字和**：
>   - 我們需要一個函數來計算每個數字的數字和。例如，數字 `123` 的數字和是 `1 + 2 + 3 = 6`。
>
>2. **分組**：
>   - 使用一個哈希表（或字典）來將數字按其數字和分組。鍵是數字和，值是具有相同數字和的數字列表。
>
>3. **找出最大總和**：
>   - 對於每個數字和組，我們需要找到兩個最大的數字，並計算它們的總和。然後，我們比較所有組中的最大總和，找出最終結果。
>
>### 解釋
>
>1. **`digitSum` 函數**：計算數字的數字和。
>2. **`digitSumMap` 哈希表**：將數字按數字和分組。
>3. **找出最大總和**：對於每個數字和組，找到兩個最大的數字，計算它們的總和，並更新最大總和。
>
>這樣，我們就能找到符合條件的數字對，並計算它們的最大總和¹(https://leetcode.com/problems/max-sum-of-a-pair-with-equal-sum-of-digits/)。

```CPP
class Solution {
public:
    int digitSum(int n){
        int ans = 0;
        while(n > 0){
            ans += n % 10;
            n /= 10;
        }
        return ans;
    }
    int maximumSum(vector<int>& nums) {
        int ans = -1;
        unordered_map<int, vector<int>> uo_map;
        // 先儲存所有數字
        for(int num : nums){
            uo_map[digitSum(num)].push_back(num);
        }
        for(auto& [key, value] : uo_map){
            // 有兩組數字以上
            if(value.size() > 1){
                // 從大排到小
                sort(value.begin(), value.end(), greater<int>());
                ans = max(ans, value[0] + value[1]);
            }
            
        }
        return ans;
    }
};
```
