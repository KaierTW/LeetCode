# 128. Longest Consecutive Sequence
Problem : [HERE](https://leetcode.com/problems/longest-consecutive-sequence/description/)

>[!TIP]
>這題目要求找到未排序的整數數組中，最長的連續元素序列的長度。解題思路如下：
>
>1. **使用哈希表**：將數組轉換為集合，以便能夠在常數時間內檢查元素是否存在。
>2. **遍歷數組**：對於每個數字，檢查它是否是某個序列的起點（即它的前一個數字不在集合中）。
>3. **擴展序列**：如果找到序列的起點，則不斷檢查後續的數字是否存在於集合中，並計算序列的長度。
>4. **更新最長序列**：每次找到更長的序列時，更新最長序列的長度。
>
>具體步驟如下：
>
>1. 將數組轉換為集合，去除重複元素並便於快速查找。
>2. 遍歷數組中的每個數字，檢查它是否是某個序列的起點。
>3. 如果是序列的起點，則不斷檢查後續的數字是否存在於集合中，並計算序列的長度。
>4. 更新最長序列的長度。
>
>這樣的算法保證了線性時間複雜度 $$O(n)$$


```CPP
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        set<int> s;
        int ans = 0;
        for(int num : nums){
            s.insert(num);
        }
        for(const int& num : s){
            if(s.find(num - 1) == s.end()){
                int count = 1;
                while(s.find(num + count) != s.end()){
                    count++;
                }
                ans = max(ans, count);
            }
        }
        return ans;
    }
};
```
