# 1497. Check If Array Pairs Are Divisible by k
Problem : [HERE](https://leetcode.com/problems/check-if-array-pairs-are-divisible-by-k/description/)

>[!TIP]
>當我們處理這個問題時，核心思路是透過「餘數」來判斷數對的和是否能被 `k` 整除。下面我將詳細解釋這個解法的原理。
>
>### 原理解釋：
>
>#### 1. **餘數的概念**：
>當我們將每個數對 `k` 取餘數後，餘數可以幫助我們確定數對的和是否能被 `k` 整除。例如，假設我們有一個數 `x`，那麼如果 `(x + y) % k == 0`，則 `x % k + y % k == k 或 0`。這表示，對於每個餘數 `r1`，需要找到一個餘數 `r2`，使得 `(r1 + r2) % k == 0`。
>
>具體的對應關係是：
>- 如果 `x % k = r`，那麼 `y` 的餘數應該是 `k - r`，這樣 `(r + (k - r)) % k == 0`，即 `(x + y) % k == 0`。
>
>#### 2. **餘數的處理**：
>我們遍歷數組中的每個元素，將它們對 `k` 取餘數，並統計每個餘數出現的次數。這樣可以讓我們判斷每個餘數是否有相應的數字可以配對，從而滿足可整除的條件。
>
>例如，假設 `k = 5`，數組中存在以下數字及其餘數：
>- `arr = [7, 3, 8, 12, 4]`
>- `7 % 5 = 2`，`3 % 5 = 3`，`8 % 5 = 3`，`12 % 5 = 2`，`4 % 5 = 4`
>
>我們需要檢查這些餘數能否配對：
>- 餘數為 `2` 的數應該與餘數為 `3` 的數配對，因為 `(2 + 3) % 5 == 0`。
>- 餘數為 `4` 的數應該與餘數為 `1` 的數配對，因為 `(1 + 4) % 5 == 0`。
>
>#### 3. **特殊情況處理**：
>- **餘數為 0** 的情況：如果一個數對 `k` 的餘數為 0，那麼它只能和另一個餘數也為 0 的數配對，因為 `(0 + 0) % k == 0`。因此，餘數為 0 的數必須成對出現。
> 
>- **餘數為 `k/2` 的情況（當 `k` 是偶數）**：如果 `k` 是偶數，餘數為 `k/2` 的數也需要成對出現，因為 `(k/2 + k/2) % k == 0`。
>
>#### 4. **算法步驟**：
>1. **餘數計算**：我們遍歷數組，對每個數 `arr[i]` 計算 `arr[i] % k`，並使用一個大小為 `k` 的數組 `remainderCount` 來記錄每個餘數出現的次數。
>   
>2. **配對檢查**：
>   - 檢查餘數為 `0` 的數是否能成對出現。
>   - 檢查餘數 `r` 和 `k - r` 的數量是否相等，這樣它們的和才能被 `k` 整除。
>
>#### 5. **例子解析**：
>我們來看一個具體的例子：
>```cpp
>arr = [7, 3, 8, 12, 4]
>k = 5
>```
>- `7 % 5 = 2`，`3 % 5 = 3`，`8 % 5 = 3`，`12 % 5 = 2`，`4 % 5 = 4`
>
>- 餘數計算結果：
>  - `remainderCount[2] = 2` （因為 `7` 和 `12` 都餘數為 2）
>  - `remainderCount[3] = 2` （因為 `3` 和 `8` 都餘數為 3）
>  - `remainderCount[4] = 1` （因為 `4` 餘數為 4）
>
>檢查：
>- 餘數 `2` 和 `3` 可以互相配對，因為它們的數量相同（都為 2），且 `(2 + 3) % 5 == 0`。
>- 餘數 `4` 無法與餘數 `1` 配對，因為沒有餘數為 `1` 的數。所以這組數無法完全配對，返回 `false`。
>
>### 總結：
>這個算法的核心是利用數字的餘數特性，將數組的配對問題轉化為餘數的配對問題。通過對餘數進行統計，我們可以高效地判斷數組中的數對能否被 `k` 整除。
>


```CPP
class Solution {
public:
    bool canArrange(vector<int>& arr, int k) {
        vector<int> remainderCount(k, 0); // 用來統計餘數的數量
        
        // 計算每個數的餘數
        for (int num : arr) {
            int remainder = ((num % k) + k) % k; // 保證餘數是正數
            remainderCount[remainder]++;
        }
        
        // 檢查每個餘數是否能配對成功
        for (int i = 1; i < k; ++i) {
            // 餘數為 i 的數量應當與餘數為 k-i 的數量相等
            if (remainderCount[i] != remainderCount[k - i]) {
                return false;
            }
        }
        
        // 檢查餘數為 0 的數能否配對
        if (remainderCount[0] % 2 != 0) {
            return false;
        }
        
        return true;
    }
};
```
