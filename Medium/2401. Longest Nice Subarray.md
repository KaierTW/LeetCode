# 2401. Longest Nice Subarray
Problem : [HERE](https://leetcode.com/problems/longest-nice-subarray/description/)

>[!TIP]
>
>當然可以！這題目要求我們找到一個數組中最長的「漂亮子數組」。具體來說，給定一個正整數數組 `nums`，我們需要找到一個最長的子數組，使得這個子數組中的任意兩個不同位置的元素的按位與（bitwise AND）結果為 0。
>
>簡單來說，子數組中的每一對元素在二進制表示中不能有任何相同的位被設置為 1。
>
>### 解題思路
>
>1. **滑動窗口**：我們可以使用滑動窗口技術來解決這個問題。滑動窗口可以幫助我們在線性時間內找到符合條件的最長子數組。
>2. **按位操作**：我們需要使用按位與（bitwise AND）操作來檢查子數組中的元素是否符合條件。
>
>### 具體步驟
>
>1. 初始化兩個指針 `i` 和 `j`，分別表示滑動窗口的起始和結束位置。
>2. 使用一個變量 `mask` 來存儲當前窗口內所有元素的按位或（bitwise OR）結果。
>3. 遍歷數組 `nums`，對於每個元素 `nums[i]`：
>   - 如果 `mask` 和 `nums[i]` 的按位與結果不為 0，則縮小窗口（移動 `j`），直到 `mask` 和 `nums[i]` 的按位與結果為 0。
>   - 更新 `mask`，將 `nums[i]` 包含進當前窗口。
>   - 計算當前窗口的長度，並更新最長子數組的長度。

>[!TIP]
>按位異或（bitwise XOR）操作具有一個非常有用的特性：對同一個數字進行兩次異或操作會恢復原來的數字。這個特性使得我們可以用它來移除或恢復某個數字的影響。
>
>### 按位異或的特性
>
>1. **自反性**：
>   - 對於任何數字 `x`，`x ^ x = 0`。這意味著一個數字與自己異或的結果是 0。
>  
>2. **交換性和結合性**：
>   - 異或操作是交換的，即 `a ^ b = b ^ a`。
>   - 異或操作是結合的，即 `(a ^ b) ^ c = a ^ (b ^ c)`。
>
>3. **恢復性**：
>   - 對於任何數字 `x` 和 `y`，`(x ^ y) ^ y = x`。這意味著如果我們對一個數字進行兩次相同的異或操作，結果會恢復到原來的數字。
>
>### 具體例子
>
>假設我們有一個數組 `nums = [1, 2, 4]`，並且當前窗口內的元素為 `[1, 2]`，`mask = 3`（即 `1 | 2`），現在我們要移除 `nums[0]`：
>
>- 初始狀態：`mask = 3`（即 `1 | 2`）。
>- 移除 `nums[0]`：`mask ^= nums[0]`，即 `mask ^= 1`，`mask = 3 ^ 1 = 2`。
>
>這裡的 `mask ^= nums[0]` 實際上是將 `nums[0]` 的影響從 `mask` 中移除。因為 `mask` 是 `1 | 2`，當我們對 `mask` 進行 `^ 1` 操作時，相當於將 `1` 的影響從 `mask` 中去掉，剩下的就是 `2`。
>
>### 更詳細的步驟
>
>1. **初始狀態**：
>   - `mask = 1 | 2 = 3`（即 `011`）。
>   
>2. **移除 `nums[0]`**：
>   - `mask ^= nums[0]`，即 `mask ^= 1`。
>   - `3 ^ 1 = 011 ^ 001 = 010`，結果是 `2`。
>
>這樣，我們就成功地從 `mask` 中移除了 `nums[0]` 的影響，`mask` 現在只包含剩餘元素的按位或結果。
>
>希望這個解釋能幫助你更好地理解為什麼 `mask ^= nums[j];` 可以移除元素的影響！如果還有其他問題，隨時告訴我。

```CPP
class Solution {
public:
    int longestNiceSubarray(vector<int>& nums) {
        int n = nums.size();
        int max_length = 1;
        int left = 0;
        int used_bits = 0;
        
        for (int right = 0; right < n; ++right) {
            while ((used_bits & nums[right]) != 0) {
                used_bits ^= nums[left];
                ++left;
            }
            
            used_bits |= nums[right];
            max_length = max(max_length, right - left + 1);
        }
        
        return max_length;

    }
};
```
