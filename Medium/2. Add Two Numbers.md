# 2. Add Two Numbers
Problem : [HERE](https://leetcode.com/problems/add-two-numbers/)

> [!TIP]
> struct ListNode* NewNode = malloc(sizeof(struct ListNode))
>
> -> 每一次執行while迴圈的時候，malloc出來的都是新的地址，用temp暫存，下一次loop的時候就可以指定給下一個地址

```C
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode* result = NULL;
    struct ListNode* temp = NULL;
    int carry = 0;
    while(l1 != NULL || l2 != NULL || carry != 0){
        int sum = carry;
        if(l1 != NULL) {
            sum += l1 -> val;
            l1 = l1 -> next;
        }
        if(l2 != NULL) {
            sum += l2 -> val;
            l2 = l2 -> next;
        }
        carry = sum /10;
        struct ListNode* NewNode = malloc(sizeof(struct ListNode));
        NewNode -> val = sum % 10;
        NewNode -> next = NULL;
        if(result == NULL) {
            result = NewNode;
            temp = NewNode;
        }
        else {
            temp -> next = NewNode;
            temp = NewNode;
        }        
    }
    return result;
}
```




>[!TIP]
>LeetCode 第 2 題「Add Two Numbers」是一道非常經典的鏈結串列題目，題目敘述如下：
>
>---
>
>### 🧩 題目簡介：
>
>你會得到兩個非空的鏈結串列，代表兩個非負整數。每個節點只儲存一位數字，並且數字是**反向儲存**的（即最低位在最前面）。你要回傳一個新的鏈結串列，>代表這兩個數字的總和，也要以反向儲存的方式呈現。
>
>---
>
>### ✅ 解題思路：
>
>這題的核心概念是「模擬加法」，就像你在紙上加兩個數字一樣，從最低位開始加，並處理進位。
>
>#### 步驟如下：
>
>1. **初始化**：
>   - 建立一個虛擬頭節點 `dummy`，用來簡化串列操作。
>   - 使用一個指標 `current` 指向目前要插入的位置。
>   - 設定一個 `carry` 變數來儲存進位（初始為 0）。
>
>2. **迴圈加法**：
>   - 當 `l1` 或 `l2` 或 `carry` 有值時，就繼續加。
>   - 取出 `l1` 和 `l2` 的值（如果節點為空則視為 0）。
>   - 計算總和 `sum = val1 + val2 + carry`。
>   - 更新 `carry = sum / 10`。
>   - 建立新節點 `new ListNode(sum % 10)` 加到結果串列中。
>   - 移動 `l1` 和 `l2` 指標。
>
>3. **回傳結果**：
>   - 回傳 `dummy->next`，因為 `dummy` 是虛擬頭節點。
>
>---
>
>### 🧠 思考延伸：
>
>- 如果數字是正向儲存（最高位在前面），就要用 stack 或遞迴處理。
>- 如果要處理負數或浮點數，就要改資料結構或邏輯。
>
>---


```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        int carry = 0;
        ListNode* ans = new ListNode();
        ListNode* temp = ans;
        while(l1 != NULL || l2 != NULL || carry != 0){            
            int l1val = (l1) ? l1 -> val : 0;
            int l2val = (l2) ? l2 -> val : 0;
            int sum = l1val + l2val + carry;
            carry = sum /10;
            temp -> next = new ListNode(sum % 10);
            temp = temp -> next;
            if(l1 != NULL) l1 = l1 -> next;
            if(l2 != NULL) l2 = l2 -> next;
        }
        return ans -> next;
    }
};
```
