# 106. Construct Binary Tree from Inorder and Postorder Traversal
Problem : [HERE](https://leetcode.com/problems/construct-binary-tree-from-inorder-and-postorder-traversal/description/)

>[!TIP]
>當然可以！以下是 LeetCode 106「**Construct Binary Tree from Inorder and Postorder Traversal**」的完整解題思路整理，幫助你更清楚這題的核心概念與實作步驟。
>
>---
>
>## ✅ 題目目標
>
>給定一棵**沒有重複值**的二元樹的：
>
>* **中序遍歷 (inorder)**
>* **後序遍歷 (postorder)**
>
>請你還原出這棵二元樹。
>
>---
>
>## 🔍 基本概念
>
>### 1. 後序遍歷（Postorder）：
>
>```
>左子樹 ➜ 右子樹 ➜ 根節點
>```
>
>➡️ 所以 `postorder` 的**最後一個元素**就是 **root**。
>
>### 2. 中序遍歷（Inorder）：
>
>```
>左子樹 ➜ 根節點 ➜ 右子樹
>```
>
>➡️ 找到 root 在 `inorder` 的位置，可以劃分出：
>
>* root 左邊：左子樹
>* root 右邊：右子樹
>
>---
>
>## 🧠 解題思路
>
>### Step 1️⃣：建立 `inorder` 索引對照表
>
>```cpp
>unordered_map<int, int> inorderIndexMap;
>for (int i = 0; i < inorder.size(); ++i)
>    inorderIndexMap[inorder[i]] = i;
>```
>
>🔧 作用：快速查詢某個值在 inorder 中的位置，**O(1)** 查表
>
>---
>
>### Step 2️⃣：定義遞迴建樹函式
>
>假設函式為：
>
>```cpp
>TreeNode* build(inL, inR, postL, postR)
>```
>
>傳入的是當前遞迴區間的：
>
>* `inorder[inL ~ inR]`
>* `postorder[postL ~ postR]`
>
>---
>
>### Step 3️⃣：遞迴邏輯
>
>1. **Base case**：
>   如果 `inL > inR` 或 `postL > postR`，表示子樹為空，回傳 `nullptr`
>
>2. **取得根節點值與位置**：
>
>   ```cpp
>   int rootVal = postorder[postR];
>   TreeNode* root = new TreeNode(rootVal);
>   int rootIndex = inorderIndexMap[rootVal];
>   ```
>
>3. **計算左右子樹大小**：
>
>   ```cpp
>   int leftSize = rootIndex - inL;
>   int rightSize = inR - rootIndex;
>   ```
>
>4. **遞迴建構左右子樹（注意順序）**：
>
>   ```cpp
>   root->right = build(rootIndex + 1, inR,
>                       postR - rightSize, postR - 1);
>
>   root->left  = build(inL, rootIndex - 1,
>                       postL, postR - rightSize - 1);
>   ```
>
>➡️ 為什麼先建「右子樹」？
>
>* 因為 postorder 的 root 是最後一個
>* 所以往回推時，右子樹會先出現（**右 ➜ 左 ➜ 根**）
>
>---
>
>## ✅ 時間與空間複雜度
>
>| 項目 | 複雜度                       |
>| -- | ------------------------- |
>| 時間 | `O(n)`，每個節點處理一次           |
>| 空間 | `O(n)`，HashMap + 遞迴 stack |
>
>---
>
>## 🧪 驗證方式
>
>可以用中序或前序遍歷的方式印出來，比對是否與原本資料一致，或用 LeetCode 提供的 Tree Visualizer 驗證。
>
>---
>
>## 🎯 小技巧補充
>
>* 中序 + 後序 ➜ 建樹：**先右後左**
>* 中序 + 前序 ➜ 建樹：**先左後右**
>* 建立 map 時建 `inorder` 的比較有用，**不要弄錯用 postorder 來查 index！**
>

>



```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    unordered_map<int, int> uom_inorderValueIndex; // <nodeVal, index>
    TreeNode* buildTreeRecursive(const vector<int>& inorder, int inorderLeftIndex, int inorderRightIndex, const vector<int>&postorder, int postorderLeftIndex, int postorderRightIndex){
        if(postorderRightIndex < postorderLeftIndex) return NULL;
        int rootVal = postorder[postorderRightIndex];
        printf("Root Value: %d\n", rootVal);
        TreeNode* rootNode = new TreeNode(rootVal);
        int rootIndexInInorder = uom_inorderValueIndex[rootVal];
        printf("Root Index in Inorder: %d\n", rootIndexInInorder);
        // 計算右子樹大小
        int rightSubTreeSize = inorderRightIndex - rootIndexInInorder;
        printf("Right Sub Tree Size: %d\n", rightSubTreeSize);
        // 建立右子樹
        rootNode -> right = buildTreeRecursive(inorder, rootIndexInInorder + 1, inorderRightIndex, postorder, postorderRightIndex - rightSubTreeSize, postorderRightIndex - 1);
        // 建立左子樹
        rootNode -> left = buildTreeRecursive(inorder, inorderLeftIndex, rootIndexInInorder - 1, postorder, postorderLeftIndex, postorderRightIndex - rightSubTreeSize - 1);

        return rootNode;
    }
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        /*
         * postorder的最後一個元素是root node
         * 應該要從右子樹開始建，因為postorder的最後一個元素可以當作root
         */
         for(int i = 0 ; i < inorder.size() ; i++){
            uom_inorderValueIndex[inorder[i]] = i;
         }
         return buildTreeRecursive(inorder, 0, inorder.size() - 1, postorder, 0, postorder.size() - 1);
    }
};
```
