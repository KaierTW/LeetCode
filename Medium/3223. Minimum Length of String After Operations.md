# 3223. Minimum Length of String After Operations
Problem : [HERE](https://leetcode.com/problems/minimum-length-of-string-after-operations/description/)

>[!TIP]
>如果字母出現偶數次，最後一定會剩下兩個字母，因為要刪掉左右兩邊一樣的，所以偶數次一定會剩兩個
>
>如果字母出現奇數次，最後一定會剩下一個字母，因為要刪掉左右兩邊一樣的，所以奇數次一定會剩一個

```CPP
class Solution {
public:
    int minimumLength(string s) {
        vector<int> charFreq(26, 0);
        int ans = 0;
        for(char sc : s){
            charFreq[sc - 'a']++;
        }
        for(int freq : charFreq){
            if(freq == 0) continue;
            // 如果字母出現偶數次，最後一定會剩下兩個字母，因為要刪掉左右兩邊一樣的，所以偶數次一定會剩兩個
            else if(freq % 2 == 0) ans += 2;
            // 如果字母出現奇數次，最後一定會剩下一個字母，因為要刪掉左右兩邊一樣的，所以奇數次一定會剩一個
            else ans += 1;
        }
        return ans;
    }
};
```
