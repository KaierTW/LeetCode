# 36. Valid Sudoku
Problem: [HERE](https://leetcode.com/problems/valid-sudoku/description/)

>[!TIP]
>解題思路如下：
>
>1. **初始化數據結構**：
>   - 使用三個集合來記錄每一行、每一列和每一個3x3小格子中已經出現的數字。
>   - 每個集合都包含9個子集合，分別對應9行、9列和9個小格子。
>
>2. **遍歷棋盤**：
>   - 使用兩個嵌套循環遍歷棋盤的每一個格子。
>   - 如果格子中有數字（不是'.'），檢查該數字是否已經在相應的行、列或小格子中出現過。
>   - 如果出現過，則返回`False`，表示棋盤無效。
>   - 如果沒有出現過，則將該數字加入相應的行、列和小格子的集合中。
>
>3. **檢查完所有格子**：
>   - 如果所有格子都符合規則，則返回`True`，表示棋盤有效 [1](https://algo.monster/liteproblems/36) [2](https://walkccc.me/LeetCode/problems/36/) [3](https://www.sparkcodehub.com/leetcode/36/valid-sudoku).
>
>這種方法的時間複雜度是O(1)，因為棋盤大小固定為9x9，遍歷所有格子所需的時間是常數時間 [2](https://walkccc.me/LeetCode/problems/36/) [3](https://www.sparkcodehub.com/leetcode/36/valid-sudoku).
>

```CPP
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        int n = board.size();
        unordered_map<int, vector<int>>uom_RowShowNum;
        unordered_map<int, vector<int>>uom_ColumnShowNum;
        unordered_map<int, vector<int>>uom_BoxShowNum;
        for(int row = 0 ; row < n ; row++) {
            for(int column = 0 ; column < n ; column++){
                if(board[row][column] != '.') {
                    int target = board[row][column];                     
                    // Check target in the row;
                    vector<int> v_RowShowNum = uom_RowShowNum[row];
                    auto it = find(v_RowShowNum.begin(), v_RowShowNum.end(), target);
                    if(it == v_RowShowNum.end()) { // Not found;
                        v_RowShowNum.push_back(target);
                        uom_RowShowNum[row] = v_RowShowNum;
                    }
                    else return false;

                    // Check target in the column
                    vector<int> v_ColumnShowNum = uom_ColumnShowNum[column];
                    it = find(v_ColumnShowNum.begin(), v_ColumnShowNum.end(), target);
                    if(it == v_ColumnShowNum.end()) { // Not found;
                        v_ColumnShowNum.push_back(target);
                        uom_ColumnShowNum[column] = v_ColumnShowNum;
                    }
                    else return false;

                    /* Check target in the box
                     * Box: 
                     * 0    1    2
                     * 3    4    5
                     * 6    7    8
                    */
                    int checkBoxRow = row / 3;
                    int checkBoxColumn = column / 3;
                    int box = checkBoxRow * 3 + checkBoxColumn;
                    vector<int> v_BoxShowNum = uom_BoxShowNum[box];
                    it = find(v_BoxShowNum.begin(), v_BoxShowNum.end(), target);
                    if(it == v_BoxShowNum.end()) { // Not found;
                        v_BoxShowNum.push_back(target);
                        uom_BoxShowNum[box] = v_BoxShowNum;
                    }
                    else return false;
                }
                else continue;
            }
        }
        return true;
    }
};
```
