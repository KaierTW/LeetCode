# 2349. Design a Number Container System

>當然可以！以下是解決「Design a Number Container System」這題目的詳細解題思路：
>
>### 1. 問題概述
>你需要設計一個數字容器系統，該系統可以執行以下操作：
>- **插入或替換數字**：在系統中給定的索引位置插入或替換一個數字。
>- **查找數字的最小索引**：返回系統中給定數字的最小索引，如果沒有該數字則返回 -1。
>
>### 2. 解題思路
>
>要實現這個系統，我們可以使用兩個哈希表來管理數字和索引之間的關係：
>1. **indexToNumber**：這個哈希表用來存儲每個索引對應的數字。
>2. **numberToIndices**：這個哈希表用來存儲每個數字對應的索引集合（使用有序集合，如 `set`）。
>
>### 3. 方法實現
>
>#### 方法1：初始化
>初始化方法 `NumberContainers()`：
>- 這個方法不需要執行任何操作，只是初始化對象。
>
>#### 方法2：插入或替換數字
>方法 `void change(int index, int number)`：
>- 如果該索引已經有數字，先從 `numberToIndices` 中移除該數字對應的索引。
>- 更新 `indexToNumber` 中該索引的新數字。
>- 將新數字對應的索引添加到 `numberToIndices` 中。
>
>#### 方法3：查找數字的最小索引
>方法 `int find(int number)`：
>- 如果 `numberToIndices` 中存在該數字，返回存儲索引的集合中的最小值。
>- 如果不存在該數字，返回 -1。
>
>### 4. 解釋
>
>- **初始化**：構造函數不執行任何操作。
>- **插入或替換數字**：
>  - 檢查 `indexToNumber` 中是否存在該索引，如果存在則從 `numberToIndices` 中移除舊數字對應的索引。
>  - 更新 `indexToNumber` 中的新數字。
>  - 將新數字對應的索引添加到 `numberToIndices` 中。
>- **查找最小索引**：
>  - 檢查 `numberToIndices` 中是否存在該數字，如果存在則返回集合中的第一個元素（即最小索引）。
>  - 如果不存在該數字，則返回 -1。
>

```CPP
class NumberContainers {
private:
    unordered_map<int, int> indexToNumber;
    unordered_map<int, set<int>> numberToIndex;
public:
    //構造函數
    NumberContainers() {
        
    }
    
    void change(int index, int number) {
        // 如果已經存在的數字要替換
        if(indexToNumber.find(index) != indexToNumber.end()){
            // 找到當前index先前對應的number
            int previousNumber = indexToNumber[index];
            // 從set裡面移除先前對應的number的index
            numberToIndex[previousNumber].erase(index);
            // 檢查set裡面還有沒有元素，沒有的話移除map
            if(numberToIndex[previousNumber].empty()){
                numberToIndex.erase(previousNumber);
            }
        }
        // 加入新的numner
        indexToNumber[index] = number;
        // 加入set
        numberToIndex[number].insert(index);
    }
    
    int find(int number) {
        if(numberToIndex.find(number) != numberToIndex.end()){
            return *numberToIndex[number].begin();
        }
        else return -1;
    }
};

/**
 * Your NumberContainers object will be instantiated and called as such:
 * NumberContainers* obj = new NumberContainers();
 * obj->change(index,number);
 * int param_2 = obj->find(number);
 */
```
