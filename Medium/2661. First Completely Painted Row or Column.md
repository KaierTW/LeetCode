# 2661. First Completely Painted Row or Column
Problem : [HERE](https://leetcode.com/problems/first-completely-painted-row-or-column/description/)

>[!TIP]
>### 解題思路詳細步驟
>
>1. **預處理位置**：
>   - 我們需要快速找到每個數字在矩陣中的位置。為此，我們可以使用一個哈希表（字典）來存儲每個數字的位置。
>   - 例如，對於矩陣 `mat = [[1, 4], [2, 3]]`，我們可以建立一個哈希表 `pos`，使得 `pos[1] = (0, 0)`，`pos[2] = (1, 0)`，`pos[3] = (1, 1)`，`pos[4] = (0, 1)`。
>
>2. **計數行和列**：
>   - 我們需要兩個數組來計數每行和每列被塗滿的單元格數量。假設矩陣有 `m` 行和 `n` 列，我們可以初始化兩個數組 `row_count` 和 `col_count`，分別用來計數每行和每列被塗滿的單元格數量。
>   - 例如，對於一個 2x2 的矩陣，我們可以初始化 `row_count = [0, 0]` 和 `col_count = [0, 0]`。
>
>3. **遍歷數組**：
>   - 我們遍歷 `arr`，每次找到對應的矩陣位置，並更新行和列的計數。
>   - 具體來說，對於 `arr` 中的每個數字，我們使用哈希表 `pos` 找到它在矩陣中的位置 `(r, c)`，然後將 `row_count[r]` 和 `col_count[c]` 分別加 1。
>   - 如果某一行的計數達到矩陣的列數（即 `row_count[r] == n`），或者某一列的計數達到矩陣的行數（即 `col_count[c] == m`），則返回當前索引 `i`。
>
>### 具體步驟解釋
>1. **初始化**：
>   - `m` 和 `n` 分別是矩陣的行數和列數。
>   - `row_count` 和 `col_count` 初始化為全零的數組，用來計數每行和每列被塗滿的單元格數量。
>   - `pos` 是一個哈希表，用來存儲每個數字在矩陣中的位置。
>
>2. **遍歷 `arr`**：
>   - 使用 `enumerate` 遍歷 `arr`，同時獲取數字 `num` 和索引 `i`。
>   - 使用 `pos` 找到數字 `num` 在矩陣中的位置 `(r, c)`。
>   - 更新 `row_count[r]` 和 `col_count[c]`。
>   - 檢查是否有某一行或某一列被完全塗滿，如果是，則返回當前索引 `i`。
>


```CPP
class Solution {
public:
    int firstCompleteIndex(vector<int>& arr, vector<vector<int>>& mat) {
        int row = mat.size(), column = mat[0].size();
        unordered_map<int, pair<int, int>> position;
        vector<int> rowCount(row, 0), columnCount(column, 0);
        for(int i = 0 ; i < row ; i++){
            for(int j = 0 ; j < column ; j++){
                position[mat[i][j]] = {i, j};
            }
        }
        for(int i = 0 ; i < arr.size() ; i++){
            auto [r, c] = position[arr[i]];
            if(++rowCount[r] == column || ++columnCount[c] == row) return i;
        }
    return -1;
    }
};
```
