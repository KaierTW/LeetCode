# 2028. Find Missing Observations
Problem : [HERE](https://leetcode.com/problems/find-missing-observations/description/)

>[!TIP]
>題目的意思是說總共骰了m+n次，然後他給你前面m次的點數跟總共骰m+n次的平均
>
>所以變數就先設定m、骰了m次的總和、骰了m+n次的總和
>
>用m+n次的總和減掉m次的總和就是n的總和
>
>要判斷n的總和有沒有超過6*n，因為不會骰出比6還大的
>
>又或是有沒有小於n，因為每次最小都是1
>
>然後用除法，記錄商數和餘數
>
>然後再把餘數分配

```CPP
class Solution {
public:
    vector<int> missingRolls(vector<int>& rolls, int mean, int n) {
        int m = rolls.size();
        int rollsSum = accumulate(rolls.begin() , rolls.end() , 0);
        int finalTotal = mean * (n + m);
        int missingTotal = finalTotal - rollsSum;
        if(missingTotal > 6 * n || missingTotal < n) return {};
        else{
            auto [q ,r] = div(missingTotal , n);
            vector<int> ans(n , q);
            fill(ans.begin() , ans.begin() + r , q + 1);
            return ans;
        }
    }
};
```
