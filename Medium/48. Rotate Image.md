# 48. Rotate Image
Problem : [HERE](https://leetcode.com/problems/rotate-image/description/)

>[!TIP]
>**48. Rotate Image** 是 LeetCode 上的一道中等難度題目。這題要求你將一個 n x n 的 2D 矩陣順時針旋轉 90 度，並且必須在原地進行旋轉，不允許使用額外的矩陣來完成旋轉。
>
>解題思路主要有兩種：
>
>1. **直接交換法**：
>   - 將矩陣分成四個部分，然後逐個交換每個部分的元素位置。
>   - 具體步驟是：將矩陣分成四個部分，然後逐個交換每個部分的元素位置。
>   - 時間複雜度為 $$O(N^2)$$，空間複雜度為 $$O(1)$$ [1](https://bclin.tw/2021/08/24/leetcode-48/)。
>
>2. **轉置加反轉法**：
>   - 先將矩陣轉置（即行列互換），然後反轉每一行。
>   - 這樣就可以達到旋轉 90 度的效果。
>   - 時間複雜度為 $$O(N^2)$$，空間複雜度為 $$O(1)$$ [1](https://bclin.tw/2021/08/24/leetcode-48/) [2](https://leetcode.com/problems/rotate-image/)。
>
>這兩種方法都能有效地解決問題，具體選擇哪種方法可以根據個人喜好和理解來決定。

## 2. **轉置加反轉法**
```CPP
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int row = matrix.size(), column = matrix[0].size();
        int top = 0, button = matrix.size() - 1;
        // Vertical Reversal
        while(top < button){
            for(int i = 0 ; i < column ; i++){
                int topTemp = matrix[top][i];
                int buttonTemp = matrix[button][i];
                matrix[top][i] = buttonTemp;
                matrix[button][i] = topTemp;
            }
            top++;
            button--;
        }

        // Transpose
        for(int r = 0 ; r < row ; r++){
            for(int c = r + 1 ; c < column ; c++){
                int rightTemp = matrix[r][c];
                matrix[r][c] = matrix[c][r];
                matrix[c][r] = rightTemp;
            }
        }
    }
};
```
