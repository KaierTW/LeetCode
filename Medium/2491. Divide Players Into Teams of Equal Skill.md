# 2491. Divide Players Into Teams of Equal Skill
Problem : [HERE](https://leetcode.com/problems/divide-players-into-teams-of-equal-skill/description/)

>[!TIP]
>LeetCode 2491 題目 "Divide Players Into Teams of Equal Skill" 要求將玩家分成隊伍，並確保每隊的技能總和相等。我們需要找出能夠分隊的情況下，所有隊伍的配對技能乘積的總和。如果無法將所有玩家分成技能總和相等的隊伍，則返回 -1。
>
>### 題目理解
>- 每個玩家有一個技能值，這些技能值存儲在 `skills` 數組中。
>- 我們需要將玩家分成若干個兩人一組的隊伍，並且每隊兩個人的技能值之和相同。
>- 如果能夠分成這樣的隊伍，我們還需要計算這些隊伍中技能乘積的總和。
>- 如果無法分隊，我們返回 `-1`。
>
>### 解題思路
>1. **總技能總和檢查**：
>   - 我們可以首先計算玩家的技能總和 `totalSum`，因為我們需要將所有玩家分成兩人一組，總共有 `n / 2` 個隊伍。
>   - 每一隊的技能和應該是 `targetSum = totalSum / (n / 2)`。
>   - 如果 `totalSum` 無法被 `n / 2` 整除，則無法達成要求，直接返回 `-1`。
>
>2. **貪心配對策略**：
>   - 我們可以將玩家的技能值排序，然後配對技能最低的玩家和技能最高的玩家。
>   - 因為配對後的技能值應該相等，這樣從排序後的兩端來進行配對最有可能讓技能和相等。
>   - 如果發現任何配對的技能和不等於 `targetSum`，則無法達成要求，返回 `-1`。
>   
>3. **計算配對乘積的總和**：
>   - 對於每一對符合條件的玩家，我們計算其技能值乘積，並累加起來。
>
>### 具體步驟
>1. 將 `skills` 排序。
>2. 逐步從最小的技能值和最大的技能值進行配對，檢查每對的技能和是否等於 `targetSum`。
>3. 計算技能乘積並累加。
>4. 返回乘積總和。
>
>
>### 解析
>1. **排序**：`sort(skill.begin(), skill.end());` 會把技能數組按從小到大的順序排列，這樣可以方便我們配對技能最小和最大的玩家。
>2. **檢查配對和**：我們選取數組的首尾兩個元素進行配對（`skill[i] + skill[n - 1 - i]`），並檢查其技能和是否等於 `targetSum`。
>3. **累加乘積**：如果配對成功，計算該配對的技能乘積，並加到 `totalProductSum`。
>4. **早期退出**：如果有任何配對的技能和不等於 `targetSum`，我們立刻返回 `-1`，無需繼續計算。
>
>### 時間複雜度
>- **排序**的時間複雜度是 `O(n log n)`，其中 `n` 是技能數組的長度。
>- **配對檢查**的時間複雜度是 `O(n)`，因為我們只需要線性遍歷已排序的數組。
>- 整體的時間複雜度為 `O(n log n)`。
>
>### 空間複雜度
>- 使用了 `sort` 進行排序，並且只使用了常數級別的額外變量，因此空間複雜度是 `O(1)`（不考慮輸入數組）。
>

``CPP
class Solution {
public:
    long long dividePlayers(vector<int>& skill) {
        sort(skill.begin() , skill.end());
        
        int len = skill.size();
        int sum = skill[0] + skill[len - 1];
        long long ans = skill[0] * skill[len - 1];

        for(int i = 1 ; i < len / 2 ; i++){
            if(skill[i] + skill[len - 1 - i] != sum) return -1;
            else{
                ans += (skill[i] * skill[len - 1 - i]);
            }
        }
        return ans;
    }
};
```
