# 80. Remove Duplicates from Sorted Array II
Problem : [HERE](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/description/)

>[!TIP]
>這題的解題思路主要是利用雙指針技術來在原地修改數組，確保每個元素最多出現兩次。以下是詳細的解題步驟：
>
>1. **初始化指針**：我們使用一個指針 `i` 來追踪新數組的長度。初始時，`i` 設為 `0`。
>
>2. **遍歷數組**：使用 `for` 循環遍歷數組中的每個元素 `num`。
>
>3. **判斷條件**：
>   - 如果 `i` 小於 `2`，這意味著我們還在處理數組的前兩個元素，直接將 `num` 放入新數組。
>   - 如果 `num` 大於 `nums[i - 2]`，這意味著當前元素 `num` 不會造成超過兩次的重複，將其放入新數組。
>
>4. **更新指針**：每次符合條件時，將 `num` 放入新數組並更新指針 `i`。
>
>5. **返回結果**：最後，返回指針 `i` 作為新數組的長度。
>
>這樣的解法不需要額外的空間，並且能夠在原地完成數組的修改。


```CPP
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int i = 0;
        for (const int num : nums) {
            if (i < 2 || num > nums[i - 2]) {
                nums[i++] = num;
            }
        }
        return i;
    }
};
```


```CPP
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        unordered_map<int, int> uom;
        int index = 0;
        for(int i = 0 ; i < nums.size() ; i++){
            if(uom[nums[i]] < 2){
                nums[index++] = nums[i];
                uom[nums[i]]++;
            }
        }
        return index;
    }
};
```
