>## 🧩 你問的問題整理
>
>### 1. `BSTIterator(TreeNode* root)` 是什麼？
>- 這是 **建構子（Constructor）**，不是 `void` 函數。
>- 它的作用是初始化 `BSTIterator` 物件，並準備好中序遍歷的起點。
>- 建構子名稱與類別名稱相同，沒有回傳值。
>
>---
>
>### 2. 為什麼一開始要把左子樹壓入 stack？
>- 因為中序遍歷的順序是：**左 → 根 → 右**。
>- 所以我們要先走到最左邊的節點（也就是最小值），才能開始正確地遍歷。
>- 用 stack 模擬遞迴的行為，記住還沒處理的節點。
>
>---
>
>### 3. 為什麼是在 `next()` 的時候才壓右子樹？
>- 因為中序遍歷在處理完「根節點」後，才會處理「右子樹」。
>- 所以當我們在 `next()` 中 pop 出一個節點後，才去壓入它的右子樹（從右子樹一路往左壓入）。
>- 這樣可以確保每次 `next()` 都回傳「下一個最小值」。
>
>---
>
>## 🧠 LeetCode 173 題解題思路整理
>
>### 題目要求：
>實作一個 `BSTIterator` 類別，支援以下操作：
>- `BSTIterator(TreeNode* root)`：初始化迭代器。
>- `int next()`：回傳下一個最小的節點值。
>- `bool hasNext()`：判斷是否還有下一個節點。
>
>---
>
>### 解法核心：用 stack 模擬中序遍歷
>
>```cpp
>class BSTIterator {
>private:
>    stack<TreeNode*> stk;
>
>    void pushLeft(TreeNode* node) {
>        while (node) {
>            stk.push(node);
>            node = node->left;
>        }
>    }
>
>public:
>    BSTIterator(TreeNode* root) {
>        pushLeft(root);
>    }
>
>    int next() {
>        TreeNode* node = stk.top();
>        stk.pop();
>        pushLeft(node->right);
>        return node->val;
>    }
>
>    bool hasNext() {
>        return !stk.empty();
>    }
>};
>```
>
>---
>
>### 使用流程（以 BST 範例說明）：
>
>假設 BST 如下：
>```
>      7
>     / \
>    3   15
>       /  \
>      9   20
>```
>
>1. 建構子呼叫 `pushLeft(7)` → stack: `[7, 3]`
>2. `next()` → pop 3 → 回傳 3 → 沒有右子樹
>3. `next()` → pop 7 → 回傳 7 → pushLeft(15) → stack: `[15, 9]`
>4. `next()` → pop 9 → 回傳 9
>5. `next()` → pop 15 → 回傳 15 → pushLeft(20)
>6. `next()` → pop 20 → 回傳 20
>
>---
>
>這樣的設計讓你可以用迭代器的方式，**逐步取得 BST 中的節點值，順序正確又有效率**。
>
>

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class BSTIterator {
public:
    stack<TreeNode*> stk;
    void pushLeft(TreeNode* node){
        // 將左子樹一路壓入堆疊
        while(node){
            stk.push(node);
            node = node -> left;
        }
    }
    // 建構子：初始化堆疊
    BSTIterator(TreeNode* root) {
        pushLeft(root);
    }
    // 回傳下一個最小的值
    int next() {
        TreeNode* node = stk.top();
        stk.pop();
        pushLeft(node -> right);
        return node -> val;
    }
    // 判斷是否還有下一個節點
    bool hasNext() {
        return !stk.empty();
    }
};

/**
 * Your BSTIterator object will be instantiated and called as such:
 * BSTIterator* obj = new BSTIterator(root);
 * int param_1 = obj->next();
 * bool param_2 = obj->hasNext();
 */
```
