# 731. My Calendar II
Problem : [HERE](https://leetcode.com/problems/my-calendar-ii/description/)

>[!TIP]
>
>具體要求：
>1. `book(start, end)` 是預定一個時間段 [start, end)，但是每個時間段不能出現**三重預訂**。
>2. 可以允許雙重預訂，但如果某一段時間會導致三重預訂，那麼這個預定應該被拒絕。
>
>### 解題思路
>
>我們需要追蹤哪些時間段已經有了**單次預訂**以及**雙次預訂**。當我們嘗試進行預訂時，我們會檢查這個新的時間段是否會造成三重預訂。
>
>具體步驟：
>1. 用一個列表 `bookings` 來保存已經確認的預訂。
>2. 用另一個列表 `overlaps` 來保存雙次重疊的時間段（即每個已經發生雙重預訂的時間段）。
>3. 當進行一個新的預訂時：
>   - 首先檢查這個時間段與 `overlaps` 列表中的時間段是否有重疊。如果有重疊，則拒絕這個預訂（因為這會導致三重預訂）。
>   - 然後檢查與 `bookings` 列表中的預訂是否有重疊。如果有重疊，則將這個重疊部分加入 `overlaps` 列表。
>   - 最後，將這個新的預訂加入 `bookings` 列表。
>
>### 解題關鍵：
>1. **重疊檢查**：使用 `max(start, s)` 和 `min(end, e)` 來判斷兩個區間是否有重疊。如果 `max(start, s) < min(end, e)`，則表示有重疊。
>2. **避免三重預訂**：當我們發現新預訂與某個雙重預訂重疊時，就應立即拒絕這次預訂，因為這會導致三重預訂。
>
>### 時間複雜度：
>- 每次調用 `book` 時，必須遍歷已經存在的預訂和雙重預訂。假設我們已經進行了 `n` 次預訂，則每次的時間複雜度為 O(n)，所以整體的時間複雜度是 O(n^2)。
>
>這樣的解法能夠有效地解決問題，並且在 LeetCode 的測試中能夠通過大多數情況下的測試。
>
>當你解決 LeetCode 731 題 "My Calendar II" 時，目的是讓日曆允許雙重預訂，但不能允許三重預訂。為此，我們需要一個策略來追蹤每次預訂的重疊情況，並在重疊超過兩次時拒絕新預訂。讓我逐步解釋該解法的原理。
>
>### 核心思想
>
>- **單次預訂**：可以在一個時間段內預訂兩次（即雙重預訂），這是允許的。
>- **雙重預訂**：當某兩個預訂重疊時，我們需要記錄這個重疊區間，並存儲起來。
>- **三重預訂**：如果新的一次預訂與某個**雙重預訂**的區間有重疊，那麼這次預訂將會導致三重預訂，因此我們必須拒絕這個預訂。
>
>### 解法步驟
>
>1. **使用兩個列表**：
>   - `bookings`：用來保存所有成功的**單次預訂**。
>   - `overlaps`：用來保存所有已經確認的**雙重預訂**區間。
>
>2. **檢查三重預訂**：
>   - 當我們嘗試進行新的預訂時，我們首先要檢查它是否會和 `overlaps` 中的任意區間重疊。如果發生重疊，這意味著這次預訂會導致三重預訂，應該直接拒絕。
>
>3. **更新雙重預訂**：
>   - 如果新的預訂通過了「三重預訂檢查」，我們接著會檢查這次預訂與 `bookings` 中的預訂是否有重疊。
>   - 對於每次重疊，我們計算這個重疊區間，並將它存入 `overlaps`，因為這表示某兩個預訂之間已經有雙重預訂。
>
>4. **保存新預訂**：
>   - 如果新的預訂沒有引發三重預訂，那麼我們將這次預訂存入 `bookings`，表示這次預訂成功。
>


```CPP
class MyCalendarTwo {
public:
    vector<pair<int , int>> bookings;
    vector<pair<int , int>> doublebookings;

    MyCalendarTwo() {
        
    }
    
    bool book(int start, int end) {
        for(auto doublebooking : doublebookings){
            int start_doublebooking = doublebooking.first;
            int end_doublebooking = doublebooking.second;
            if(max(start , start_doublebooking) < min(end , end_doublebooking)){
                return false;
            }
        }
        
        for(auto booking : bookings){
            int start_booking = booking.first;
            int end_booking = booking.second;
            if(max(start , start_booking) < min(end , end_booking)){
                doublebookings.push_back({max(start , start_booking) , min(end , end_booking)});                
            }            
        }
        bookings.push_back({start , end});
        return true;
    }
};

/**
 * Your MyCalendarTwo object will be instantiated and called as such:
 * MyCalendarTwo* obj = new MyCalendarTwo();
 * bool param_1 = obj->book(start,end);
 */
```
