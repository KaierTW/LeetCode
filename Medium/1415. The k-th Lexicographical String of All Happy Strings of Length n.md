# 1415. The k-th Lexicographical String of All Happy Strings of Length n
Problem : [HERE](https://leetcode.com/problems/the-k-th-lexicographical-string-of-all-happy-strings-of-length-n/description/)

>[!TIP]
>我們可以使用回溯法來生成所有的 Happy Strings，然後按字典順序排序並找到第 k 個。
>這段代碼的主要步驟如下：
>1. 使用 `generateHappyStrings` 函數來生成所有長度為 n 的 Happy Strings。
>2. 使用回溯法確保生成的字符串符合 Happy String 的定義。
>3. 將生成的字符串存儲在 `result` 向量中，並按字典順序排序。
>4. 返回排序後的第 k 個字符串，如果 k 超過了字符串的數量，則返回空字符串。
>

```CPP
class Solution {
public:    
    void generateHappyString(int n, string& current, vector<string>& result){
        if(current.size() == n){
            result.push_back(current);
            return;
        }
        for(char c : {'a', 'b', 'c'}){
            if(current.empty() || current.back() != c){
                current.push_back(c);
                generateHappyString(n, current, result);
                current.pop_back();
            }            
        }
    }

    string getHappyString(int n, int k) {
        vector<string> result;
        string current;
        generateHappyString(n, current, result);
        if(k > result.size()) return "";
        else return result[k - 1];
    }
};
```
