# 61. Rotate List
Problem : [HERE](https://leetcode.com/problems/rotate-list/description/)

>[!TIP]
>LeetCode 第 61 題「Rotate List」的解題思路主要是針對 **單向鏈結串列（singly linked list）**進行旋轉操作。題目要求將鏈結串列向右旋轉 `k` 次。
>
>---
>
>### 🧠 解題思路
>
>假設我們有一個鏈結串列 `1 -> 2 -> 3 -> 4 -> 5`，若 `k = 2`，旋轉後應該變成 `4 -> 5 -> 1 -> 2 -> 3`。
>
>---
>
>### ✅ 步驟解析
>
>1. **計算鏈結串列長度**：
>   - 因為旋轉次數可能大於鏈結串列長度，所以需要先計算長度 `n`。
>
>2. **取模簡化旋轉次數**：
>   - `k = k % n`，這樣可以避免重複旋轉。
>
>3. **找到新的尾節點**：
>   - 新的尾節點是第 `n - k` 個節點。
>   - 新的頭節點是 `n - k + 1` 個節點。
>
>4. **斷開並重接鏈結串列**：
>   - 將新的尾節點的 `next` 設為 `null`。
>   - 原本的尾節點接到原本的頭節點上。
>
>---


```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if(head == NULL) return NULL;
        // STEP 1. 計算長度跟記錄最後一個節點
        int listNum = 0;
        ListNode* endNode;
        ListNode* temp = head;        
        while(temp){
            listNum++;     
            if(temp -> next == NULL) endNode = temp;
            temp = temp -> next;
        }

        // STEP 2. 計算轉幾次
        int rotateTime = k % listNum;
        if(rotateTime == 0) return head;

        // STEP 3. 找到新的頭跟尾        
        int newEnd = listNum - rotateTime - 1;
        int countTime = 0;
        temp = head;
        for(int i = 0 ; i < newEnd ; i++){
            temp = temp -> next;
        }
        ListNode* newHeadNode = temp -> next;
        ListNode* newEndNode = temp;
        newEndNode -> next = NULL;
        endNode -> next = head;
        return newHeadNode;

    }
};
```
