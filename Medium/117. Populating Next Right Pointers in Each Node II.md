>## 🔵 題目再複習一次
>
>### 題目名稱：
>
>**117. Populating Next Right Pointers in Each Node II**
>
>### 題目重點：
>
>* 任意形狀的二叉樹（**不是 perfect binary tree**）
>* 每一層的節點，要從左到右，用 `next` 指向它右邊的節點
>* 最右邊的節點 `next = nullptr`
>
>### 結構：
>
>```cpp
>struct Node {
>    int val;
>    Node* left;
>    Node* right;
>    Node* next;
>};
>```
>
>---
>
># ✅ 解法一：使用 Queue 做 BFS（層序遍歷）
>
>### ✅ 思路圖解：
>
>用 queue 進行 BFS，一層一層處理，類似這樣的過程：
>
>```
>Level 0:          1          => [1]
>Level 1:        /   \        => [2, 3]
>               2     3
>Level 2:      / \     \      => [4, 5, 7]
>             4   5     7
>
>結果應是：
>4->5->7->null
>2->3->null
>1->null
>```
>
>### ✅ 實作程式碼：
>
>```cpp
>#include <queue>
>
>class Solution {
>public:
>    Node* connect(Node* root) {
>        if (!root) return nullptr;
>
>        std::queue<Node*> q;
>        q.push(root);
>
>        while (!q.empty()) {
>            int size = q.size();
>            Node* prev = nullptr;
>
>            for (int i = 0; i < size; ++i) {
>                Node* curr = q.front(); q.pop();
>
>                // 前一個節點接到目前節點
>                if (prev)
>                    prev->next = curr;
>                prev = curr;
>
>                // 加入左右子節點到 queue 中
>                if (curr->left)
>                    q.push(curr->left);
>                if (curr->right)
>                    q.push(curr->right);
>            }
>            // 最右邊的節點 next 會自然留成 null
>        }
>
>        return root;
>    }
>};
>```
>
>---
>
>### ✅ 每段說明：
>
>* `queue<Node*> q;`：存放每層的節點
>* `while (!q.empty())`：代表還有下一層
>* `int size = q.size();`：記錄這一層有幾個節點（一次處理整層）
>* `prev->next = curr;`：把前一個節點的 `next` 指到現在的節點
>* 加入左右子節點到 queue，是為了下一層
>
>---
>
>### ✅ 優點 / 缺點
>
>| 優點      | 缺點          |
>| ------- | ----------- |
>| 好理解、直觀  | 空間複雜度是 O(n) |
>| 適合練 BFS | 需要額外 queue  |
>

># ✅ 解法二：使用常數空間（最推薦 LeetCode 用法）
>
>### ✅ 思路圖解：
>
>這種方法不用 queue，而是利用「目前這層的 `next` 指標」來走訪，並且在過程中建立下一層的 `next`。
>
>舉例來說：
>
>```
>           1
>         /   \
>        2     3
>       / \     \
>      4   5     7
>```
>
>你會從 1 開始走，接著用 dummy 節點串起下一層：
>
>```
>dummy -> 2 -> 3
>dummy -> 4 -> 5 -> 7
>```
>
>---
>
>### ✅ 關鍵技巧
>
>* `dummy`: 一個假的節點，幫你連起下一層的頭
>* `prev`: 指向 dummy，用來連接下一層的節點
>* `curr`: 走訪目前這層，利用 `curr->next` 向右移動
>
>---
>
>### ✅ 實作程式碼：
>
>```cpp
>class Solution {
>public:
>    Node* connect(Node* root) {
>        if (!root) return nullptr;
>
>        Node* curr = root;  // 目前這層的開頭
>
>        while (curr) {
>            Node dummy(0);  // 虛擬節點，幫你串起下一層
>            Node* prev = &dummy;
>
>            while (curr) {
>                if (curr->left) {
>                    prev->next = curr->left;
>                    prev = prev->next;
>                }
>                if (curr->right) {
>                    prev->next = curr->right;
>                    prev = prev->next;
>                }
>
>                // 移動到右邊節點（同一層）
>                curr = curr->next;
>            }
>
>            // 移動到下一層的第一個節點
>            curr = dummy.next;
>        }
>
>        return root;
>    }
>};
>```
>
>---
>
>### ✅ 每段說明：
>
>* `Node dummy(0)`：我們會用這個節點串起下一層
>* `prev` 指向 dummy，幫你連 `prev->next = child`
>* `curr` 是目前這層的節點，用它走一整層
>* 最後 `curr = dummy.next;` 移到下一層開始
>
>---
>
>### ✅ 優點 / 缺點
>
>| 優點            | 缺點          |
>| ------------- | ----------- |
>| 空間複雜度 O(1)    | 稍難理解，指標操作多  |
>| 無需額外記憶體       | debug 時不易追蹤 |
>| LeetCode 面試常考 |             |
>
>---
>
>## 🟡 總結：什麼時候用哪個？
>
>| 你的目標               | 解法            |
>| ------------------ | ------------- |
>| 想要快速寫出來、容易理解       | BFS 用 `queue` |
>| 想優化空間、面試表現更進階      | 常數空間解法        |
>| 想理解 `next` 指標的連接邏輯 | 常數空間解法        |
>

```CPP
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* left;
    Node* right;
    Node* next;

    Node() : val(0), left(NULL), right(NULL), next(NULL) {}

    Node(int _val) : val(_val), left(NULL), right(NULL), next(NULL) {}

    Node(int _val, Node* _left, Node* _right, Node* _next)
        : val(_val), left(_left), right(_right), next(_next) {}
};
*/

class Solution {
public:
    Node* connect(Node* root) {
        if(root == NULL) return NULL;
        Node* currentNode = root; // 根節點
        while(currentNode){
            Node* virtualNode = new Node(); //虛擬節點，幫根節點串連到下一層
            Node* previousNode = virtualNode;
            while(currentNode){
                if(currentNode -> left){
                    previousNode -> next = currentNode -> left;
                    previousNode = previousNode -> next;
                }
                if(currentNode -> right){
                    previousNode -> next = currentNode -> right;
                    previousNode = previousNode -> next;
                }
                currentNode = currentNode -> next;
            }            
            currentNode = virtualNode -> next;
        }
        return root;
    }    
};
```
