# 2220. Minimum Bit Flips to Convert Number
Problem : [HERE](https://leetcode.com/problems/minimum-bit-flips-to-convert-number/description/)

>[!TIP]
>題目描述：
>
>給定兩個整數 start 和 goal，我們需要將 start 的二進制表示轉換成 goal 的二進制表示。每次操作可以選擇翻轉某個位元（0 變 1，或 1 變 0）。我們要計算出最少的翻轉次數。
>
>解題思路：
>
>XOR 運算：首先，考慮二進制數的性質，XOR (異或) 運算可以幫助我們找出兩個數字在每個位元上是否相同。當某個位元不同時，XOR 的結果在該位元上會是 1。
>
>因此，計算 start ^ goal 可以得到一個新的數字，這個數字的二進制表示中每個 1 代表 start 和 goal 的對應位不同，需要翻轉一次。
>
>計算 1 的個數：接下來，只需要計算 start ^ goal 結果中有多少個 1，這就代表需要翻轉的次數。
>
>Brian Kernighan's Algorithm
>
>這個演算法通過每次將 n & (n - 1) 清除掉數字中最右邊的 1，有效地計算出有多少個 1。這個方法非常高效，因為它只需要迴圈運行與 1 的個數相同的次數。
>


```CPP
class Solution {
public:
    int minBitFlips(int start, int goal) {
        int xorResult = start ^ goal;
        int count = 0;
        while (xorResult) {
            xorResult &= (xorResult - 1);  // 清除最右邊的 1
            count++;
        }
        return count;
    }
};
```

## Brian Kernighan's Algorithm

當我們使用 Brian Kernighan's Algorithm 時，會看到一個步驟是將 `n &= (n - 1)`，這個操作能夠「清除」數字中最右邊的一個 `1`。讓我們詳細解釋一下這個操作背後的原理。

## 原理
對於任意一個整數 `n`，`n - 1` 會將 `n` 的二進制表示中最右邊的 `1` 變為 `0`，並將該位右邊的所有位元變為 `1`。而當我們做 `n & (n - 1)` 的時候，這個操作會把 `n` 中最右邊的 `1` 清除掉。

### 具體步驟：

1. **`n - 1` 的效果**：
   當你對一個數 `n` 減 1 時，它會影響到 `n` 的二進制表示，從最右邊的 `1` 開始發生變化：
   - 最右邊的 `1` 變成 `0`。
   - 這個 `1` 右邊的所有位元（如果有的話）都會變成 `1`。
   - 左邊的位元保持不變。

2. **`n & (n - 1)` 的效果**：
   當你進行按位與運算 `n & (n - 1)` 時，所有左邊的位保持不變，只有最右邊的 `1` 被清除，因為這個位在 `n - 1` 時已經被變成 `0`，因此與運算結果是 `0`。

### 例子：

假設我們有一個數字 `n = 12`，其二進制表示為 `1100`。

- **`n = 12 (1100)`**
- **`n - 1 = 11 (1011)`**

當我們進行 `n & (n - 1)`：

```
  1100   (n)
& 1011   (n - 1)
--------
  1000   (結果)
```

可以看到，最右邊的 `1` 被清除了。

再來看下一個步驟：

- **`n = 8 (1000)`**
- **`n - 1 = 7 (0111)`**

```
  1000   (n)
& 0111   (n - 1)
--------
  0000   (結果)
```

這樣，整個數字中的所有 `1` 最終都被清除了。

### 推論：
由於每次運行 `n &= (n - 1)` 都會將數字中最右邊的一個 `1` 清除掉，最終這個操作會迴圈執行 `n` 中 `1` 的個數次，直到 `n` 變成 `0` 為止。因此，這個方法的效率非常高，因為它的迴圈次數取決於 `1` 的個數，而不是整數的總位數。

### C++ 示例：

```cpp
#include <iostream>
using namespace std;

int countOnes(int n) {
    int count = 0;
    while (n) {
        n &= (n - 1);  // 清除最右邊的 1
        count++;
    }
    return count;
}

int main() {
    int n = 12;  // 二進制為 1100
    cout << "1 的個數: " << countOnes(n) << endl;  // 輸出: 2
    return 0;
}
```

在這個例子中，`countOnes(12)` 會計算出 `12` 的二進制中有 2 個 `1`。
