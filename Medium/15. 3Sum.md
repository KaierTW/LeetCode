# 15. 3Sum
Problem : [HERE](https://leetcode.com/problems/3sum/description/)

>[!TIP]
>先把陣列數字從小排到大
>
>先固定第一個數字，第二個數字從第一個數字旁邊開始，第三個數字從最後往前
>
>如果總和小於0就可以換下一個組合 不用嘗試第三個數字往前移動了，因為最右邊已經是最大的了
>
>反之，如果總和大於0就可以把第三個數字往前移動，因為會變小

>[!NOTE]
>int* returnSize 表示回傳有幾組答案 → 一個數字和只有一個數字的陣列其實是一樣的，如果*returnSize = 2，那也可以是[2]
>
>int** returnColumnSizes就是一個二維陣列了，LeetCode應該有先給他位址，所以我自己用*returnColumnSizes = malloc((numsSize * numsSize) * sizeof(int));把裡面分配大小存數字
>
>他原本如果int** returnColumnSizes = malloc(sizeof(int*))，那這樣陣列大小就是[[n,n,n]]


>[!IMPORTANT]
>其實也可以看成原先int* returnSize應該是有int* returnSize = malloc(sizeof(int)) → 所以只需要回傳幾組答案(一個數字)就可以了
>
>int** returnColumnSizes應該是有int** returnColumnSizes = malloc(sizeof(int*)) → 所以裡面就只會放一組陣列[[ ]]
>
>我們只要再自己*returnColumnSizes = malloc((numsSize * numsSize) * sizeof(int)) → 給裡面那個陣列的大小就好[[n ,n ,n]]

```C
/**
 * Return an array of arrays of size *returnSize.
 * The sizes of the arrays are returned as *returnColumnSizes array.
 * Note: Both returned array and *columnSizes array must be malloced, assume caller calls free().
 */
 void BubbleSort(int* nums , int size){
    for(int i = 0 ; i < size - 1 ; i++){
        for(int j = 0 ; j < size - i - 1 ; j++){
            if(nums[j] > nums[j + 1]){
                int temp = nums[j];
                nums[j] = nums[j + 1];
                nums[j + 1] = temp;
            }
        }
    }
 }
int** threeSum(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    *returnSize = 0;
    int** ans = malloc((numsSize * numsSize) * sizeof(int*));
    //int** ans = malloc(sizeof(int*));
    //*returnColumnSizes = malloc((numsSize * numsSize) * sizeof(int*));
    *returnColumnSizes = malloc((numsSize * numsSize) * sizeof(int));    
    //*returnColumnSizes = malloc(sizeof(int));
    BubbleSort(nums , numsSize);
    for(int i = 0 ; i < numsSize - 2 ; i++){
        if(i != 0 && nums[i] == nums[i - 1]) continue;
        int second = i + 1;
        int third = numsSize - 1;
        while(second < third){
            int sum = nums[i] + nums[second] + nums[third];
            if(sum == 0){
                ans[*returnSize] = malloc(3 * sizeof(int));
                ans[*returnSize][0] = nums[i];
                ans[*returnSize][1] = nums[second];
                ans[*returnSize][2] = nums[third];
                (*returnColumnSizes)[*returnSize] = 3;                          
                (*returnSize)++;
                //ans = realloc(ans , ((*returnSize + 1) * sizeof(int*)));
                //printf("Pointer : %p\n" , ans);
                //*returnColumnSizes = realloc(*returnColumnSizes , ((*returnSize + 1) * sizeof(int)));                
                while(second < third && nums[second] == nums[second + 1]) second++;
                while(second < third && nums[third] == nums[third - 1]) third--;
                second++;
                third--;
            }
            else if(sum < 0) second++;
            else if(sum > 0) third--;
        }
    }
    return ans;
}
```

>[!TIP]
>是的，我知道這題。`3Sum` 是一道經典的算法題目，目的是在一個整數數組中找到所有和為零的三元組（triplets），並且結果集中不能包含重複的三元組。
>
>這題的解法通常包括以下步驟：
>
>1. **排序數組**：首先將數組排序，這樣可以方便地使用雙指針技術來避免重複的三元組。
>2. **遍歷數組**：使用一個循環來固定每個數字作為三元組中的第一個數字。
>3. **雙指針技術**：對於每個固定的數字，使用雙指針來查找剩餘兩個數字，使得三個數字的和為零。

```CPP
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());
        for(int i = 0 ; i < nums.size() - 2 ; i++){            
            if(i > 0 && nums[i] == nums[i - 1]) continue; //避免重複
            int left = i + 1, right = nums.size() - 1;
            while(left < right){                
                int sum = nums[i] + nums[left] + nums[right];
                if(sum == 0) {
                    vector<int> tempAns = {nums[i], nums[left], nums[right]};                
                    ans.push_back(tempAns);          
                    while(left < right && nums[left] == nums[left + 1]) left++; //避免重複
                    while(left < right && nums[right] == nums[right - 1]) right--; //避免重複
                    left++;
                    right--;
                }
                else if(sum > 0) right--;
                else left++;
            }
        }
        return ans;
    }
};
```
