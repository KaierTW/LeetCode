# 238. Product of Array Except Self
Problem : [HERE](https://leetcode.com/problems/product-of-array-except-self/description/)

>[!TIP]
>用一個具體的例子來幫助你理解。
>
>假設我們有一個數組 `nums = [1, 2, 3, 4]`，我們需要計算每個元素的乘積，除了它自己。目標是得到一個新數組 `answer`，其中 `answer[i]` 是 `nums` 中除了 `nums[i]` 之外的所有元素的乘積。
>
>### 步驟 1：計算前綴積
>我們先計算每個元素左邊所有元素的乘積，並存儲在 `answer` 中。
>
>- 初始化 `prefix = 1`。
>- 遍歷數組：
>  - `i = 0` 時，`answer[0] = prefix = 1`，然後更新 `prefix = prefix * nums[0] = 1 * 1 = 1`。
>  - `i = 1` 時，`answer[1] = prefix = 1`，然後更新 `prefix = prefix * nums[1] = 1 * 2 = 2`。
>  - `i = 2` 時，`answer[2] = prefix = 2`，然後更新 `prefix = prefix * nums[2] = 2 * 3 = 6`。
>  - `i = 3` 時，`answer[3] = prefix = 6`，然後更新 `prefix = prefix * nums[3] = 6 * 4 = 24`。
>
>此時，`answer` 為 `[1, 1, 2, 6]`。
>
>### 步驟 2：計算後綴積並得到最終結果
>接下來，我們計算每個元素右邊所有元素的乘積，並將其與前綴積相乘。
>
>- 初始化 `suffix = 1`。
>- 反向遍歷數組：
>  - `i = 3` 時，`answer[3] = answer[3] * suffix = 6 * 1 = 6`，然後更新 `suffix = suffix * nums[3] = 1 * 4 = 4`。
>  - `i = 2` 時，`answer[2] = answer[2] * suffix = 2 * 4 = 8`，然後更新 `suffix = suffix * nums[2] = 4 * 3 = 12`。
>  - `i = 1` 時，`answer[1] = answer[1] * suffix = 1 * 12 = 12`，然後更新 `suffix = suffix * nums[1] = 12 * 2 = 24`。
>  - `i = 0` 時，`answer[0] = answer[0] * suffix = 1 * 24 = 24`，然後更新 `suffix = suffix * nums[0] = 24 * 1 = 24`。
>
>最終，`answer` 為 `[24, 12, 8, 6]`。
>
>### 總結
>- **前綴積**：計算每個元素左邊所有元素的乘積。
>- **後綴積**：計算每個元素右邊所有元素的乘積，並與前綴積相乘。
>
>這樣，我們就能在O(n)的時間內完成計算，並且只使用了常數級別的額外空間。
>
>希望這個解釋能幫助你更好地理解這個原理！如果還有其他問題，隨時告訴我哦！😊

```CPP
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        vector<int> ans;
        int containZero = 0;
        int sum = 1;
        for(int i = 0 ; i < nums.size() ; i++){
            if(nums[i] != 0) sum *= nums[i];
            else containZero++;
        }
        for(int i = 0 ; i < nums.size() ; i++){
            if(nums[i] != 0){
                if(containZero > 0) ans.push_back(0);
                else{
                    ans.push_back(sum / nums[i]);
                }
            }
            else{
                if(containZero > 1) ans.push_back(0);
                else ans.push_back(sum);
            }
        }
        return ans;
    }
};
```
