# 29. Divide Two Integers
Problem : [HERE](https://leetcode.com/problems/divide-two-integers/description/)

>[!TIP]
>如果dividend是INT_MIN的話，要去判斷divisor是1還是-1。如果是-1的話會變成正數，所以要return INT_MAX；如果是1的話就一樣returb INT_MIN
>
>然後因為INT_MAX數字部分比INT_MIN還要小1，所以先通通轉成負數。
>


```C
int divide(int dividend, int divisor) {
    int ans = 0;
    bool neg = false;
    if(dividend == INT_MIN){
        if(divisor == -1) return INT_MAX;
        else if(divisor == 1) return INT_MIN;
    } 
    if(dividend > 0){
        dividend = -dividend;
        neg = !neg;
    }
    if(divisor > 0){
        divisor = -divisor;
        neg = !neg;
    }
    while(dividend <= divisor){
        int max_divisor = divisor , times = 1;
        while(max_divisor > INT_MIN /2 && dividend <= max_divisor + max_divisor){
            max_divisor += max_divisor;
            times += times;
            printf("Max : %d\n" , max_divisor);
        }
        dividend -= max_divisor;
        ans+=times;
    }
    if(neg) return -ans;
    else return ans;
}
```
