# 167. Two Sum II - Input Array Is Sorted
Problem : [HERE](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/description)

>[!TIP]
>是的，我會這題！這題目是LeetCode上的一個經典問題。題目要求在一個已排序的整數數組中找到兩個數，使它們的和等於指定的目標數。這個數組是1索引的，意思是索引從1開始，而不是0。
>
>### 解題思路
>這題可以使用**雙指針**技巧來解決，因為數組已經排序好了。具體步驟如下：
>
>1. **初始化指針**：設置兩個指針，`i`指向數組的起始位置，`j`指向數組的末尾位置。
>2. **迭代**：在迴圈中，計算`numbers[i]`和`numbers[j]`的和。
>3. **比較和**：如果和等於目標數，返回這兩個數的索引（注意索引是1索引的，所以需要加1）。
>4. **調整指針**：如果和小於目標數，移動`i`指針向右；如果和大於目標數，移動`j`指針向左。

```CPP
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {        
        int left = 0, right = numbers.size() - 1;
        while(left < right){
            int total = numbers[left] + numbers[right];
            if(total == target) return {left + 1, right + 1};
            else if(total > target) right--;
            else left++;
        }
        return {-1, -1};
    }
};
```
