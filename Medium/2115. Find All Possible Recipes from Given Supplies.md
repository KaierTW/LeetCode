>### 解題思路
>這題的核心是使用拓撲排序來解決食譜和材料之間的依賴關係。具體步驟如下：
>
>1. **建立圖和入度表**：
>   - 使用一個哈希表 `graph` 來表示每個材料到食譜的依賴關係。
>   - 使用一個哈希表 `indegree` 來記錄每個食譜所需的材料數量（入度）。
>
>2. **初始化隊列**：
>   - 將所有初始材料加入隊列 `queue`，這些材料可以直接使用。
>
>3. **拓撲排序**：
>   - 從隊列中取出材料，檢查哪些食譜可以製作，並將這些食譜加入結果列表。
>   - 將可以製作的食譜加入隊列，因為它們可以作為其他食譜的材料。
>   - 重複上述步驟，直到隊列為空。
>
>### 詳細解題步驟
>1. **建立圖和入度表**：
>   - `graph` 用來記錄每個材料到食譜的依賴關係。
>   - `indegree` 用來記錄每個食譜所需的材料數量。
>
>2. **初始化隊列**：
>   - 將所有初始材料加入隊列 `q`。
>
>3. **拓撲排序**：
>   - 從隊列中取出材料，檢查哪些食譜可以製作，並將這些食譜加入結果列表。
>   - 將可以製作的食譜加入隊列，因為它們可以作為其他食譜的材料。
>   - 重複上述步驟，直到隊列為空。
>
>這樣就可以找到所有可以製作的食譜了！希望這個解釋和代碼對你有幫助。如果有任何問題或需要進一步的解釋，隨時告訴我哦！

```CPP
class Solution {
public:
    vector<string> findAllRecipes(vector<string>& recipes, vector<vector<string>>& ingredients, vector<string>& supplies) {
        queue<string> q;
        unordered_map<string, vector<string>> recipesNeedIngredients;
        unordered_map<string, int> recipesNeedIngredientsNumber;
        vector<string> ans;
        for(int i = 0 ; i < recipes.size() ; i++){
            for(string ingredient : ingredients[i]){
                recipesNeedIngredients[ingredient].push_back(recipes[i]);
                recipesNeedIngredientsNumber[recipes[i]]++;
            }
        }

        for(string supply : supplies){
            q.push(supply);
        }

        while(!q.empty()){
            string ingredient = q.front();
            q.pop();
            for(string recipe : recipesNeedIngredients[ingredient]){
                recipesNeedIngredientsNumber[recipe]--;
                if(recipesNeedIngredientsNumber[recipe] == 0){
                    ans.push_back(recipe);
                    q.push(recipe);
                }
            }
        }
        return ans;
    }
};
```
