# 904. Fruit Into Baskets
Problem : [HERE](https://leetcode.com/problems/fruit-into-baskets/description/)

>[!TIP]
>滑動視窗（Sliding Window）在 C++ 中的實現方式通常是用雙指標（`left` 和 `right`），配上一個 `unordered_map` 來記錄目前視窗內的水果種類及數量。
>
>---
>
>### ✅ 題目重點（轉換成滑動視窗邏輯）：
>
>* 我們維護一個「視窗」`[left, right]`，表示目前從第 `left` 棵樹摘到第 `right` 棵樹。
>* 條件是：**視窗內最多只能有兩種水果**（即 `unordered_map` 的 size <= 2）。
>* 每次右指標往右擴張，加新水果；如果水果種類超過 2，就縮小左指標直到只有兩種為止。
>* 過程中紀錄「目前能摘的最多水果數量」。
>
>---
>
>### 💡 C++ 程式碼範例：
>
>```cpp
>#include <iostream>
>#include <vector>
>#include <unordered_map>
>using namespace std;
>
>int totalFruit(vector<int>& fruits) {
>    unordered_map<int, int> basket;
>    int left = 0;
>    int maxFruits = 0;
>
>    for (int right = 0; right < fruits.size(); ++right) {
>        basket[fruits[right]]++;  // 加入右邊的水果
>
>        // 超過兩種水果，就從左邊開始移除
>        while (basket.size() > 2) {
>            basket[fruits[left]]--;
>            if (basket[fruits[left]] == 0) {
>                basket.erase(fruits[left]);
>            }
>            left++;  // 縮小視窗左邊
>        }
>
>        // 更新最大值
>        maxFruits = max(maxFruits, right - left + 1);
>    }
>
>    return maxFruits;
>}
>```
>
>---
>
>### 📘 範例輸入測試：
>
>```cpp
>int main() {
>    vector<int> fruits = {1, 2, 3, 2, 2};
>    cout << totalFruit(fruits) << endl;  // 輸出 4
>    return 0;
>}
>```
>
>---
>
>### 🧠 時間與空間複雜度：
>
>* **時間複雜度：** O(n)，每個元素最多被左指標和右指標各經過一次。
>* **空間複雜度：** O(1)，因為最多只會有兩種水果（`unordered_map` 最多兩項）。
>
>---
>
>



```CPP
class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        int left = 0;
        int ans = 0;
        unordered_map<int, int> uom; // <fruit type, fruit number>
        for(int right = 0 ; right < fruits.size() ; right++){
            // 先加入
            uom[fruits[right]]++;
            // 檢查有沒有超過兩種水果
            while(uom.size() > 2){
                // 有超過 要先從左邊開始移除
                uom[fruits[left]]--;
                if(uom[fruits[left]] == 0) uom.erase(fruits[left]);
                left++;
            }
            // 更新答案
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```
