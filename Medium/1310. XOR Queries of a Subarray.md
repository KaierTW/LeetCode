# 1310. XOR Queries of a Subarray
Problem : [HERE](https://leetcode.com/problems/xor-queries-of-a-subarray/description/)

>[!TIP]
>
>當我們解決「XOR Queries of a Subarray」這道題目時，使用了**前綴 XOR** 的技巧來高效計算區間內的 XOR 值。讓我們一步一步解釋這個原理。
>
>### XOR 性質
>首先，了解 XOR（異或運算）的一些重要性質：
>
>1. **自身 XOR 自身為 0**：`a ^ a = 0`。
>2. **XOR 與交換律**：`a ^ b ^ c = a ^ c ^ b`（可以改變順序）。
>3. **任何數與 0 的 XOR 結果是這個數**：`a ^ 0 = a`。
>
>這些性質是我們解決問題的關鍵。
>
>### 問題總結
>我們的任務是處理多個區間查詢，查詢的內容是計算給定數組 `arr` 中區間 `[L, R]` 的 XOR 值，即：`arr[L] ^ arr[L+1] ^ ... ^ arr[R]`。
>
>### 暴力解法（低效）
>如果我們每次查詢都直接計算該區間的 XOR 值，會導致每次查詢需要遍歷整個區間，這樣的時間複雜度為 O(n)（假設區間長度為 n）。如果查詢次數很多，這樣的做法會導致性能問題。
>
>### 前綴 XOR 原理
>為了解決這個問題，我們使用「前綴 XOR」來優化區間查詢。這個方法的核心思想是通過計算從數組開頭到每個位置的 XOR，然後利用這些結果來快速得到區間的 XOR 值。
>
>#### 具體解釋：
>1. **前綴 XOR 定義**：
>   設 `prefixXOR[i]` 為從 `arr[0]` 到 `arr[i]` 的 XOR 結果，即：
>   ```
>   prefixXOR[i] = arr[0] ^ arr[1] ^ ... ^ arr[i]
>   ```
>   這樣，我們可以用 O(n) 的時間預先計算出所有的 `prefixXOR` 值。
>
>2. **區間 XOR 計算**：
>   如果我們想計算區間 `[L, R]` 的 XOR 值，我們可以用前綴 XOR 來高效計算：
>   - 當 `L == 0` 時，區間 `[0, R]` 的 XOR 值就是 `prefixXOR[R]`，因為這本來就是從 `arr[0]` 到 `arr[R]` 的 XOR 結果。
>   - 當 `L > 0` 時，區間 `[L, R]` 的 XOR 可以通過以下公式得到：
>     ```
>     arr[L] ^ arr[L+1] ^ ... ^ arr[R] = prefixXOR[R] ^ prefixXOR[L-1]
>     ```
>     這是因為：
>     - `prefixXOR[R]` 是從 `arr[0]` 到 `arr[R]` 的 XOR 結果。
>     - `prefixXOR[L-1]` 是從 `arr[0]` 到 `arr[L-1]` 的 XOR 結果。
>     - 因為 XOR 的交換律和自身 XOR 自身為 0，我們可以通過把 `prefixXOR[L-1]` 從 `prefixXOR[R]` 中「抵消掉」，只剩下區間 `[L, R]` 的 XOR。
>
>#### XOR 抵消例子
>假設我們有數組 `arr = [a, b, c, d, e]`，並且要查詢區間 `[L = 1, R = 3]` 的 XOR 值，即 `b ^ c ^ d`。我們可以通過前綴 XOR 來計算：
>- `prefixXOR[3] = a ^ b ^ c ^ d`
>- `prefixXOR[0] = a`
>
>然後，`b ^ c ^ d` 可以通過 `prefixXOR[3] ^ prefixXOR[0]` 計算得到：
>```
>a ^ b ^ c ^ d ^ a = (a ^ a) ^ b ^ c ^ d = 0 ^ b ^ c ^ d = b ^ c ^ d
>```
>
>這樣就得到了區間 `[1, 3]` 的 XOR 值。
>
>### 總結
>通過使用前綴 XOR，我們可以將每次區間查詢的時間複雜度從 O(n) 降到 O(1)，只需常數時間查詢預先計算好的 `prefixXOR` 結果。預處理的時間複雜度是 O(n)，因此總的時間複雜度是 O(n + m)，其中 `n` 是數組長度，`m` 是查詢次數。
>
>這使得處理大量查詢變得高效可行。


```CPP
class Solution {
public:
    vector<int> xorQueries(vector<int>& arr, vector<vector<int>>& queries) {
        vector<int> ans;
        int arrSize = arr.size();
        vector<int> prefixArr(arrSize);
        prefixArr[0] = arr[0];
        for(int i = 1 ; i < arrSize ; i++){
            prefixArr[i] = arr[i] ^ prefixArr[i - 1];
        }
        for(const auto query : queries){
            int start = query[0];
            int end = query[1];
            int xorValue;
            if(start == 0){
                xorValue = prefixArr[end];
            }
            else{
                xorValue = prefixArr[end] ^ prefixArr[start - 1];
            }            
            ans.push_back(xorValue);
        }
        return ans;
    }
};
```
