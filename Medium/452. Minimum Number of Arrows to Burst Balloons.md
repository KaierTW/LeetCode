# 452. Minimum Number of Arrows to Burst Balloons
Problem : [HERE](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/description/)

>[!TIP]
>這題的核心解題思路是使用 **貪心演算法（Greedy Algorithm）**，以下是詳細的解題步驟與邏輯：
>
>---
>
>### 🎯 題目目標
>給定一堆氣球，每個氣球的範圍是 `[start, end]`，你可以從任意 x 軸位置射出一支垂直向上的箭，箭會射爆所有範圍內的氣球。**你要找出最少需要幾支箭，才能射爆所有氣球。**
>
>---
>
>### 💡 解題思路（Greedy）
>
>1. **將所有氣球依照「結束位置」`end` 進行排序**。
>   - 為什麼？因為我們希望每次射箭都能「覆蓋最多的氣球」，而最早結束的氣球是最緊急要處理的。
>
>2. **初始化箭的數量為 1**，並設第一支箭的位置為第一個氣球的 `end`。
>
>3. **從第二個氣球開始遍歷**：
>   - 如果這個氣球的 `start` 大於目前箭的位置，代表這支箭射不到這個氣球 → 需要再射一支箭。
>   - 更新箭的位置為這個氣球的 `end`。
>
>4. 重複這個過程直到所有氣球都處理完。
>
>---
>
>### 🧠 時間複雜度分析
>- 排序： $$O(n \log n)$$
>- 遍歷氣球： $$O(n)$$
>- 總時間複雜度： $$O(n \log n)$$
>
>---
>

class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        int ans = 1;
        sort(points.begin(), points.end(), [](const vector<int>& a, const vector<int>& b){
            return a[1] < b[1];
        });
        int arrowIndex = points[0][1];
        for(int i = 1 ; i < points.size() ; i++){
            // 箭超出範圍
            if(arrowIndex < points[i][0]){
                ans++;
                arrowIndex = points[i][1];

            }
        }
        return ans;
    }
};
