# 151. Reverse Words in a String
Porblem : [HERE](https://leetcode.com/problems/reverse-words-in-a-string/description)

>[!TIP]
>在 C++ 中，我們可以使用 **`istringstream`** 來分割單詞，並利用 **`vector<string>`** 存儲單詞，再反轉順序並拼接成新的字串。以下是一種簡潔的解法：
>
>### 思路解析：
>1. **利用 `istringstream` 處理字串**：
>   - `istringstream iss(s)` 把 `s` 轉換成流，這樣可以用 `iss >> word` 逐個提取單詞，同時自動去除多餘的空格。
>
>2. **存入 `vector<string>`**：
>   - 逐個讀取單詞並存入 `vector`，這樣可以方便反轉單詞順序。
>
>3. **利用 `rbegin()` 反向遍歷 `vector`**：
>   - 透過 `vector<string>::rbegin()` 反向迭代單詞，並拼接成結果字串。
>
>這種方法時間複雜度為 **O(N)**，空間複雜度約為 **O(N)**，但如果使用 **原地操作（In-place）**，我們還能優化空間至 **O(1)**。
>


```CPP
class Solution {
public:
    string reverseWords(string s) {
        istringstream iss(s);
        string word, ans;
        vector<string>words;        
        while(iss >> word){
            words.push_back(word);
        }
        for(auto it = words.rbegin() ; it != words.rend() ; it++){
            if(it + 1 == words.rend()) ans += *it;
            else ans  += (*it + " ");
        }
        return ans;
    }
};
```
