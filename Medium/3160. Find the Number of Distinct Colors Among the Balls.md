# 3160. Find the Number of Distinct Colors Among the Balls
Problem : [HERE](https://leetcode.com/problems/find-the-number-of-distinct-colors-among-the-balls/description/)

>[!TIP]
>
>要解決這道題目，你可以按照以下步驟進行：
>
>1. **初始化數據結構**：
>   - 使用一個字典來記錄每個球的顏色。
>   - 使用一個集合來記錄所有不同的顏色。
>
>2. **處理每個查詢**：
>   - 遍歷 `queries`，對於每個查詢 `[x, y]`：
>     - 如果球 `x` 已經有顏色，先從集合中移除這個顏色（如果這個顏色不再存在於其他球上）。
>     - 更新球 `x` 的顏色為 `y`。
>     - 將新顏色 `y` 添加到集合中。
>
>3. **記錄結果**：
>   - 在每次查詢後，記錄當前集合的大小，這就是不同顏色的數量。

```CPP
class Solution {
public:
    vector<int> queryResults(int limit, vector<vector<int>>& queries) {
        vector<int> ans;
        unordered_map<int, int> mapBallColor;
        unordered_set<int> setColor;
        for(int i = 0 ; i < queries.size() ; i++){
            // 檢查現在的球之前有沒有被填色過
            // 之前有填色過
            if(mapBallColor.find(queries[i][0]) != mapBallColor.end()){
                // 先知道原本的顏色
                int previousColor = mapBallColor[queries[i][0]];
                // 先檢查是不是有別的球也是這個顏色
                bool stillOtherBallIsThePreviousColor = false;
                for(const auto& pair : mapBallColor){
                    if(pair.second == previousColor && pair.first != queries[i][0]){
                        stillOtherBallIsThePreviousColor = true;
                        break;
                    }
                }
                // 如果有別的球也是這個顏色就不能刪掉
                if(!stillOtherBallIsThePreviousColor) setColor.erase(previousColor);
                // 更新球跟顏色的unordered_map中
                mapBallColor[queries[i][0]] = queries[i][1];
                // 直接再insert到獨立顏色的set中，set的特性，所以已經存在的顏色不會重複插入 也不會有error                
                setColor.insert(queries[i][1]);
            }
            // 之前沒有填色過
            else{
                // 加入球跟顏色的unordered_map中        
                mapBallColor[queries[i][0]] = queries[i][1];
                // 加入獨立顏色的set中
                setColor.insert(queries[i][1]);
            }
            // 填入獨立的顏色
            ans.push_back(setColor.size());
        }
        return ans;
    }
};
```
