# 92. Reverse Linked List II
Problem : [HERE](https://leetcode.com/problems/reverse-linked-list-ii/description/)

>[!TIP]
>LeetCode 第 92 題「Reverse Linked List II」的題目是要求你**反轉單向鏈表的一部分**，具體是從第 `left` 個節點到第 `right` 個節點。這題的解題思路可以分成幾個步驟：
>
>---
>
>### 🧠 解題思路
>
>假設你有一個鏈表 `1 → 2 → 3 → 4 → 5`，並且 `left = 2`，`right = 4`，那麼反轉後應該變成 `1 → 4 → 3 → 2 → 5`。
>
>---
>
>### 🔧 步驟解析
>
>1. **建立虛擬頭節點（dummy node）**
>   - 為了處理 `left = 1` 的情況，建立一個 dummy node 指向 head。
>
>2. **找到 left 的前一個節點（pre）**
>   - 從 dummy 開始走 `left - 1` 步，找到 `pre` 節點。
>
>3. **反轉 left 到 right 節點之間的鏈表**
>   - 使用「頭插法」來反轉這段鏈表：
>     - 每次把 `cur.next` 插入到 `pre.next` 的位置。
>
>4. **返回 dummy.next 作為新的 head**
>
>---
>
>### ✅ 時間與空間複雜度
>
>- **時間複雜度**： $$O(n)$$，需要遍歷一次鏈表。
>- **空間複雜度**： $$O(1)$$，原地反轉，不需要額外空間。
>
>---


```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseBetween(ListNode* head, int left, int right) {
        ListNode* vHead = new ListNode();
        vHead -> next = head;
        ListNode* temp = vHead;
        ListNode* startLeft;
        for(int i = 0 ; i < left - 1 ; i++){
            temp = temp -> next;
        }
        startLeft = temp;
        stack<ListNode*> s;
        temp = temp -> next;
        for(int i = left ; i <= right ; i++){
            s.push(temp);
            temp = temp -> next;
        }
        ListNode* endRight = temp;
        ListNode* reverseStart = s.top();
        ListNode* reverseTemp = reverseStart;
        s.pop();
        while(!s.empty()){            
            reverseTemp -> next = s.top();
            s.pop();
            reverseTemp = reverseTemp -> next;
        }
        reverseTemp -> next = endRight;
        startLeft -> next = reverseStart;
        return vHead -> next;
    }
};
```
