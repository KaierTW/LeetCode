# 209. Minimum Size Subarray Sum
Problem : [HERE](https://leetcode.com/problems/minimum-size-subarray-sum/description/)

>[!TIP]
>當然可以！這題的解題思路主要是使用滑動窗口（Sliding Window）技術。以下是詳細步驟：
>
>1. **初始化變量**：
>   - 設置兩個指針 `left` 和 `right`，都指向數組的起始位置。
>   - 設置一個變量 `sum` 來存儲當前窗口內的數字和，初始值為0。
>   - 設置一個變量 `min_length` 來存儲最小子數組的長度，初始值為一個很大的數（如 `INT_MAX`）。
>
>2. **擴展窗口**：
>   - 使用 `right` 指針遍歷數組，將 `nums[right]` 加到 `sum` 中。
>   - 每次加完後，檢查 `sum` 是否大於或等於 `target`。
>
>3. **收縮窗口**：
>   - 當 `sum` 大於或等於 `target` 時，更新 `min_length` 為當前窗口的長度（`right - left + 1`）。
>   - 然後將 `nums[left]` 從 `sum` 中減去，並將 `left` 指針右移一位，嘗試找到更小的符合條件的窗口。
>
>4. **重複步驟2和3**：
>   - 直到 `right` 指針遍歷完整個數組。
>
>5. **返回結果**：
>   - 如果 `min_length` 沒有被更新過，說明沒有符合條件的子數組，返回0。
>   - 否則，返回 `min_length`。
>
>這樣的滑動窗口技術可以在O(n)的時間複雜度內完成，因為每個元素最多被訪問兩次（一次被 `right` 指針訪問，一次被 `left` 指針訪問）。


```CPP
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0, sum = 0, minLen = INT_MAX;
        for(int right = 0 ; right < nums.size() ; right++){
            sum += nums[right];
            while(sum >= target){
                int len = right - left + 1;
                if(len < minLen) minLen = len;
                sum -= nums[left++];
            }
        }
        return (minLen == INT_MAX) ? 0 : minLen;

    }
};
```
