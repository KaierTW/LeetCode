# 57. Insert Interval
Problem : [HERE](https://leetcode.com/problems/insert-interval/description/)

>[!TIP]
>解題思路如下：
>
>1. **初始化**：首先，創建一個空的結果向量`ans`來存儲最終的區間。
>
>2. **遍歷原始區間**：
>   - **添加不重疊的區間**：遍歷原始區間，將所有在`newInterval`之前且不重疊的區間直接添加到`ans`中。
>   - **合併重疊的區間**：當遇到與`newInterval`重疊的區間時，更新`newInterval`的起始和結束位置，使其包含所有重疊的區間。
>
>3. **添加合併後的區間**：將更新後的`newInterval`添加到`ans`中。
>
>4. **添加剩餘的區間**：將所有在`newInterval`之後且不重疊的區間添加到`ans`中。
>
>這個方法的時間複雜度是 $$O(n)$$ ，其中 $$n$$ 是原始區間的數量

```CPP
class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {        
        vector<vector<int>> ans;
        int i = 0, n = intervals.size();
        // 現在區間比newInterval還左邊
        while(i < n && intervals[i][1] < newInterval[0]){
            ans.push_back(intervals[i++]);
        }
        // 現在區間碰到newInterval，確保現在區間的開頭沒有超過newInterval的結尾
        while(i < n && intervals[i][0] <= newInterval[1]){
            newInterval[0] = min(newInterval[0], intervals[i][0]);
            newInterval[1] = max(newInterval[1], intervals[i][1]);
            i++;
        }
        ans.push_back(newInterval);
        while(i < n){
            ans.push_back(intervals[i++]);
        }
        return ans;

    }
};
```
