# 2658. Maximum Number of Fish in a Grid
Problem : [HERE](https://leetcode.com/problems/maximum-number-of-fish-in-a-grid/description/)

>[!TIP]
>這裡是解題的思路：
>
>1. **遍歷所有水域單元格**：從每個非零的水域單元格開始，進行深度優先搜索（DFS）。
>
>2. **深度優先搜索（DFS）**：對於每個起始單元格，使用DFS遍歷所有相鄰的水域單元格，並計算捕獲的魚數量。DFS的步驟如下：
>   - 如果當前單元格是水域單元格，捕獲該單元格的魚，並將該單元格標記為已訪問（設置為0）。
>   - 遞歸地對相鄰的水域單元格進行DFS，累加捕獲的魚數量。
>   - 回溯到上一個單元格，繼續探索其他相鄰單元格。
>
>3. **更新最大魚數量**：對於每個起始單元格，計算捕獲的魚數量，並更新最大值。

```CPP
class Solution {
public:
    int findMax(int row, int col, vector<vector<int>>& grid){
        if(row < 0 || row >= grid.size() || col < 0 || col >= grid[0].size() || grid[row][col] == 0) return 0;
        int fish = grid[row][col];
        grid[row][col] = 0; // 訪問過
        fish += findMax(row + 1, col, grid); // 右
        fish += findMax(row, col + 1, grid); // 上
        fish += findMax(row - 1, col, grid); // 左
        fish += findMax(row, col - 1, grid); // 下
        return fish;
    }
    int findMaxFish(vector<vector<int>>& grid) {
        int row = grid.size();
        int col = grid[0].size();
        int maxFish = 0;
        for(int r = 0 ; r < row ; r++){
            for(int c = 0 ; c < col ; c++){
                if(grid[r][c] > 0)maxFish = max(maxFish, findMax(r, c, grid));
            }
        }
        return maxFish;
    }
};
```
