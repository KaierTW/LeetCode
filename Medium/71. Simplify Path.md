# 71. Simplify Path
Problem : [HERE](https://leetcode.com/problems/simplify-path/description)

>[!TIP]
>LeetCode 第 71 題 **Simplify Path** 是一道關於處理 Unix-style 路徑的字串題。這題的解題思路主要是模擬 Unix 檔案系統的路徑解析規則，並使用 **stack（堆疊）** 來幫助簡化路徑。
>
>---
>
>### 🧠 解題思路：
>
>#### 題目要求：
>給定一個絕對路徑（例如 `"/home/"` 或 `"/a/./b/../../c/"`），你需要返回其 **簡化後的標準路徑**。
>
>#### Unix 路徑規則：
>- `"."` 表示當前目錄 → 忽略
>- `".."` 表示上一層目錄 → 從 stack 中 pop 一個元素（如果有的話）
>- 多個 `/` 被視為一個 `/`
>- 其他字串表示目錄名稱 → push 到 stack
>
>---
>
>### ✅ 解法步驟：
>
>1. **分割字串**：使用 `/` 將路徑分割成各個部分。
>2. **使用 stack 處理路徑**：
>   - 如果是空字串或 `"."` → 忽略
>   - 如果是 `".."` → pop stack（如果 stack 不為空）
>   - 否則 → push 該目錄名稱到 stack
>3. **組合結果**：用 `/` 將 stack 中的元素組合起來，並加上開頭的 `/`。
>
>---

```CPP
class Solution {
public:
    string simplifyPath(string path) {        
        stringstream ss(path);
        string word, ans;
        vector<string>vecstr_path;
        // getline遇到分隔符會自動當成空字串，連續的也一樣
        while(getline(ss, word, '/')){
            std::cout << word << std::endl;
            if(word == "" || word == ".") continue;
            else if(word == "..") {
                if(!vecstr_path.empty()) vecstr_path.pop_back();
            }
            else vecstr_path.push_back(word);
        }
        for(string p : vecstr_path){
            ans+= ("/" + p);
        }
        return ans.empty() ? "/" : ans;
    }
};
```
