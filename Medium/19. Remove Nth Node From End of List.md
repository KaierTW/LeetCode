# 19. Remove Nth Node From End of List
Problem : [HERE](https://leetcode.com/problems/remove-nth-node-from-end-of-list/description/)

>[!TIP]
>先找出整個List Node有多長，count是他的間隔，count - n代表你要從head往前數多少間隔
>
>然後數到的那個要跳過他的next，指到 next的next

```C
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    if(head -> next == NULL) return NULL;
    int count = 0;
    struct ListNode* current = head;
    while(current -> next != NULL) {
        current = current -> next;
        count++;
    }
    current = head;
    count -= n;
    if(count == -1){
        head = head -> next;
    }
    else{
        while(count > 0){
            current = current -> next;
            count--;
        }
        current -> next = current -> next -> next;
    }
    return head;
}
```

>這題是 LeetCode 第 19 題：「Remove Nth Node From End of List」，屬於 Linked List 的經典題目。以下是解題思路與 C++ 範例程式碼。
>
>---
>
>### 🧠 解題思路
>
>題目要求從單向鏈結串列中移除倒數第 N 個節點。常見的解法是使用 **雙指針（Two Pointers）** 技巧：
>
>1. **初始化兩個指針**：`fast` 和 `slow` 都指向 dummy 節點（dummy 節點指向 head）。
>2. **讓 fast 先走 N 步**：這樣 fast 和 slow 之間就會有 N 個節點的距離。
>3. **fast 和 slow 一起走**：直到 fast 到達鏈結串列尾端。
>4. 此時 slow 的下一個節點就是要被刪除的節點。
>5. **刪除節點**：`slow->next = slow->next->next`。
>
>使用 dummy 節點是為了處理刪除 head 節點的情況。
>
>---
>
>這個解法的時間複雜度是 $$O(L)$$，其中 $$L$$ 是鏈結串列的長度；空間複雜度是 $$O(1)$$。
>

>
>### 🧠 關鍵概念：雙指針距離
>
>假設鏈結串列長度是 `L`，我們要刪除的是 **倒數第 N 個節點**，也就是第 `L - N + 1` 個節點（從頭數起）。
>
>---
>
>### 🪜 操作步驟回顧
>
>1. **建立 dummy 節點**：dummy 指向 head，這樣可以統一處理刪除 head 的情況。
>2. **fast 指針先走 N 步**：此時 fast 距離 dummy 有 N 個節點。
>3. **fast 和 slow 一起走**：直到 fast 到達尾端（`fast->next == nullptr`）。
>
>---
>
>### 📐 為什麼 slow->next 是要刪除的節點？
>
>當 fast 到尾端時，slow 剛好在 **要刪除的節點的前一個節點**。
>
>這是因為：
>
>- fast 比 slow 多走了 N 步。
>- 所以當 fast 到尾端（第 L 個節點）時，slow 剛好在第 `L - N` 個節點。
>- 而第 `L - N + 1` 個節點就是要刪除的節點，也就是 `slow->next`。
>
>---
>
>### 🧮 舉例說明
>
>假設鏈結串列是：`1 -> 2 -> 3 -> 4 -> 5`，要刪除倒數第 2 個節點（也就是 `4`）。
>
>- fast 先走 2 步，停在 `2`
>- 然後 fast 和 slow 一起走：
>  - fast 到 `3`，slow 到 `1`
>  - fast 到 `4`，slow 到 `2`
>  - fast 到 `5`，slow 到 `3`
>- 此時 slow 在 `3`，而 `slow->next` 是 `4`，正是要刪除的節點。
>
>---
>


牛逼寫法:
```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* vHead = new ListNode();
        vHead -> next = head;
        ListNode* fast = vHead;
        ListNode* slow = vHead;
        // fast 先走 n 步
        for(int i = 0 ; i < n ; i++){
            fast = fast -> next;
        }
        // fast 和 slow 一起走，直到 fast 到尾端
        while(fast -> next != NULL){
            fast = fast -> next;
            slow = slow -> next;
        }
        // 刪除 slow 的下一個節點
        ListNode* deleteNode = slow -> next;
        slow -> next = slow -> next -> next;
        delete deleteNode;

        return vHead -> next;
    }
};
```

        ListNode* vHead = new ListNode();
        vHead -> next = head;

        int nodeNum = 0;
        while(temp){
            nodeNum++;
            temp = temp -> next;
        }
        int nodeRemove = nodeNum - n + 1;
        int count = 0;
