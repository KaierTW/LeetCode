# 19. Remove Nth Node From End of List
Problem : [HERE](https://leetcode.com/problems/remove-nth-node-from-end-of-list/description/)

>[!TIP]
>先找出整個List Node有多長，count是他的間隔，count - n代表你要從head往前數多少間隔
>
>然後數到的那個要跳過他的next，指到 next的next

```C
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    if(head -> next == NULL) return NULL;
    int count = 0;
    struct ListNode* current = head;
    while(current -> next != NULL) {
        current = current -> next;
        count++;
    }
    current = head;
    count -= n;
    if(count == -1){
        head = head -> next;
    }
    else{
        while(count > 0){
            current = current -> next;
            count--;
        }
        current -> next = current -> next -> next;
    }
    return head;
}
```
