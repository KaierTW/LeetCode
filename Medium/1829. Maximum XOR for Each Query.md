# 1829. Maximum XOR for Each Query
Problem : [HERE](https://leetcode.com/problems/maximum-xor-for-each-query/description/)

>[!TIP]
>題目 **"1829. Maximum XOR for Each Query"** 要求的是給定一個數組 `nums` 和一個目標數字 `maximumBit`，每次在 `nums` 的某個子陣列上進行 XOR 操作，並找到每次的最大可能結果。具體來說：
>
>- 對於給定的 `nums` 陣列，我們想要找到每次 XOR 結果後的最大值。
>- `maximumBit` 指定了 XOR 結果的最大可能位數，因此最大可能值為 `2^maximumBit - 1`。
>
>### 解題步驟：
>
>1. **求前綴 XOR**：
>   - 建立一個變量 `prefixXOR` 用於儲存從頭開始累積的 XOR 結果。
>   - 使用一個迴圈遍歷 `nums`，計算出到目前位置的 XOR 結果並累加到 `prefixXOR` 中。
>
>2. **找到最大 XOR**：
>   - 計算 `maximumNum = 2^maximumBit - 1`，這是 XOR 運算的最大目標值。
>   - 由於我們想要最大化結果，可以使用公式 `maximumNum ^ prefixXOR`，這樣每次都能得到當前累積 XOR 的最大值。
>  
>3. **倒序計算結果**：
>   - 依據題意，每次要移除 `nums` 的最後一個元素並重新計算 XOR，因此我們可以從完整的 `prefixXOR` 開始，依次移除最後一個數字的 XOR，計算並存儲每次的最大結果。
>
>### 時間複雜度
>- **O(n)**：因為我們需要遍歷一次 `nums` 陣列來計算 `prefixXOR`，且需要一次倒序遍歷來計算每次的結果。
>
>### 範例
>假設 `nums = [0,1,1,3]` 且 `maximumBit = 2`：
>- 最大可能值 `maximumNum = 2^2 - 1 = 3`
>- 每次倒序計算後的結果會儲存在 `result` 陣列中並返回。
>

>[!TIP]
>在這題中，「移除最後一個元素的 XOR」是指把當前累積的 XOR 結果從最後一個元素反推回去。
>
>### 解釋
>
>當我們計算 `prefixXOR` 時，這個值代表從 `nums` 陣列的開頭到目前為止所有數字的 XOR 結果。而根據題目的需求，我們需要每次去除最後一個元素的影響，這樣才能逐步取得倒序 XOR 結果的最大值。
>
>### XOR 運算性質
>
>XOR（異或）運算具有一個重要特性：如果我們對一個數 `a` 做兩次相同的 XOR，它會恢復原值：
>- \( a \oplus b \oplus b = a \)
>
>### 如何應用到這題
>
>1. **計算整體 XOR 結果**：
>   - 首先，計算 `nums` 陣列所有元素的 XOR 結果，稱為 `prefixXOR`。
>
>2. **移除元素的 XOR**：
>   - 如果我們希望計算「移除最後一個元素後的 XOR 結果」，可以將 `prefixXOR` 再 XOR 一次該元素，這樣這個元素的影響就會被消除。
>   - 例如，如果 `prefixXOR` 是整個陣列的 XOR 結果，而 `nums[-1]` 是最後一個元素，那麼 `prefixXOR ^ nums[-1]` 就是移除最後一個元素的 XOR 結果。
>
>3. **逐步計算每次的結果**：
>   - 每次我們去除一個元素，然後重新計算 XOR 的最大值，直到所有元素都被移除。
>
>### 範例
>
>假設 `nums = [0, 1, 1, 3]`，而 `maximumBit = 2`。
>
>- 計算 `maximumNum = 2^2 - 1 = 3`。
>- 計算初始的 `prefixXOR = 0 ^ 1 ^ 1 ^ 3 = 3`。
>
>接下來倒序處理，分別計算每次的結果：
>
>1. **當前 `prefixXOR = 3`**，計算 `3 ^ 3 = 0`，得到的結果為 `0`。
>   - 接著更新 `prefixXOR = 3 ^ 3 = 0`，即移除最後一個元素 `3` 的影響。
>
>2. **當前 `prefixXOR = 0`**，計算 `0 ^ 3 = 3`，得到的結果為 `3`。
>   - 更新 `prefixXOR = 0 ^ 1 = 1`，即移除下一個元素 `1`。
>
>3. **當前 `prefixXOR = 1`**，計算 `1 ^ 3 = 2`，得到的結果為 `2`。
>   - 更新 `prefixXOR = 1 ^ 1 = 0`，即移除下一個元素 `1`。
>
>4. **當前 `prefixXOR = 0`**，計算 `0 ^ 3 = 3`，得到的結果為 `3`。
>
>最終結果是 `[0, 3, 2, 3]`。

>[!TIP]
>在這題中，`maximumNum ^ prefixXOR` 之所以能得到最大值，是因為 `maximumNum` 是在指定的位數內能表示的最大數，並且 XOR 運算可以用來「翻轉」位元，讓結果最大化。下面具體解釋為什麼這樣的 XOR 可以讓結果最大。
>
>### 關鍵概念
>1. **XOR 的作用**：XOR 可以翻轉二進制數的每一位。例如，如果某一位是 `1`，XOR 之後會變成 `0`，而 `0` 會變成 `1`。
>2. **目標最大值**：`maximumNum` 是 \( 2^{\text{maximumBit}} - 1 \)，表示這個位數內能表達的最大整數，因此它的二進制位全部為 `1`。例如，如果 `maximumBit = 3`，那麼 `maximumNum = 2^3 - 1 = 7`，即二進制為 `111`。
>
>### XOR 的最大化效果
>
>給定任意 `prefixXOR`，將它與 `maximumNum` 做 XOR 的效果是將 `prefixXOR` 的所有位元進行「翻轉」，使得結果的每一位都盡可能朝向最大的值 `1`。
>
>具體來說：
>- 如果 `prefixXOR` 的某一位是 `1`，那麼 `maximumNum ^ prefixXOR` 會把這一位翻轉為 `0`。
>- 如果 `prefixXOR` 的某一位是 `0`，那麼 `maximumNum ^ prefixXOR` 會把這一位翻轉為 `1`。
>
>通過翻轉 `prefixXOR` 的每一位，我們可以最大化結果，因為我們盡可能地使得結果的高位為 `1`，而這正是取得最大值的方式。
>
>### 為什麼這樣能保證最大值？
>
>1. **全 1 的效果**：`maximumNum` 的每一位都是 `1`，這表示我們有能力控制 `prefixXOR` 的每一位進行翻轉，以確保每一位都是最有利於取得最大值的。
>   
>2. **最大化每一位的效果**：高位對數字的影響比低位大，因此，我們通過翻轉 `prefixXOR` 的每一位，讓高位儘量變成 `1`，這樣結果在二進制上就變成了最大值。
>
>### 範例
>
>假設 `maximumBit = 3`，所以 `maximumNum = 7` (二進制是 `111`)。
>
>若 `prefixXOR = 5`（二進制 `101`）：
>- `maximumNum ^ prefixXOR = 111 ^ 101 = 010`（二進制），結果是 `2`。
>
>若 `prefixXOR = 0`（二進制 `000`）：
>- `maximumNum ^ prefixXOR = 111 ^ 000 = 111`，結果是 `7`，這是可能的最大結果。
>
>因此，`maximumNum ^ prefixXOR` 保證了每次運算中 XOR 的最大化效果，確保我們取得可能的最大值。


```CPP
class Solution {
public:
    vector<int> getMaximumXor(vector<int>& nums, int maximumBit) {
        int tempXOR = 0 , numsSize = nums.size() , maxNum = static_cast<int>(pow(2 , maximumBit) - 1);
        vector<int> ans;
        for(int i = 0 ; i < numsSize ; i++){
            tempXOR = tempXOR ^ nums[i];
        }            
        for(int j = 0 ; j < numsSize ; j++){
            ans.push_back(tempXOR ^ maxNum);
            tempXOR ^= nums[numsSize - 1 - j];
        }        
        return ans;
    }
};
```
