>## 🧠 題目目標
>
>給定：
>- `preorder`：前序遍歷結果
>- `inorder`：中序遍歷結果
>
>你要根據這兩個遍歷結果，**重建原本的二元樹結構**。
>
>---
>
>## 🧩 解題思路詳解
>
>### 1️⃣ 前序遍歷的特性
>- 順序是：**根 → 左 → 右**
>- 所以 `preorder[0]` 一定是根節點。
>
>### 2️⃣ 中序遍歷的特性
>- 順序是：**左 → 根 → 右**
>- 根節點在中序中的位置可以劃分出左子樹和右子樹。
>
>### 3️⃣ 利用中序位置切割子樹
>假設根節點在中序中的位置是 `inRootIndex`：
>- 左子樹的中序範圍是 `inLeft` 到 `inRootIndex - 1`
>- 右子樹的中序範圍是 `inRootIndex + 1` 到 `inRight`
>
>### 4️⃣ 利用左子樹大小切割前序
>左子樹節點數量為 `leftSubtreeSize = inRootIndex - inLeft`：
>- 左子樹的前序範圍是 `preLeft + 1` 到 `preLeft + leftSubtreeSize`
>- 右子樹的前序範圍是 `preLeft + leftSubtreeSize + 1` 到 `preRight`
>
>### 5️⃣ 遞迴建樹
>重複以上步驟直到範圍無效（`preLeft > preRight`），表示沒有節點了。
>
>---
>
>## 🔍 關鍵細節補充
>
>### ✅ `inLeft 到 inRootIndex - 1` 是什麼？
>這是中序遍歷中「左子樹的範圍」，因為根節點在 `inRootIndex`，左邊的就是左子樹。
>
>### ✅ 為什麼要用 `unordered_map`？
>中序遍歷中查找根節點位置如果用 `find()` 是 O(n)，用哈希表可以降到 O(1)。
>
>---


```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    unordered_map<int, int> uom_InorderIndexMap; // <node -> Val, index>
    TreeNode* buildTreeRecursive(const vector<int>& preorder, int preorderLeftIndex, int preorderRightIndex, const vector<int>& inorder, int inorderLeftIndex, int inorderRightIndex){
        if(preorderLeftIndex > preorderRightIndex) return NULL;
        // 建立根節點，把preorderLeftIndex都當作每一個根節點
        int rootVal = preorder[preorderLeftIndex];        
        TreeNode* root = new TreeNode(rootVal);
        // 找根節點在indorder中的Index
        int rootIndexInInorderIndexMap = uom_InorderIndexMap[rootVal];
        // 計算左子樹大小，inorderLeftIndex到rootIndexInInorderIndexMap
        int leftSubTreeSize = rootIndexInInorderIndexMap - inorderLeftIndex;
        // 建立左子樹，preorder部分最左邊是根節點，所以每次往右移動一個
        // 左子樹在preorder的範圍就是從下一個根節點到左子樹的大小
        // 左子樹在inorder的範圍就是第一個元素到根節點的Index - 1
        root -> left = buildTreeRecursive(preorder, preorderLeftIndex + 1, preorderLeftIndex + leftSubTreeSize, inorder, inorderLeftIndex, rootIndexInInorderIndexMap - 1);
        // 建立右子樹
        // 右子樹的範圍就是剩下的
        root -> right = buildTreeRecursive(preorder, preorderLeftIndex + leftSubTreeSize + 1, preorderRightIndex, inorder, rootIndexInInorderIndexMap + 1, inorderRightIndex);

        return root;
    }
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        /* 
         * preorder: 中 -> 左 -> 右
         * inorder: 左 -> 中 -> 右
         *
         * preorder的第一個元素是根節點
         * inorder再碰到根節點以前是左子樹，碰到之後是右子樹
         * 根據左子樹的大小切割preorder的範圍
         *
         * 1. preorder(前序)遍歷提供根節點順序
         * 2. inorder(中序)遍歷提供左右子樹的分界
         * 3. 用遞迴方式不斷切割子樹區間
         * 4. 用哈希表加速中序索引查找
         */
        
        for(int i = 0 ; i < inorder.size() ; i++){
            uom_InorderIndexMap[inorder[i]] = i;
        }
        return buildTreeRecursive(preorder, 0, preorder.size() - 1, inorder, 0, inorder.size() - 1);

    }
};
```
