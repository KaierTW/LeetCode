# 5. Longest Palindromic Substring
Problem : [HERE](https://leetcode.com/problems/longest-palindromic-substring/)
>[!TIP]
>中心點展開，以每個字元為中心點展開，比對左右兩邊。先以奇數的方式找，再以偶數的方式找。

```C
void find(char* s , int left , int right , int* length , int* max , char** ans){
    while(left >= 0 && right < *length && s[left] == s[right]) {
        left--;
        right++;
    }
    if(right - left - 1 > *max){
        *max = right - left - 1;
        *ans = realloc(*ans , (*max + 1) * sizeof(char));
        strncpy(*ans , s + left + 1 , *max);
        (*ans)[*max] = '\0';
    }
}
char* longestPalindrome(char* s) {
    int length = strlen(s);
    char* result = malloc(sizeof(char));
    int max = 0;
    if(length < 2) return s;
    else{
        for(int i = 0  ; i < length ; i++) {
            //Odd
            find(s , i , i , &length , &max , &result);
            //Even
            find(s , i , i + 1 , &length , &max , &result);
        }
    }
    return result;
}
```

>Case 2:
>
>如果以**鏡像位置為中心**，擴展回文字串後，範圍**超過或碰到邊界(包含邊界)**，而且當前位置還在右邊界裡面，當前位置的回文字串範圍取**鏡像位置的回文字串範圍**和**邊界和當前位置距離**的**最小值**。
>
>![超過邊界](https://i.imgur.com/CjuHady.png)
>
>以上圖為例，現在中心是Index=6，邊界是Index=10，要計算Index=9，Index=9的鏡像位置是Index=3，Index=3的擴展回文範圍是3(也就是往左往右擴展3)，擴展回文範圍之後還超出邊界，所以取**鏡像位置的回文字串範圍=3**和**邊界和當前位置距離(10-9=1)**的**最小值=1**，所以Index=9的擴展回文範圍是1。

>這樣剛剛找的位置就編成新的中心，而邊界也變成往旁邊9(最大的回文擴展)。

```C
char* longestPalindrome(char* s) {
   int len = strlen(s);
    if(len < 2) return s;
    char* temp = malloc((2 * len + 2) * sizeof(char));
    int* arr = calloc((2 * len + 1) , sizeof(int));
    //在頭尾和字串間隔中間加入#
    for(int i = 0 ; i < (2 * len + 2) ; i++){
        if(i % 2 == 0) *(temp + i) = '#';
        else *(temp + i) = s[i / 2];
    }
    *(temp + 2 * len + 1) = '\0';
    int Center = 0 , RightBoundary = 0 , MaxarrIndex = 0 , MaxarrValue = 0;
    for(int i = 0 ; i < (2 * len + 1) ; i++){        
        //     (距離)     =      (距離)       -> 鏡像   = 2 * 中間   - 現在索引 -> IndexA是IndexC的鏡像    
        //IndexB - IndexA = IndexC - IndexB  -> IndexA = 2 * IndexB - IndexC
        int MirrorIndex = 2 * Center - i;
        //如果還在右邊邊界裡面，鏡像對應的或是離邊界距離取比較小的
        if(i < RightBoundary) arr[i] = (arr[MirrorIndex] < RightBoundary - i) ? arr[MirrorIndex] : RightBoundary - i;
        //取好之後再看能不能往兩邊擴展
        while(i - 1 - arr[i] >= 0 && i + 1 + arr[i] < (2 * len + 1) && temp[i - 1 - arr[i]] == temp[i + 1 + arr[i]]) arr[i]++;
        //如果加上擴展超出原先邊界，更新中心點和邊界
        if(i + arr[i] > RightBoundary){
            Center = i;
            RightBoundary = i + arr[i];
        }
        //紀錄最大回文擴展
        if(arr[i] > MaxarrValue){
            MaxarrValue = arr[i];
            MaxarrIndex = i;
        }
    }
    printf("MaxarrValue : %d , MaxarrIndex : %d" , MaxarrValue , MaxarrIndex);
    char* ans = malloc((MaxarrValue + 1) * sizeof(char));
    strncpy(ans , s + ((MaxarrIndex - MaxarrValue) / 2) , MaxarrValue);
    *(ans + MaxarrValue) = '\0';
    return ans;
}
```
