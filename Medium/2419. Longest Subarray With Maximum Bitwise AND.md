# 2419. Longest Subarray With Maximum Bitwise AND
Problem : [HERE](https://leetcode.com/problems/longest-subarray-with-maximum-bitwise-and/description/)

>[!TIP]
>題目 2419「Longest Subarray With Maximum Bitwise AND」要求找出一個子陣列，使該子陣列中所有元素的位元 AND 結果最大，並且返回這樣的子陣列中最長的長度。
>
>### 題目理解：
>1. **位元 AND 操作**（Bitwise AND）：對於兩個整數，位元 AND 操作會對其二進位表示的每一位進行按位比較，當兩個位元均為 1 時，結果為 1，否則為 0。例如：
>   - 5 (0101) AND 3 (0011) = 1 (0001)
>
>2. **子陣列**：一個陣列中的連續元素序列。
>
>### 題目需求：
>給定一個整數陣列 `nums`，你需要找到具有最大位元 AND 值的子陣列，並返回這樣的子陣列中最長的長度。
>
>### 例子：
>```plaintext
>輸入: nums = [1, 2, 3, 3, 2, 2]
>輸出: 2
>```
>
>#### 解釋：
>- 整個陣列中最大的位元 AND 值是 3。
>- 子陣列 `[3, 3]` 的 AND 值是 3，它的長度是 2。
>- 因此，答案是 2。
>
>### 解法思路：
>1. **找最大值**：首先，我們可以找出陣列中的最大值，因為位元 AND 的值不會超過陣列中的最大值。
>2. **找最大值的最長子陣列**：接下來，我們需要找出包含這個最大值的最長連續子陣列的長度。
>
>#### 基本步驟：
>1. 找出陣列中的最大值 `max_val`。
v2. 遍歷陣列，找出連續的 `max_val` 子陣列，記錄其中最長的長度。
>
>這個問題的關鍵在於理解「位元 AND」和找出「最大值的最長連續子陣列」。

```CPP
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        auto max_iter = max_element(nums.begin() , nums.end());
        int maxValue = *max_iter;
        int temp = 0 , ans = 0;
        for(int i = 0 ; i < nums.size() ; i++){
            if(nums[i] == maxValue){
                temp++;
            }
            else{
                if(temp > ans) ans = temp;
                temp = 0;
            }
        }
        return max(temp , ans);
    }
};
```
