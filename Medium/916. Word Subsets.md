# 916. Word Subsets
Problem : [HERE](https://leetcode.com/problems/word-subsets/description/)

>[!TIP]
>### 詳細步驟
>
>1. **計算 `words2` 中每個字母的最大出現次數**：
>   - 首先，我們需要遍歷 `words2` 中的每個字串，並計算每個字母的出現次數。
>   - 然後，對於所有字串，記錄每個字母的最大出現次數。例如，如果 `words2` 包含 ["e", "oo", "lo"], 那麼我們需要記錄 'e' 出現 1 次，'o' 出現 2 次，'l' 出現 1 次。
>
>2. **檢查 `words1` 中的每個字串**：
>   - 接下來，我們需要遍歷 `words1` 中的每個字串，並計算每個字母的出現次數。
>   - 然後，我們檢查這些字母的出現次數是否至少等於 `words2` 中對應字母的最大出現次數。例如，如果 `words1` 中的某個字串是 "google"，我們需要確保 'e' 至少出現 1 次，'o' 至少出現 2 次，'l' 至少出現 1 次。
>
>3. **返回符合條件的字串**：
>   - 如果 `words1` 中的某個字串滿足上述條件，我們將其加入結果列表。
>
>### 原理
>
>這個方法的核心原理是確保 `words1` 中的每個字串都包含 `words2` 中所有字串的所有字母，且每個字母的出現次數不少於 `words2` 中的最大出現次數。這樣，我們就能找到所有符合條件的「通用字串」。
>
>### 具體範例
>
>假設 `words1` = ["amazon", "apple", "facebook"]，`words2` = ["e", "oo"]。
>
>1. 計算 `words2` 中每個字母的最大出現次數：
>   - 'e' 出現 1 次
>   - 'o' 出現 2 次
>
>2. 檢查 `words1` 中的每個字串：
>   - "amazon"：'e' 出現 1 次，'o' 出現 1 次（不符合條件）
>   - "apple"：'e' 出現 1 次，'o' 出現 0 次（不符合條件）
>   - "facebook"：'e' 出現 1 次，'o' 出現 2 次（符合條件）
>
>3. 返回符合條件的字串：
>   - 結果是 ["facebook"]
>

```CPP
class Solution {
public:
    vector<string> wordSubsets(vector<string>& words1, vector<string>& words2) {
        int maxCharFreq[26] = {0}, tempCharFreq[26] = {0};
        // 計算 words2 中每個字母的最大出現次數
        for(auto word2 : words2){
            fill(tempCharFreq, tempCharFreq + 26, 0);
            for(auto ch : word2){
                tempCharFreq[ch - 'a']++;
            }
            for(int i = 0 ; i < 26 ; i++){
                maxCharFreq[i] = max(maxCharFreq[i], tempCharFreq[i]);
            }
        }
        vector<string> ans;
        // 檢查 words1 中的每個字串
        for(auto word1 : words1){
            fill(tempCharFreq, tempCharFreq + 26, 0);
            for(auto ch : word1){
                tempCharFreq[ch - 'a']++;
            }
            bool check = true;
            for(int i = 0 ; i < 26 ; i++){
                if(tempCharFreq[i] < maxCharFreq[i]){
                    check = false;
                    break;
                }
            }
            if(check) ans.push_back(word1);
        }
        return ans;
    }
};
```
