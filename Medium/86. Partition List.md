# 86. Partition List
Problem : [HERE](https://leetcode.com/problems/partition-list/description/)

>[!TIP]
>LeetCode 第 86 題「Partition List」的解題思路如下：
>
>---
>
>### 🧩 題目描述：
>給定一個單向鏈結串列 `head` 和一個值 `x`，將鏈結串列重新排列，使得所有小於 `x` 的節點都出現在大於或等於 `x` 的節點之前。你應該保留每個節點的原始相對順序。
>
>---
>
>### 💡 解題思路：
>
>這題的核心是**分成兩個鏈結串列**，然後再把它們接起來：
>
>1. **建立兩個虛擬頭節點（dummy nodes）**：
>   - 一個用來儲存小於 `x` 的節點（稱為 `before`）
>   - 一個用來儲存大於或等於 `x` 的節點（稱為 `after`）
>
>2. **遍歷原始鏈結串列**：
>   - 如果節點的值小於 `x`，就接到 `before` 的尾端
>   - 否則接到 `after` 的尾端
>
>3. **合併兩個鏈結串列**：
>   - 把 `before` 的尾端接到 `after` 的頭部
>   - 記得把 `after` 的尾端設為 `null`，避免形成環
>
>4. **回傳新的頭節點**：
>   - 即 `before` 的下一個節點
>
>---
>
>### ✅ 時間與空間複雜度：
>
>- **時間複雜度**： $$O(n)$$，遍歷一次鏈結串列
>- **空間複雜度**： $$O(1)$$，只使用了常數額外空間（除了 dummy nodes）
>
>---




```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* partition(ListNode* head, int x) {
        if(head == NULL) return NULL;
        queue<ListNode*> greaterQueue;
        queue<ListNode*> lessQueue;
        ListNode* temp = head;
        while(temp){
            if(temp -> val >= x) greaterQueue.push(temp);
            else lessQueue.push(temp);
            temp = temp -> next;
        }
        if(!lessQueue.empty()) {
            head = lessQueue.front();
            lessQueue.pop();
            temp = head;
            while(!lessQueue.empty()){
                temp -> next = lessQueue.front();
                lessQueue.pop();
                temp = temp -> next;
            }            
            if(!greaterQueue.empty()){
                temp -> next = greaterQueue.front();
                greaterQueue.pop();
                temp = temp -> next;
                while(!greaterQueue.empty()){
                    temp -> next = greaterQueue.front();
                    greaterQueue.pop();
                    temp = temp -> next;
                }
            }
            temp -> next = NULL;
        }
        else{
            head = greaterQueue.front();
            greaterQueue.pop();
            temp = head;
            while(!greaterQueue.empty()){
                temp -> next = greaterQueue.front();
                greaterQueue.pop();
                temp = temp -> next;            
            }
            temp -> next = NULL;
        }
        return head;

    }
};
```
