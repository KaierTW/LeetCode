# 2064. Minimized Maximum of Products Distributed to Any Store
Problem : [HERE](https://leetcode.com/problems/minimized-maximum-of-products-distributed-to-any-store/description/)

>[!TIP]
>這段程式碼：
>
>```CPP
>(q + mid - 1) / mid
>```
>
>是一種常見的「天花板除法」技巧，計算在整除的情況下，如何得到商的「向上取整」結果。
>
>### 用途說明
>
>當我們有一個數 `q`，並且希望以 `mid` 為分配單位，把 `q` 分成不超過 `mid` 的「份數」時，可以使用這個技巧。
>
>### 原理
>
>通常 `q / mid` 會給出整數商，**向下取整**結果。例如，如果 `q = 11` 且 `mid = 5`：
>
>- `q / mid` 會給出 2，因為 \( 11 \div 5 = 2.2 \)，向下取整得到 2。
>- 但實際上，11 可以分成 3 個包含不多於 5 的份數（5, 5, 1）。
>
>這時，如果我們希望得到「向上取整」的效果，可以用這個公式：
>
>```CPP
>(q + mid - 1) / mid
>```
>
>它的原理是先對 `q` 加上 `mid - 1`，這樣會在不完全整除的情況下多加 1，保證結果往上取整。
>
>### 例子
>
>- 當 \( q = 11 \)、\( mid = 5 \) 時：
>
> \[
>  (11 + 5 - 1) // 5 = 15 // 5 = 3
>  \]
>
>  得到的結果是 3，表示我們需要 3 個「不超過 5」的份數來容納 11。
>
>- 當 \( q = 10 \)、\( mid = 5 \) 時：
>
>  \[
>  (10 + 5 - 1) // 5 = 14 // 5 = 2
>  \]
>
>  結果是 2，正確地反映了 10 可以分成兩個 5。
>
>### 應用場合
>
>這個技巧經常出現在以下場景：
>
>1. 需要將數字 `q` 分成若干份，每份不超過 `mid`。
>2. 二分搜尋或分配問題中，需要確保分配結果向上取整以符合條件。
>![image](https://github.com/user-attachments/assets/16212874-09bc-4419-92d7-8498704beb89)

>[!TIP]
>在這段二分搜尋的程式碼中：
>
>```python
>if canDistribute(mid):
>    right = mid  # 可以分配，嘗試更小的最大配額
>else:
>    left = mid + 1  # 不可分配，需要更大的最大配額
>```
>
>**不需要讓 `right` 減 1** 的原因在於，這個二分搜尋的結束條件是 `left == right`，並且我們想保留可能的解 `mid`。具體來說，這裡的 `right` 代表的是「可能的最大配額上限」，在 `canDistribute(mid)` 可行的情況下，我們希望繼續縮小這個上限，而不是跳過這個值。
>
>### 詳細解釋
>
>1. **二分搜尋的範圍設置：**
>   - 在這個問題中，`left` 和 `right` 一開始分別代表了最小可能的「最大分配數量」（通常是 1）和最大可能的「最大分配數量」（通常是 `max(quantities)`）。
>   - 二分搜尋的目標是縮小 `left` 和 `right` 的範圍，最終收斂到唯一解。
>
>2. **`canDistribute(mid)` 的含義：**
>   - 如果 `canDistribute(mid)` 返回 `True`，表示我們能夠在「每家商店最多分配 `mid` 個產品」的條件下，完成產品的分配。因此 `mid` 是一個可行的解，甚至可能是最優解（即最小的最大分配數量）。
>   - 因此，當 `canDistribute(mid)` 為 `True` 時，我們將 `right` 更新為 `mid`，而不減 1，這樣可以保留當前的 `mid` 作為一個可能的解，並繼續尋找更小的最大分配數量。
>
>3. **不使用 `right = mid - 1` 的原因：**
>   - 如果將 `right` 設為 `mid - 1`，可能會跳過一個符合條件的候選解。例如，如果 `mid` 本身就是我們要找的最小解，減去 1 可能會錯過這個值。
>   - 而直接設置 `right = mid`，可以保留當前的 `mid`，確保不會漏掉任何可能的解，這樣最終 `left` 和 `right` 會在收斂時指向相同的最小值。
>
>4. **終止條件 `left == right`：**
>   - 在二分搜尋的結束時，`left` 和 `right` 會收斂到同一個數字，這個數字就是最小的最大分配數量。
>   - 保持 `right = mid` 可以讓 `left` 和 `right` 漸漸逼近，最終不會漏掉任何可能的解。
>
>### 小結
>
>這段程式碼的設計是為了確保每一個可能的解都被考慮到，因此在 `canDistribute(mid)` 為 `True` 的情況下，我們僅更新 `right = mid` 而不減去 1，避免跳過可能的解。同樣地，在 `canDistribute(mid)` 為 `False` 的情況下，將 `left` 設為 `mid + 1`，以尋找更大的最大分配數量。

```CPP
class Solution {
public:
    int minimizedMaximum(int n, vector<int>& quantities) {
        // Use Binary Search
        //最小值是每一個商店都分配一個商品
        //最大值是所有商品都分配給同一個商店
        int left = 1 , right = 100000;
        while(left < right){
            int mid = (left + right) / 2;
            if(canDistributed(n , quantities , mid)) left = mid + 1;
            else right = mid;
        }
        return left;
    }
    bool canDistributed(int n , vector<int>& quantities , int mid){
        int store = 0;
        for(int q : quantities){
            //向上取整
            store += (q + mid - 1) / mid;
        }
        //商店比較多代表這個方法可行
        return store > n;
    }
};
```
