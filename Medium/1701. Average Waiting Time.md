# 1701. Average Waiting Time

Problem : [HERE](https://leetcode.com/problems/crawler-log-folder/description)

>[!TIP]
>主要是要判斷廚師的時間有沒有超過客人進來的時間
>
>有的話就要先以廚師的時間做計算
>
>沒有的話就從客人進來的時間計算

```C
double averageWaitingTime(int** customers, int customersSize, int* customersColSize) {
    double waitTime = 0.0;
    int chefTime = customers[0][0];
    for(int i = 0 ; i < customersSize ; i++){
        if(chefTime < customers[i][0]){
            chefTime = customers[i][0] + customers[i][1];
        }
        else{
            chefTime += customers[i][1];
        }
        
        waitTime += chefTime - customers[i][0];
    }
    return waitTime / customersSize;
}
```
