# 289. Game of Life
Problem : [HERE]()


>[!TIP]
>題目「289. Game of Life」是基於數學家John Horton Conway創造的細胞自動機。這個遊戲使用一個m x n的網格，每個格子代表一個細胞，細胞可以是活的（用1表示）或死的（用0表示） [1](https://algo.monster/liteproblems/289) [2](https://leetcode.com/problems/game-of-life/)。
>
>遊戲的進程是通過一系列規則來決定每個細胞的下一代狀態
>1. 任何活細胞如果周圍少於兩個活細胞，則會因為人口不足而死亡。
>2. 任何活細胞如果周圍有兩個或三個活細胞，則會繼續存活到下一代。
>3. 任何活細胞如果周圍有超過三個活細胞，則會因為人口過多而死亡。
>4. 任何死細胞如果周圍正好有三個活細胞，則會因為繁殖而變成活細胞。
>
>這些規則同時應用於每個細胞，並且需要在不改變原始狀態的情況下計算下一代的狀態
>
>解題「289. Game of Life」的思路可以分為以下幾個步驟
>
>1. **理解規則**：每個細胞的下一代狀態取決於其周圍八個鄰居的狀態。根據這些規則來決定細胞是存活還是死亡。
>
>2. **使用中間狀態**：為了在不使用額外空間的情況下更新網格，可以使用中間狀態來表示細胞的變化：
>   - 用 `2` 表示一個活細胞將變成死細胞。
>   - 用 `-1` 表示一個死細胞將變成活細胞。
>
>3. **遍歷網格**：遍歷每個細胞，計算其周圍的活細胞數量，並根據規則更新其狀態為中間狀態。
>
>4. **應用變化**：再次遍歷網格，將中間狀態更新為最終狀態：
>   - 將 `2` 變為 `0`（死細胞）。
>   - 將 `-1` 變為 `1`（活細胞）。
>
>這樣可以確保所有細胞的變化是同步的，而不會影響其他細胞的計算




```CPP
class Solution {
public:
    int FindLiveNeighbors(int row, int column, vector<vector<int>>& board){
        int rowSize = board.size();
        int columnSize = board[0].size();
        int liveNeighbors = 0;
        for(int r = max(row - 1, 0) ; r <= min(row + 1, rowSize - 1) ; r++) {
            for(int c = max(column - 1, 0) ; c <= min(column + 1, columnSize - 1) ; c++) {
                if(r == row & c == column) continue;
                else{
                    if(board[r][c] == 1 || board[r][c] == -10) liveNeighbors++;
                }
            }
        }
        return liveNeighbors;
    }
    
    void gameOfLife(vector<vector<int>>& board) {
        // 10: die to live, -10: live to die;
        int row = board.size();
        int column = board[0].size();
        for(int r = 0 ; r < row ; r++){
            for(int c = 0 ; c < column ; c++){                              
                // Find live neighbors
                int liveNeighbors = FindLiveNeighbors(r, c, board);
                if(board[r][c] == 1 && (liveNeighbors < 2 || liveNeighbors > 3)) board[r][c] = -10;                                
                if(board[r][c] == 0 && liveNeighbors == 3) board[r][c] = 10;
            }
        }
        for(int r = 0 ; r < row ; r++){
            for(int c = 0 ; c < column ; c++){
                if(board[r][c] == -10) board[r][c] = 0;
                else if(board[r][c] == 10) board[r][c] = 1;
            }
        }
    }    
};
```
