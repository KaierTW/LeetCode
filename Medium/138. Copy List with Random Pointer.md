# 138. Copy List with Random Pointer
Problem : [HERE](https://leetcode.com/problems/copy-list-with-random-pointer/description/)

>[!TIP]
>LeetCode 第 138 題「**Copy List with Random Pointer**」的題目意思如下：
>
>---
>
>### 🧩 題目描述：
>
>你會得到一個特殊的**鏈表（Linked List）**，每個節點除了有一個 `next` 指針指向下一個節點外，還有一個 `random` 指針，這個 `random` 指針可以指向鏈表中的任意一個節點，或者是 `null`。
>
>你的任務是：**複製這個鏈表**，也就是建立一個**深拷貝（deep copy）**，使得新鏈表的每個節點都和原鏈表的節點有相同的值，並且 `next` 和 `random` 指針的結構也完全一致。
>
>---
>
>### 📌 要求：
>
>- 新鏈表中的節點必須是**全新的節點**（不能是原鏈表的節點）。
>- `random` 指針的指向也要和原鏈表一致。
>- 返回新鏈表的頭節點。
>
>---
>
>### 🧪 範例：
>
>#### 範例 1：
>輸入：
>```
>head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
>```
>這表示：
>- 第一個節點值是 7，random 是 null
>- 第二個節點值是 13，random 指向第 0 個節點（值為 7）
>- 依此類推...
>
>輸出：
>```
>[[7,null],[13,0],[11,4],[10,2],[1,0]]
>```
>表示你成功複製了一個一模一樣的鏈表。
>
>---
>
>### 🧠 解題思路簡述：
>
>1. **使用 HashMap**：建立原節點到新節點的映射，先複製所有節點，再設定 `next` 和 `random`。
>2. **不使用額外空間的技巧**：將新節點插入到原節點之後，形成交錯結構，然後再設定 `random`，最後拆分成兩個鏈表。
>
>---
>

```CPP
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* next;
    Node* random;
    
    Node(int _val) {
        val = _val;
        next = NULL;
        random = NULL;
    }
};
*/

class Solution {
public:
    Node* copyRandomList(Node* head) {
        if(head == NULL) return NULL;
        unordered_map<Node*, Node*> uom_Node;
        Node* currentNode = head;
        // Step 1: 建立原節點到新節點的映射       
        while(currentNode){
            uom_Node[currentNode] = new Node(currentNode -> val);
            currentNode = currentNode -> next;
        }
        // Step 2: 設定新節點的 next 和 random
        currentNode = head;
        while(currentNode){
            uom_Node[currentNode] -> next = uom_Node[currentNode -> next];
            uom_Node[currentNode] -> random = uom_Node[currentNode -> random];
            currentNode = currentNode -> next;
        }
        return uom_Node[head];
    }
};
```
