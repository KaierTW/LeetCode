# 1590. Make Sum Divisible by P
Problem : [HERE](https://leetcode.com/problems/make-sum-divisible-by-p/description/)

>[!TIP]
>這個公式是基於**區間和**和**模運算**的性質，幫助我們理解如何找到一段符合條件的子陣列。
>
>讓我來逐步解釋這個公式的來歷和含義。
>
>### 區間和與模數
>
>假設我們有一個陣列 `nums`，定義它的**前綴和**（`prefix_sum[j]`）為從陣列的開頭一直加到索引 `j` 的累積和：
>
>```
>prefix_sum[j] = nums[0] + nums[1] + ... + nums[j]
>```
>
>同樣地，`prefix_sum[i]` 是從開頭累積到索引 `i` 的和。
>
>那麼從 `i+1` 到 `j` 這段區間的和可以表示為：
>
>```
>sum(i+1 to j) = prefix_sum[j] - prefix_sum[i]
>```
>
>我們的目標是找到一個子陣列，使得這段區間和模 `p`（即 `sum(i+1 to j) % p`）等於某個給定的 `target_mod`。
>
>### 關於模數的公式變形
>
>對於這段區間和，我們要求它模 `p` 等於 `target_mod`，即：
>
>```
>(prefix_sum[j] - prefix_sum[i]) % p = target_mod
>```
>
>這就是說，從 `i+1` 到 `j` 的區間和模 `p` 等於 `target_mod`。我們需要利用這個公式來找到符合條件的 `i` 和 `j`。
>
>根據模運算的性質，如果我們要滿足上述條件，可以將它變形如下：
>
>```
>prefix_sum[j] % p = (prefix_sum[i] + target_mod) % p
>```
>
>這個公式的意思是：**當前的前綴和 `prefix_sum[j]` 的模數應該等於之前某個前綴和 `prefix_sum[i]` 的模數加上 `target_mod`**。
>
>### 這個公式的意圖
>
>這個公式的用處是讓我們能夠快速找到符合條件的區間。具體來說，`prefix_sum[j] % p` 是我們當前位置的前綴和模 `p`，而我們想要找到一個之前的前綴和模數 `prefix_sum[i]`，使得這兩者之間的區間和正好符合目標 `target_mod`。
>
>### 舉例解釋
>
>假設我們有一個陣列 `nums = [3, 1, 4, 2]`，`p = 6`，並且總和模 `p` 為 `total_sum % p = 4`，那麼我們需要找到一段子陣列，其和模 `p` 等於 `target_mod = 4`。
>
>我們逐步計算每個位置的前綴和模數：
>
>- 當 `j = 0` 時，`prefix_sum[0] = 3`，`prefix_sum[0] % p = 3`。
>- 當 `j = 1` 時，`prefix_sum[1] = 3 + 1 = 4`，`prefix_sum[1] % p = 4`。
>- 當 `j = 2` 時，`prefix_sum[2] = 3 + 1 + 4 = 8`，`prefix_sum[2] % p = 8 % 6 = 2`。
>- 當 `j = 3` 時，`prefix_sum[3] = 3 + 1 + 4 + 2 = 10`，`prefix_sum[3] % p = 10 % 6 = 4`。
>
>根據我們的公式，當 `prefix_sum[j] % p = 4`，我們希望找到之前的 `prefix_sum[i] % p`，使得 `(prefix_sum[j] - prefix_sum[i]) % p = 4`，也就是：
>
>```
>prefix_sum[j] % p = (prefix_sum[i] + target_mod) % p
>```
>
>如果 `prefix_sum[j] % p = 4` 且我們要找的 `target_mod` 也是 4，那麼我們希望 `prefix_sum[i] % p` 等於 `0`，這樣區間和正好等於 4。
>
>這個公式幫助我們快速定位是否有符合條件的前綴和模數，從而確定一段符合條件的區間。
>
>### 小結
>
>`prefix_sum[j] % p = (prefix_sum[i] + target_mod) % p` 的含義是：
>
>- 我們當前位置的前綴和模數 `prefix_sum[j] % p`，應該等於之前某個位置的前綴和模數 `prefix_sum[i] % p` 加上目標模數 `target_mod`。
>- 這個公式幫助我們在遍歷過程中快速定位是否存在一個符合條件的區間，使得該區間的和模 `p` 等於 `target_mod`。
>
>這樣，我們可以利用哈希表來記錄之前的前綴和模數，從而在常數時間內查找符合條件的區間。
>

```CPP
class Solution {
public:
    int minSubarray(vector<int>& nums, int p) {        
    // STEP 1: 計算整個陣列的總和 total_sum 並計算它的模數 total_sum % p
    int total_sum = 0;
    for (int num : nums) {
        total_sum = (total_sum + num) % p;
    }
    
    // 如果總和 total_sum 已經是 p 的倍數，直接返回 0
    if (total_sum == 0) return 0;
    
    int target_mod = total_sum;  // 我們需要找的子陣列的模數目標是 target_mod = total_sum % p
    unordered_map<int, int> prefix_mod_map;  // 記錄每個前綴和模 p 出現的位置
    prefix_mod_map[0] = -1;  // 為了處理從開頭開始的情況，我們預設 0 出現在索引 -1
    int current_sum = 0;     // 用來累計當前的前綴和
    int min_len = nums.size();  // 初始化最小子陣列長度為陣列的大小（即最壞情況）

    // STEP 2: 遍歷 nums，逐步累加當前的前綴和，並通過哈希表來檢查符合條件的子陣列
    for (int i = 0; i < nums.size(); ++i) {
        current_sum = (current_sum + nums[i]) % p;
        
        // 計算需要的 target (previous_sum)，公式為 (current_sum - target_mod + p) % p
        int target = (current_sum - target_mod + p) % p;
        
        // 如果哈希表中存在這個 target，表示存在一個之前的前綴和符合條件
        if (prefix_mod_map.find(target) != prefix_mod_map.end()) {
            min_len = min(min_len, i - prefix_mod_map[target]);
        }
        
        // 記錄當前前綴和模數出現的位置
        prefix_mod_map[current_sum] = i;
    }
    
    // 如果找到符合條件的子陣列，返回最小長度，否則返回 -1
    return min_len == nums.size() ? -1 : min_len;
    }
};
```
