# 2429. Minimize XOR
Problem : [HERE](https://leetcode.com/problems/minimize-xor/description/)

>[!TIP]
>這題的核心思想是要找到一個數字，使得它與給定的數字進行 XOR 運算後的結果最小，並且它的二進位表示中 1 的數量與另一個給定數字相同。這裡的關鍵在於如何有效地選擇這個數字。
>
>### 原理解釋
>
>1. **計算 num2 中 1 的數量**：
>   我們首先使用 `__builtin_popcount` 函數來計算 `num2` 中 1 的數量。這是因為我們需要找到一個數字，其二進位表示中 1 的數量與 `num2` 相同。
>
>2. **優先設置 num1 中的高位 1**：
>   為了使 XOR 結果最小，我們希望新數字的高位與 `num1` 的高位盡可能相同。這樣可以確保在高位上的差異最小，從而使整體的 XOR 結果最小。因此，我們從最高位開始，逐位檢查 `num1` 的每一位，如果該位是 1，則在結果數字中也設置該位為 1，並減少需要設置的 1 的數量。
>
>3. **設置剩餘的低位 1**：
>   如果在設置完 `num1` 的高位 1 之後，還有剩餘的 1 需要設置，我們就從最低位開始，逐位設置結果數字中的 0 為 1。這樣可以確保我們設置的 1 的數量正好與 `num2` 中的 1 的數量相同。
>
>### 具體步驟
>
>1. **計算 `num2` 中 1 的數量**：
>   ```cpp
>   int count = __builtin_popcount(num2);
>   ```
>
>2. **優先設置 `num1` 中的高位 1**：
>   ```cpp
>   for (int i = 31; i >= 0 && count > 0; --i) {
>       if (num1 & (1 << i)) {
>           result |= (1 << i);
>           --count;
>       }
>   }
>   ```
>
>3. **設置剩餘的低位 1**：
>   ```cpp
>   for (int i = 0; i <= 31 && count > 0; ++i) {
>       if (!(result & (1 << i))) {
>           result |= (1 << i);
>           --count;
>       }
>   }
>   ```
>
>這樣，我們就能找到一個數字，使得它與 `num1` 進行 XOR 運算後的結果最小，並且它的二進位表示中 1 的數量與 `num2` 相同。
>


```CPP
class Solution {
public:
    
    int minimizeXor(int num1, int num2) {
        //理想情況是找到跟num1一樣的，因為自己XOR自己會是0
        int howManyOneInNum2 = __builtin_popcount(num2);
        int ans = 0;
        for(int i = 31 ; i > 0 ; i--){
            /* 優先設置 num1 中的高位 1
               為了使 XOR 結果最小，我們希望新數字的高位與 num1 的高位盡可能相同。
               這樣可以確保在高位上的差異最小，從而使整體的 XOR 結果最小。
               因此，我們從最高位開始，逐位檢查 num1 的每一位，
               如果該位是 1，則在結果數字中也設置該位為 1，並減少需要設置的 1 的數量。
            */

            // num1 & (1 << i) 可以確認第i位是不是0                       
            if(num1 & (1 << i) && howManyOneInNum2 > 0){
                ans |= (1 << i);
                howManyOneInNum2--;
            }
        }
        /* 設置剩餘的低位 1
           如果在設置完 num1 的高位 1 之後，還有剩餘的 1 需要設置，我們就從最低位開始，
           逐位設置結果數字中的 0 為 1。這樣可以確保我們設置的 1 的數量正好與 num2 中的 1 的數量相同。
        */
        for(int i = 0 ; i < 32 && howManyOneInNum2 > 0 ; i++){
            //如果第i位不是0
            if(!(ans & (1 << i))){
                ans |= (1 << i);
                howManyOneInNum2--;
            }
        }
        return ans;

    }
};
```
