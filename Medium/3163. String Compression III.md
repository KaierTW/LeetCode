# 3163. String Compression III
Problem : [HERE](https://leetcode.com/problems/string-compression-iii/description)

>[!TIP]
>這題滿簡單，就按照題目一個一個數就好

```CPP
class Solution {
public:
    string compressedString(string word) {
        string ans;
        int count = 1;
        for(int i = 0 ; i < word.size() - 1 ; i++){
            if(word[i] == word[i + 1] && count < 9) count++;
            else{
                ans += ('0' + count);
                ans += word[i];
                count = 1;
            }
        }
        ans += ('0' + count);
        ans += word[word.size() - 1];
        return ans;
    }
};
```
