# 82. Remove Duplicates from Sorted List II
Problem : [HERE](https://leetcode.com/problems/remove-duplicates-from-sorted-list-ii/description/)

>[!TIP]
>LeetCode 第 82 題「Remove Duplicates from Sorted List II」的解題思路如下：
>
>---
>
>### 🧩 題目描述：
>給定一個**已排序**的鏈結串列，刪除所有重複的元素，只保留**沒有重複**出現的節點。
>
>例如：
>- 輸入：`1 -> 2 -> 3 -> 3 -> 4 -> 4 -> 5`
>- 輸出：`1 -> 2 -> 5`
>
>---
>
>### 🔍 解題思路：
>
>由於鏈結串列是**排序好的**，重複的元素會**連續出現**，這讓我們可以一次性跳過所有重複的節點。
>
>#### ✅ 步驟：
>
>1. **使用虛擬頭節點（dummy node）**：
>   - 為了處理頭節點可能被刪除的情況，建立一個 dummy node 指向 head。
>
>2. **使用兩個指標**：
>   - `prev`：指向最後一個確定不重複的節點。
>   - `current`：用來遍歷整個鏈結串列。
>
>3. **檢查重複**：
>   - 如果 `current.val == current.next.val`，表示有重複，記錄這個值。
>   - 跳過所有值相同的節點。
>   - 然後把 `prev.next` 指向下一個不重複的節點。
>
>4. **如果沒有重複**：
>   - 就把 `prev` 往前移動。
>
>---
>
>### 🧠 小技巧：
>- 使用 dummy node 是處理鏈結串列問題的常見技巧，尤其是當頭節點可能會被刪除時。
>- 這題的關鍵是**一次性跳過所有重複的節點**，而不是逐個刪除。
>
>---




```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {
        ListNode* vHead = new ListNode();        
        vHead -> next = head;
        ListNode* distinctNode = vHead;
        ListNode* currentNode = head;
        while(currentNode){
            // 重複
            if(currentNode -> next && currentNode -> val == currentNode -> next -> val){
                int duplicateVal = currentNode -> val;
                // 跳過重複的節點
                while(currentNode && currentNode -> val == duplicateVal){
                    currentNode = currentNode -> next;
                }
                // 連接不重複的節點
                distinctNode -> next = currentNode;                
            }
            else{
                distinctNode = distinctNode -> next;
                currentNode = currentNode -> next;
            }
        }
        return vHead -> next;
    }
};
```
