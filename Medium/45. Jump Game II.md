# 45. Jump Game II
Problem : [HERE](https://leetcode.com/problems/jump-game-ii/description/)

>[!TIP]
>Jump Game II 是一道經典的動態規劃問題。目標是找到從數組的第一個元素跳到最後一個元素所需的最少跳躍次數。這裡有一個簡單的解法：
>
>### 解法思路
>1. **初始化**：設置 `ans` 為 0（跳躍次數），`end` 為 0（當前層的結束位置），`farthest` 為 0（能跳到的最遠位置）。
>2. **遍歷數組**：使用一個隱式的廣度優先搜索（BFS）來遍歷數組。
>3. **更新最遠位置**：對於每個元素，更新 `farthest` 為 `max(farthest, i + nums[i])`。
>4. **檢查是否到達終點**：如果 `farthest` 超過或等於數組的最後一個位置，增加 `ans` 並結束循環。
>5. **更新層次**：如果遍歷到當前層的結束位置，增加 `ans` 並更新 `end` 為 `farthest`。
>
>### 代碼示例
>以下是使用 C++ 的代碼示例：
>
>```cpp
>class Solution {
>public:
>    int jump(vector<int>& nums) {
>        int ans = 0;
>        int end = 0;
>        int farthest = 0;
>        for (int i = 0; i < nums.size() - 1; ++i) {
>            farthest = max(farthest, i + nums[i]);
>            if (farthest >= nums.size() - 1) {
>                ++ans;
>                break;
>            }
>            if (i == end) {
>                ++ans;
>                end = farthest;
>            }
>        }
>        return ans;
>    }
>};
>```
>
>這個解法的時間複雜度是 $$O(n)$$，空間複雜度是 $$O(1)$$[1](https://walkccc.me/LeetCode/problems/45/)[2](https://neetcode.io/solutions/jump-game-ii)[3](https://algo.monster/liteproblems/45)。

```CPP
class Solution {
public:
    int jump(vector<int>& nums) {
        int count = 0, endPos = 0, farPos = 0;
        for(int i = 0 ; i < nums.size() - 1 ; i++){
            farPos = max(farPos, i + nums[i]);
            if(farPos >= nums.size() - 1){
                count++;
                break;
            }
            if(i == endPos){
                count++;
                endPos = farPos;
            }
        }
        return count;
    }
};
```
