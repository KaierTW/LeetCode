# 150. Evaluate Reverse Polish Notation
Problem : [HERE](https://leetcode.com/problems/evaluate-reverse-polish-notation/description/)

>[!TIP]
>這題 LeetCode 150：「**Evaluate Reverse Polish Notation**」的解題思路可以分成以下幾個步驟，主要是使用 **堆疊（stack）** 來處理逆波蘭表示法的運算：
>
>---
>
>### 🧠 解題思路：
>
>1. **初始化一個堆疊（stack）**，用來存放數字。
>2. **遍歷整個 `tokens` 陣列**：
>   - 如果是數字（例如 `"2"`、`"-3"`），就轉成整數後推入堆疊。
>   - 如果是運算符號（例如 `"+"`、`"-"`、`"*"`、`"/"`）：
>     - 從堆疊中**彈出兩個數字**（注意順序：先彈出的為右操作數，後彈出的為左操作數）。
>     - 根據運算符號進行計算。
>     - 把結果再推入堆疊。
>3. **最後堆疊中只剩下一個數字**，就是答案。
>
>---
>
>### 📌 注意事項：
>
>- 除法是**整數除法**，而且要**向零取整**（LeetCode 題目有特別說明）。
>- 運算順序要注意：例如 `"4" "13" "5" "/" "+"` → `13 / 5` 是右除左。
>
>---
>

```CPP
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int>stk;
        for(string token : tokens) {            
            if (token != "+" && token != "-" && token != "*" && token != "/") {
                stk.push(stoi(token));
            } 
            else {
                int a = stk.top(); stk.pop();
                int b = stk.top(); stk.pop();
                if (token == "+") stk.push(b + a);
                else if (token == "-") stk.push(b - a);
                else if (token == "*") stk.push(b * a);
                else if (token == "/") stk.push(b / a);
            }
       }
       return stk.top();
    }
};
```
