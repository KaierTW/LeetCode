# 2583. Kth Largest Sum in a Binary Tree
Problem : [HERE](https://leetcode.com/problems/kth-largest-sum-in-a-binary-tree/description/)

>[!TIP]
>在二元樹中，有幾種常見的搜尋方法：
>
>1. 前序遍歷 (Pre-order Traversal): 先訪問根節點，再訪問左子樹，最後訪問右子樹。
>
>2. 中序遍歷 (In-order Traversal): 先訪問左子樹，再訪問根節點，最後訪問右子樹。
>
>3. 後序遍歷 (Post-order Traversal): 先訪問左子樹，再訪問右子樹，最後訪問根節點。
>
>4. 層序遍歷 (Level-order Traversal): 按照樹的層次逐層訪問節點。
>
>你提到的「先找左邊再找右邊，再回到中間」的方法是後序遍歷 (Post-order Traversal)。這種方法在某些應用中非常有用，例如刪除樹中的節點或計算樹的高度

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    long long kthLargestLevelSum(TreeNode* root, int k) {
        unordered_map<long long ,long long> sums;
        long long level = 1;
        findSum(root , sums , level);
        vector<long long> sort_sum;
        for(const auto& sum : sums){
            sort_sum.push_back(sum.second);
        }

        sort(sort_sum.begin() , sort_sum.end() , greater<long long>());
        if(k <= sort_sum.size()){
            return sort_sum[k - 1];
        }
        else return -1;
    }
    void findSum(TreeNode* node , unordered_map<long long , long long>& sums , long long level){
        if(node == NULL) return;
        sums[level] += node -> val;
        findSum(node -> left , sums , level + 1);
        findSum(node -> right , sums , level + 1);
    }
};
```
