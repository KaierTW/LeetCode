# 7. Reverse Integer
Problem : [HERE](https://leetcode.com/problems/reverse-integer/description/)

>[!TIPS]
>資料型態大小 char  1 bytes ， short  2 byte ， int  4 bytes ， long  8 bytes long int  8 bytes ， long long  8 bytes ， long long int  8 bytes ， long double  16 bytes

```C
int reverse(int x){
    long int ans = 0;
    while(x != 0){
        ans = ans * 10 + x % 10;
        x /= 10;
        if(ans > INT_MAX || ans < INT_MIN) return 0;
    }
    return ans;
}
```
