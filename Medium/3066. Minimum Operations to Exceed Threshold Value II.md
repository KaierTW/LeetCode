# 3066. Minimum Operations to Exceed Threshold Value II
Problem : [HERE](https://leetcode.com/problems/minimum-operations-to-exceed-threshold-value-ii/description/)

>[!TIP]
>
>### 解題思路
>1. **初始化最小堆**：
>   - 使用 C++ 的 `priority_queue` 並指定比較函數來創建一個最小堆，將數組 `nums` 中的所有元素加入到最小堆中。
>
>2. **進行操作**：
>   - 設置一個計數器 `operations` 來記錄操作次數。
>   - 當最小堆中的最小元素小於 `k` 時，重複以下步驟：
>     1. 從最小堆中取出兩個最小的元素 `x` 和 `y`。
>     2. 計算新元素 `new_element = min(x, y) * 2 + max(x, y)`。
>     3. 將 `new_element` 插入到最小堆中。
>     4. 增加操作次數 `operations`。
>
>3. **返回結果**：
>   - 當最小堆中的所有元素都大於或等於 `k` 時，返回操作次數 `operations`。


>[!TIP]
>這行代碼使用了 C++ 標準模板庫（STL）中的 `priority_queue` 來創建一個最小堆。讓我們來分解這行代碼並詳細解釋其用法：
>
>### `priority_queue` 模板
>`priority_queue` 是一個模板類，它提供了一個優先佇列的實現。默認情況下，`priority_queue` 是一個最大堆，即每次取出的元素都是當前佇列中的最大值。
>
>### 模板參數
>`priority_queue` 模板接受三個參數：
>1. **Type**：元素的數據類型。在這裡是 `int`。
>2. **Container**：底層容器類型。默認是 `vector`，這裡也使用 `vector<int>`。
>3. **Compare**：比較函數對象，用於決定元素的優先級。默認是 `less<T>`，這裡使用 `greater<int>` 來創建最小堆。
>
>### 具體代碼解釋
>```cpp
>priority_queue<int, vector<int>, greater<int>> minHeap(nums.begin(), nums.end());
>```
>- **`priority_queue<int, vector<int>, greater<int>>`**：這部分定義了一個優先佇列，其中元素類型為 `int`，底層容器為 `vector<int>`，並使用 `greater<int>` 作為比較函數，從而創建一個最小堆。
>- **`minHeap`**：這是優先佇列的變量名。
>- **`nums.begin(), nums.end()`**：這部分將 `nums` 數組中的所有元素初始化到優先佇列中。
>
>### 最小堆的行為
>使用 `greater<int>` 作為比較函數，`priority_queue` 會將最小的元素放在堆頂，因此每次調用 `top()` 都會返回當前佇列中的最小值。
>
>### 代碼示例
>以下是一個簡單的示例，展示如何使用這種優先佇列：
>```cpp
>#include <iostream>
>#include <vector>
>#include <queue>
>
>using namespace std;
>
>int main() {
>    vector<int> nums = {2, 11, 10, 1, 3};
>    priority_queue<int, vector<int>, greater<int>> minHeap(nums.begin(), nums.end());
>
>    // 輸出最小堆中的元素
>    while (!minHeap.empty()) {
>        cout << minHeap.top() << " ";
>        minHeap.pop();
>    }
>    // 輸出：1 2 3 10 11
>
>    return 0;
>}
>```
>在這個示例中，`minHeap` 是一個最小堆，並且我們依次取出並輸出堆頂元素，結果是按從小到大的順序輸出。


```CPP
class Solution {
public:
    int minOperations(vector<int>& nums, int k) {
        // 使用 greater<int> 創建最小堆
        priority_queue<long long, vector<long long>, greater<long long>> pq(nums.begin(), nums.end());
        int ans = 0;
        while(pq.top() < k){
            if(pq.size() < 2) return -1;

            long long x = pq.top();
            pq.pop();
            long long y = pq.top();
            pq.pop();

            pq.push(min(x, y) * 2 + max(x, y));
            ans++;
        }
        return ans;

    }
};
```
