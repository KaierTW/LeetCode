# 1358. Number of Substrings Containing All Three Characters
Problem : [HERE](https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/description/)

>[!TIP]
>這題的解題思路主要是利用滑動窗口（Sliding Window）技術來有效地找到包含所有三個字符（a, b, c）的子字符串。以下是詳細的解題步驟：
>
>1. **初始化**：
>   - 建立一個字典 `count` 來記錄字符 a, b, c 的出現次數。
>   - 設置兩個指針 `left` 和 `right` 分別表示窗口的左右邊界。
>   - 設置一個變量 `result` 來記錄包含所有三個字符的子字符串數量。
>
>2. **遍歷字符串**：
>   - 使用 `right` 指針遍歷字符串，將當前字符的出現次數記錄在 `count` 字典中。
>
>3. **調整窗口**：
>   - 每次移動 `right` 指針後，檢查窗口內是否包含所有三個字符（即 `count` 字典中 a, b, c 的值都大於 0）。
>   - 如果包含所有三個字符，則移動 `left` 指針來縮小窗口，直到窗口不再包含所有三個字符。每次移動 `left` 指針時，減少相應字符的出現次數。
>
>4. **計算結果**：
>   - 每次窗口內包含所有三個字符時，計算以當前字符結尾的有效子字符串數量，並累加到 `result` 中。
>
>這樣，我們就能有效地找到所有包含 a, b, c 的子字符串。希望這個解題思路對你有幫助！如果有其他問題或需要進一步的解釋，隨時告訴我哦！😊

```CPP
class Solution {
public:
    int numberOfSubstrings(string s) {
        unordered_map<char, int> count;
        int left = 0, ans = 0;
        for(int right = 0 ; right < s.size() ; right++){
            count[s[right]]++;
            while(count['a'] > 0 && count['b'] > 0 && count['c'] > 0){
                count[s[left]]--;
                left++;
            }
            ans += left;
        }
        return ans;
    }
};
```
