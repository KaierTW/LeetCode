# 2683. Neighboring Bitwise XOR
Problem : [HERE](https://leetcode.com/problems/neighboring-bitwise-xor/description/)

>[!TIP]
>
>1. 假設 `original[0]` 為 0，然後根據 `derived` 數組計算 `original` 數組的其他元素。
>2. 檢查 `original` 數組的最後一個元素與第一個元素的按位異或結果是否等於 `derived` 數組的最後一個元素。
>3. 如果不滿足，則假設 `original[0]` 為 1，重新計算 `original` 數組，並再次檢查條件。

```CPP
class Solution {
public:
    bool doesValidArrayExist(vector<int>& derived) {
        int n = derived.size();
        vector<int> original(n);
        original[0] = 0;
        for(int i = 1 ; i < n ; i++){
            original[i] = derived[i - 1] ^ original[i - 1];
        }

        //檢查最後一個條件
        if(original[n - 1] ^ original[0] == derived[n - 1]) return true;

        original[0] = 1;
        for(int i = 1 ; i < n ; i++){
            original[i] = derived[i - 1] ^ original[i - 1];
        }

        //檢查最後一個條件
        if(original[n - 1] ^ original[0] == derived[n - 1]) return true;
        else return false;
    }
};
```
