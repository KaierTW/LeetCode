# 729. My Calendar I




>[!TIP]
>這個條件 `(max(s, start) < min(e, end))` 用來檢查兩個區間是否重疊，讓我們拆解這個判斷條件的含義：
>
>### 1. 基本概念：
>假設有兩個區間，第一個區間是 `(s, e)`，第二個區間是 `(start, end)`：
>- `s` 和 `e` 表示已經存在的預訂區間的起始和結束時間。
>- `start` 和 `end` 表示新嘗試預訂的區間。
>
>如果這兩個區間不重疊，那麼必須滿足以下任意一個條件：
>- 第一個區間完全位於新區間的左側：`e <= start`
>- 第一個區間完全位於新區間的右側：`s >= end`
>
>如果這兩個條件都不成立，那麼兩個區間就是重疊的。
>
>### 2. 為什麼用 `max(s, start) < min(e, end)` 檢查重疊？
>
>這個條件的背後邏輯是找到兩個區間的**交集部分**。
>
>- `max(s, start)`：選擇兩個區間中較晚的起始時間，這是兩個區間可能重疊的最早時間。
>- `min(e, end)`：選擇兩個區間中較早的結束時間，這是兩個區間可能重疊的最晚時間。
>
>如果這兩個時間點之間存在有效的時間段（即 `max(s, start) < min(e, end)`），表示這兩個區間有重疊。反之，如果 `max(s, start)` 大於或等於 `min(e, end)`，說明這兩個區間不重疊。
>
>### 視覺化：
>假設兩個區間在時間軸上表示如下：
>
>```
>已存在的區間： |-------s----------e-------|
>新嘗試的區間：      |------start-------end---|
>```
>
>在這個例子中，兩個區間的重疊區間是：
>
>```
>重疊區間：        |----max(s, start)--------min(e, end)---|
>```
>
>只有當 `max(s, start) < min(e, end)` 時，這個區間才是有效的重疊部分。如果這個條件不成立，則兩個區間不會有交集。
>
>### 3. 具體情況：
>讓我們看看幾種不同的情況：
>
>- **完全不重疊**（新區間在前或後）：
>  1. 已存在區間在新區間之前：
>     - `(10, 20)` 和 `(30, 40)`，此時 `max(10, 30) = 30`，`min(20, 40) = 20`，`30 >= 20`，不重疊。
>  
>  2. 已存在區間在新區間之後：
>     - `(30, 40)` 和 `(10, 20)`，此時 `max(30, 10) = 30`，`min(40, 20) = 20`，`30 >= 20`，不重疊。
>
>- **有重疊**：
>  1. 新區間部分重疊：
>     - `(10, 20)` 和 `(15, 25)`，此時 `max(10, 15) = 15`，`min(20, 25) = 20`，`15 < 20`，重疊。
>  
>  2. 新區間完全包含已存在區間：
>     - `(10, 20)` 和 `(5, 25)`，此時 `max(10, 5) = 10`，`min(20, 25) = 20`，`10 < 20`，重疊。
>
>### 結論：
>`max(s, start) < min(e, end)` 是檢查兩個區間是否重疊的標準方法，它確保當兩個區間有交集時，返回 `true`，否則表示不重疊。
