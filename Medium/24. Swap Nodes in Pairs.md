# 24. Swap Nodes in Pairs
Problem : [HERE](https://leetcode.com/problems/swap-nodes-in-pairs/description/)

>[!TIP]
>先把head(第一個)跟head -> next(第二個)暫存起來，然後把head(第一個)原先要指到head -> next (第二個)改成head -> next -> next(第三個)
>
>再把head(第一個) 換成 head -> next(第二個)，然後原本的head(第一個)變成 head -> next(第二個)

```C
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* swapPairs(struct ListNode* head) {
    if(head == NULL || head -> next == NULL) return head;
    else{
        struct ListNode* first;
        struct ListNode* second;
        first = head;
        second = head -> next;
        head -> next  = head -> next -> next;
        head = second;
        head -> next = first;
        if(head -> next -> next == NULL) return head;
        else head -> next -> next = swapPairs(head -> next -> next);
    }
    return head;
}
```
