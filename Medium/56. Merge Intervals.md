# 56. Merge Intervals
Problem : [HERE](https://leetcode.com/problems/merge-intervals/description/)

>[!TIP]
>這道題目要求將一組區間合併，使得所有重疊的區間合併成一個。解題思路如下：
>
>1. **排序區間**：首先根據每個區間的起始值進行排序，這樣可以保證在遍歷時能夠按順序處理每個區間。
>2. **合併區間**：使用一個結果列表來存儲合併後的區間。遍歷排序後的區間，並檢查當前區間是否與結果列表中的最後一個區間重疊。如果重疊，則合併這兩個區間；如果不重疊，則將當前區間添加到結果列表中。
>
>具體步驟如下：
>
>1. **排序**：將區間列表根據起始值進行排序。
>2. **初始化結果列表**：創建一個空的結果列表 `merged`。
>3. **遍歷區間**：對於每個區間 `interval`：
>   - 如果結果列表為空或當前區間的起始值大於結果列表中最後一個區間的結束值，則將當前區間添加到結果列表中。
>   - 否則，更新結果列表中最後一個區間的結束值為當前區間的結束值和結果列表中最後一個區間的結束值的最大值。
>
>這樣的算法保證了時間複雜度為 $$O(n \log n)$$，其中 $$n$$ 是區間的數量

```CPP
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        vector<vector<int>>ans;
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b){
            return a[0] < b[0];
        });
        vector<int> previous = intervals[0];
        for(int i = 1 ; i < intervals.size() ; i++){
            vector<int> temp = intervals[i];
            if(temp[0] <= previous[1]){
                temp[0] = previous[0];
                temp[1] = (temp[1] > previous[1]) ? temp[1] : previous[1];
            }
            else ans.push_back(previous);
            previous = temp;
        }
        ans.push_back(previous);
        return ans;
    }
};
```
