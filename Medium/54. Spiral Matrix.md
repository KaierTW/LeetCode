# 54. Spiral Matrix
Problem : [HERE](https://leetcode.com/problems/spiral-matrix/description/)

>[!TIP]
>解題思路如下：
>
>1. **初始化邊界**：
>   - 定義四個邊界：上邊界`top`、下邊界`bottom`、左邊界`left`和右邊界`right`。
>   - 初始值分別為`top = 0`、`bottom = matrix.length - 1`、`left = 0`和`right = matrix[0].length - 1`。
>
>2. **遍歷矩陣**：
>   - 使用一個循環來遍歷矩陣，直到所有元素都被訪問。
>   - 按照順序遍歷：從左到右、從上到下、從右到左、從下到上。
>   - 每次遍歷完一行或一列後，更新相應的邊界。
>
>3. **添加元素到結果列表**：
>   - 在每次遍歷中，將元素添加到結果列表中。
>   - 確保不重複訪問已經添加過的元素。
>
>4. **停止條件**：
>   - 當`top`超過`bottom`或`left`超過`right`時，停止遍歷 [1](https://algo.monster/liteproblems/54) [2](https://neetcode.io/solutions/spiral-matrix) [3](https://walkccc.me/LeetCode/problems/54/).
>
>這種方法的時間複雜度是O(m * n)，其中m是矩陣的行數，n是矩陣的列數 [1](https://algo.monster/liteproblems/54) [2](https://neetcode.io/solutions/spiral-matrix).
>

```CPP
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int row = matrix.size();
        int column = matrix[0].size();
        int leftBound = 0, rightBound = column - 1, upperBound = 1, lowerBound = row - 1;
        int currentRow = 0, currentColumn = 0;
        int n = row * column;
        vector<int> ans;
        int direction = 0; // 0 = Left, 1 = Down, 2 = Up, 3 = Right
        if(column == 1) direction = 1;
        for(int i = 0 ; i < n ; i++){
            int target = matrix[currentRow][currentColumn];
            switch(direction){
                case 0 :                    
                    ans.push_back(target);
                    currentColumn++;                    
                    if(currentColumn == rightBound){
                        direction = 1;
                        rightBound--;
                    }
                    break;
                case 1 :                    
                    ans.push_back(target);
                    currentRow++;                    
                    if(currentRow == lowerBound){
                        direction = 2;
                        lowerBound--;
                    }
                    break;
                case 2 :                    
                    ans.push_back(target);
                    currentColumn--;                    
                    if(currentColumn == leftBound){
                        direction = 3;
                        leftBound++;
                    }
                    break;
                case 3 :                    
                    ans.push_back(target);
                    currentRow--;                    
                    if(currentRow == upperBound){
                        direction = 0;
                        upperBound++;
                    }
                    break;    
            }
        }
        return ans;
    }
};
```
