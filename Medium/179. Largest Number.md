# 179. Largest Number
Problem : [HERE](https://leetcode.com/problems/largest-number/description/)

>[!TIP]
>當我們解決 **179. Largest Number** 這道題時，核心問題是設計一個排序規則，能夠將數字排列成最大的數字。為了做到這一點，我們不能僅僅依照數字的大小進行排序，而是必須根據數字**拼接後的結果**進行比較。下面詳細講解這個排序過程的原理。
>
>### 排序的關鍵：
>- 假設有兩個數字 `a` 和 `b`，我們需要決定將 `a` 放在 `b` 的前面還是後面。
>- 要決定它們的相對順序，我們不單單比較數值，而是比較兩個數字**拼接後的結果**：
>  - 拼接方式 1：`a + b` （即 `a` 放在 `b` 前面）
>  - 拼接方式 2：`b + a` （即 `b` 放在 `a` 前面）
>- 我們比較這兩個拼接結果的大小，來決定 `a` 和 `b` 的排序順序。
>  - 如果 `a + b > b + a`，那麼 `a` 應該排在 `b` 前面。
>  - 如果 `a + b < b + a`，那麼 `b` 應該排在 `a` 前面。
>
>### 示例分析：
>假設有一組數字 `[3, 30, 34, 5, 9]`，我們需要通過拼接它們形成最大的數字。具體排序過程如下：
>
>1. **比較 `"3"` 和 `"30"`**：
>   - 拼接結果 1：`"330"`
>   - 拼接結果 2：`"303"`
>   - 因為 `"330" > "303"`，所以 `3` 應該排在 `30` 的前面。
>
>2. **比較 `"30"` 和 `"34"`**：
>   - 拼接結果 1：`"3034"`
>   - 拼接結果 2：`"3430"`
>   - 因為 `"3430" > "3034"`，所以 `34` 應該排在 `30` 的前面。
>
>3. **比較 `"34"` 和 `"5"`**：
>   - 拼接結果 1：`"345"`
>   - 拼接結果 2：`"534"`
>   - 因為 `"534" > "345"`，所以 `5` 應該排在 `34` 的前面。
>
>4. **比較 `"5"` 和 `"9"`**：
>   - 拼接結果 1：`"59"`
>   - 拼接結果 2：`"95"`
>   - 因為 `"95" > "59"`，所以 `9` 應該排在 `5` 的前面。
>
>### 排序後的結果：
>根據上面的排序規則，最終排序結果是 `[9, 5, 34, 3, 30]`。將這些數字拼接起來，就得到了最大的數字 `9534330`。
>
>### 排序的詳細步驟：
>1. **轉換數字為字串**：這一步是因為我們需要比較的是數字拼接後的大小，因此將所有的整數轉換為字符串。
>2. **自定義比較函數**：我們的排序規則不再依賴數值大小，而是通過拼接兩個數字的字串來比較。比較兩個數字拼接後的結果，來決定它們在最終結果中的順序。
>3. **排序**：使用 `sort()` 函數，並傳入自定義的比較函數來對字符串進行排序。
>4. **處理邊界條件**：如果排序後的第一個元素是 `"0"`，那麼說明整個輸入都是 `0`，我們應該直接返回 `"0"`。
>5. **拼接結果**：將排序後的字符串按順序拼接起來，得到最終的結果。
>
>### 重要提示：
>- **`a + b` 與 `b + a` 的比較**：這是整個問題的核心。通過這種比較方式，我們能夠確保排列後的結果是最大的數字。
>- **處理特殊情況**：如果所有的數字都是 `0`，最終結果應該是 `"0"`，而不是 `"000"`。
>
>### 時間複雜度分析：
>- **時間複雜度**：排序的時間複雜度為 \(O(n \log n)\)，其中 \(n\) 是數字的個數。每次比較兩個數字的拼接結果的時間是 \(O(1)\)（假設數字的長度是固定的）。
>- **空間複雜度**：需要額外的空間來存儲字符串，空間複雜度為 \(O(n)\)。
>
>### 小結：
>這道題的關鍵在於正確設計自定義的比較規則，通過比較兩個數字拼接後的結果來決定排序順序。排序完成後，將所有數字拼接成字符串即可得到最終的結果。
>
>
```CPP
class Solution {
public:
    static bool sortMethod(string& a , string& b){
        return a + b > b + a;
    }
    string largestNumber(vector<int>& nums) {
        vector<string> stringNums;
        for(int num : nums){
            stringNums.push_back(to_string(num));
        }
        sort(stringNums.begin() , stringNums.end() , sortMethod);
        if(stringNums[0] == "0") return "0";
        else{
            string ans;
            for(string stringNum : stringNums){
                ans += stringNum;
            }
            return ans;
        }
    }
};
```
