# 1726. Tuple with Same Product
Problem : [HERE](https://leetcode.com/problems/tuple-with-same-product/description/)

>[!TIP]
>當然可以！讓我們再深入探討一下這道題目的原理，以及為什麼使用哈希表（`unordered_map`）來記錄乘積。
>
>### 題目回顧
>題目要求我們找到所有滿足條件的四元組 `(a, b, c, d)`，使得 `a * b = c * d`，且 `a, b, c, d` 都是數組 `nums` 中的元素，並且 `a != b != c != d`。
>
>### 使用哈希表的原因
>1. **快速查找**：哈希表允許我們在常數時間內（O(1)）查找某個乘積是否已經出現過。這樣可以大大提高查找效率，避免了線性查找的高時間複雜度。
>
>2. **避免重複計算**：如果我們不記錄乘積，每次遇到新的數對 `(a, b)` 都需要重新計算並檢查所有之前的數對，這樣會導致大量的重複計算。通過記錄乘積，我們可以避免這些重複計算，從而提高效率。
>
>3. **簡化邏輯**：記錄乘積可以簡化我們的邏輯，讓我們只需要關注每個乘積出現的次數，而不需要關注具體的數對。這樣可以讓代碼更加簡潔和易於理解。
>
>### 解題步驟
>1. **初始化哈希表**：創建一個哈希表來記錄每個乘積出現的次數。
>2. **遍歷數組**：使用兩層循環遍歷數組中的所有可能的數對 `(a, b)`，計算它們的乘積 `product = a * b`。
>3. **更新哈希表**：對於每個計算出的乘積，檢查它是否已經存在於哈希表中。如果存在，說明之前已經有其他數對 `(c, d)` 使得 `c * d = a * b`。這時，我們可以將哈希表中該乘積的值加到結果中，因為每找到一個新的數對 `(a, b)`，就可以形成多個新的四元組 `(a, b, c, d)`。
>4. **計算結果**：每找到一個新的數對 `(a, b)`，我們就更新哈希表中該乘積的出現次數。最後，根據哈希表中的數據，我們可以計算出滿足條件的四元組數量。需要注意的是，每個四元組可以有 8 種排列方式，所以最終的結果需要乘以 8。

```CPP
class Solution {
public:
    int tupleSameProduct(vector<int>& nums) {
        unordered_map<int,int> map;
        int ans = 0;
        for(int i = 0 ; i < nums.size() ; i++){
            for(int j = i + 1 ; j < nums.size() ; j++){
                int temp = nums[i] * nums[j];
                ans += 8 * map[temp];
                map[temp]++;
            }
        }
        return ans;
    }
};
```
