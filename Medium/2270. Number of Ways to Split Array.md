# 2270. Number of Ways to Split Array
Problem : [HERE](https://leetcode.com/problems/number-of-ways-to-split-array/description/)

>[!TIP]
>要先用一個prefix把前面的總和記起來，這樣才不會time limit

```CPP
class Solution {
public:
    int waysToSplitArray(vector<int>& nums) {
        int ans = 0;
        vector<long long>prefixSum(nums.size(), 0);
        prefixSum[0] = nums[0];
        for(int i = 1 ; i < nums.size() ; i++){
            prefixSum[i] = prefixSum[i - 1] + nums[i];
        }
        for(int i = 0 ; i < nums.size() - 1 ; i++){
            long long sum1 = prefixSum[i];
            long long sum2 = prefixSum[nums.size() - 1] - sum1;
            //printf("sum1: %d , sum2: %d\n", sum1, sum2);
            if(sum1 >= sum2)ans++;
        }
        return ans;
    }
};
```
