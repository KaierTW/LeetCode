#2017. Grid Game
Problem : [HERE](https://leetcode.com/problems/grid-game/description/)

>[!TIP]
>
>
>### 問題描述
>在一個2 x n的網格上，有兩個機器人從左上角(0, 0)開始，目標是到達右下角(1, n-1)。每個網格單元格包含一定數量的點數。第一個機器人先移動，收集經過的所有點數，並將這些單元格的點數設為0。第二個機器人接著移動，收集剩餘的點數。第一個機器人的目標是選擇一條路徑，使得第二個機器人能收集到的點數最少；而第二個機器人的目標是收集最多的點數。我們的任務是計算第二個機器人在兩個機器人都選擇最佳路徑的情況下能收集到的點數。
>
>### 解題思路
>1. **計算前綴和**：
>   - 我們首先計算每一行的前綴和。前綴和是一個數組，其中每個元素表示從起點到當前位置的點數總和。這樣可以快速計算出任意區間的點數總和。
>
>2. **模擬第一個機器人的路徑**：
>   - 第一個機器人從左上角(0, 0)開始，選擇一條路徑到達右下角(1, n-1)，並將經過的點數設為0。
>   - 我們需要計算第一個機器人經過的每一個位置的點數總和。
>
>3. **計算第二個機器人的最佳路徑**：
>   - 第二個機器人從左上角(0, 0)開始，選擇一條路徑到達右下角(1, n-1)，並收集剩餘的點數。
>   - 我們需要計算第二個機器人經過的每一個位置的點數總和。
>
>4. **優化路徑選擇**：
>   - 第一個機器人應該選擇一條路徑，使得第二個機器人能收集到的點數最少。
>   - 使用動態規劃或貪心算法來優化第一個機器人的路徑選擇。
>
>### 具體步驟
>1. **計算前綴和**：
>   ```cpp
>   vector<int> prefix_sum_top(n + 1, 0);
>   vector<int> prefix_sum_bottom(n + 1, 0);
>
>   for (int i = 0; i < n; ++i) {
>       prefix_sum_top[i + 1] = prefix_sum_top[i] + grid[0][i];
>       prefix_sum_bottom[i + 1] = prefix_sum_bottom[i] + grid[1][i];
>   }
>   ```
>
>2. **模擬第一個機器人的路徑**：
>   - 第一個機器人可以選擇在任意一列向下移動。
>   - 我們需要計算第一個機器人在每一列向下移動時，第二個機器人能收集到的最小點數。
>
>3. **計算第二個機器人的最佳路徑**：
>   - 第二個機器人可以選擇在第一個機器人向下移動後的剩餘路徑上移動。
>   - 我們需要計算第二個機器人能收集到的點數。
>
>4. **優化路徑選擇**：
>   ```cpp
>   int result = INT_MAX;
>   for (int i = 0; i < n; ++i) {
>       int points_top = prefix_sum_top[n] - prefix_sum_top[i + 1];
>       int points_bottom = prefix_sum_bottom[i];
>       result = min(result, max(points_top, points_bottom));
>   }
>   ```
>
>這樣，我們就能計算出第二個機器人在兩個機器人都選擇最佳路徑的情況下能收集到的最小點數。
>

```CPP
class Solution {
public:
    long long gridGame(vector<vector<int>>& grid) {
        int n = grid[0].size();
        long long ans = LLONG_MAX;
        vector<long long> prefixSumTop(n, 0);
        vector<long long> prefixSumBot(n, 0);
        prefixSumTop[0] = grid[0][0];
        prefixSumBot[0] = grid[1][0];
        //先建立prefixSum
        for(int i = 1 ; i < n ; i++){
            prefixSumTop[i] = prefixSumTop[i - 1] + grid[0][i];
            prefixSumBot[i] = prefixSumBot[i - 1] + grid[1][i];
        }
        //選擇在第i列往下轉        
        for(int i = 0 ; i < n ; i++){
            long long tempTop, tempBot;
            tempTop = prefixSumTop[n - 1] - prefixSumTop[i];
            if(i == 0) tempBot = 0;
            else tempBot = prefixSumBot[i - 1];
            //在同一條往下轉的時候 要看是上面的總分比較多還是下面的，所以取max
            //但整個迴圈來說是要總分越小越好，所以取min
            ans = min(ans, max(tempTop, tempBot));
            //printf("Column: %d, tempTop: %d, tempBot: %d\n", i, tempTop, tempBot);
        }

        return ans;
    }
};
```
