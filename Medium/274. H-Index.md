# 274. H-Index
Problem : [HERE](https://leetcode.com/problems/h-index/description/)

>[!TIP]
>H-Index 是一個用來衡量研究者學術影響力的指標。這個指標的定義是：一個研究者的 H-Index 是指他/她有至少 H 篇論文分別被引用了至少 H 次，而其餘的論文被引用的次數不超過 H 次。
>
>### 題目描述
>給定一個整數數組 `citations`，其中 `citations[i]` 表示研究者的第 `i` 篇論文被引用的次數。要求計算這個研究者的 H-Index。
>
>### 例子
>- **例子 1**：
>  - 輸入：`citations = [3,0,6,1,5]`
>  - 輸出：`3`
>  - 解釋：研究者有 5 篇論文，分別被引用了 3, 0, 6, 1, 5 次。由於有 3 篇論文被引用了至少 3 次，其餘 2 篇論文被引用的次數不超過 3 次，所以 H-Index 是 3。
>
>- **例子 2**：
>  - 輸入：`citations = [1,3,1]`
>  - 輸出：`1`
>  - 解釋：研究者有 3 篇論文，分別被引用了 1, 3, 1 次。由於有 1 篇論文被引用了至少 1 次，其餘 2 篇論文被引用的次數不超過 1 次，所以 H-Index 是 1。
>
>### 解題思路
>1. **排序法**：將 `citations` 數組按降序排序，然後遍歷排序後的數組，找到第一個 `citations[i]` 小於等於 `i+1` 的位置，這個位置的索引值就是 H-Index。
>2. **計數排序法**：利用計數排序的思想，統計每個引用次數出現的頻率，然後從高到低累加計數，直到累加值大於等於當前引用次數。
>

>

```CPP
class Solution {
public:
    int hIndex(vector<int>& citations) {
        if(citations.size() == 1) return (citations[0] == 0) ? 0 : 1;
        sort(citations.begin(), citations.end());
        for(int i = 0 ; i < citations.size() ; i++){
            if(citations.size() - i <= citations[i]) return citations.size() - i;
        }
        return 0;
    }
};
```
