>### 解題思路
>1. **總油量檢查**：首先，我們需要檢查總油量是否足夠完成整個環形路線。如果總油量小於總消耗量，那麼無論從哪個加油站出發都無法完成旅行，直接返回 -1。
>2. **遍歷加油站**：我們遍歷每個加油站，計算當前油量。如果當前油量小於0，則表示從起始加油站到當前加油站無法完成旅行，因此需要將起始加油站設置為下一個加油站，並重置當前油量。
>3. **返回結果**：如果總油量大於等於0，則返回起始加油站的索引，否則返回 -1。
>
>### C++代碼
>```cpp
>#include <vector>
>using namespace std;
>
>int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
>    int total_tank = 0, curr_tank = 0;
>    int start_index = 0;
>    for (int i = 0; i < gas.size(); ++i) {
>        total_tank += gas[i] - cost[i];
>        curr_tank += gas[i] - cost[i];
>        if (curr_tank < 0) {
>            start_index = i + 1;
>            curr_tank = 0;
>        }
>    }
>    return total_tank >= 0 ? start_index : -1;
>}
>```
>
>這段代碼的思路是：
>1. **初始化變量**：`total_tank` 用於計算總油量，`curr_tank` 用於計算當前油量，`start_index` 用於記錄起始加油站的索引。
>2. **遍歷加油站**：在每個加油站，我們更新 `total_tank` 和 `curr_tank`。如果 `curr_tank` 小於0，則更新 `start_index` 並重置 `curr_tank`。
>3. **返回結果**：根據 `total_tank` 的值，決定是否能完成旅行並返回相應的起始加油站索引。

```CPP
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {                
        int n = gas.size();
        int start = -1;
        for(int i = 0 ; i < n ; i++){
            if(gas[i] >= cost[i]){                
                start = i;                
                int tank = gas[start];
                //printf("Start Pos: %d, Initial Tank: %d\n", start, tank);
                for(int j = 0 ; j < n ; j++){
                    if(j != (n - 1)){
                        tank -= cost[(start + j) % n];
                        if(tank <= 0) break;
                        tank += gas[(start + j + 1) % n];                        
                    }
                    // Last station
                    else{
                        tank -= cost[(start + j) % n];     
                        if(tank >= 0) return start;
                    }                                 
                    //printf("Cuerrent Pos: %d, Tank: %d\n", ((start + j + 1) % n), tank);                    
                }                
            }
        }
        return -1;        
    }
};
```
