# 1079. Letter Tile Possibilities
Problem : [HERE](https://leetcode.com/problems/letter-tile-possibilities/description/)

>
>### 題目概述
>
>你有若干個字母瓦片，每個瓦片上印有一個字母。目標是生成所有可能的非空字母序列，並計算這些序列的數量。
>
>### 解題思路
>
>這題目主要使用回溯法（backtracking）來解決，我們需要遍歷所有可能的字母序列。具體步驟如下：
>
>1. **初始化集合**：
>   - 使用一個集合來存儲所有可能的非空字母序列。
>   - 初始化一個布爾數組來標記每個字母瓦片是否已經使用過。
>
>2. **遞歸構建序列**：
>   - 從每個字母瓦片開始，遞歸地構建所有可能的序列。
>   - 將每個生成的序列添加到集合中，以確保不重複計算相同的序列。
>
>3. **防止重複**：
>   - 使用布爾數組來標記每個字母瓦片是否已經使用過，防止生成重複的序列。
>
>### 詳細步驟
>
>以下是具體的步驟和解釋：
>
>1. **定義回溯函數**：
>   - 回溯函數 `backtrack` 負責構建所有可能的序列。
>   - 函數參數包括原始字母瓦片字符串、當前生成的序列、已使用的字母瓦片標記、以及存儲所有可能序列的集合。
>
>2. **遞歸結束條件**：
>   - 在每次遞歸中，我們從未使用過的字母瓦片開始構建序列。
>   - 每次生成一個新的序列後，將其添加到集合中。
>
>3. **遞歸過程**：
>   - 對於每個字母瓦片，標記其為已使用，並將其添加到當前序列中。
>   - 進一步遞歸構建剩餘字母瓦片的可能序列。
>   - 回溯時，取消當前字母瓦片的使用標記，並從當前序列中移除。
>
>
>### 示例說明
>
>以範例 `tiles = "AAB"` 為例，回溯過程如下：
>1. 從字母 `A` 開始，生成序列 `"A"`，並繼續遞歸生成其他序列。
>2. 在序列 `"A"` 基礎上，添加另一個 `A`，生成 `"AA"`，繼續遞歸。
>3. 添加 `B`，生成 `"AAB"`，然後回溯，嘗試其他可能的組合。
>4. 從 `B` 開始，生成 `"B"`，並繼續遞歸生成其他序列，如 `"BA"` 和 `"BAA"`。
>
>最終，所有可能的序列被加入集合中，集合的大小即為所有可能非空序列的數量。
>

```CPP
class Solution {
public:        
    void backtrack(const string& tiles, unordered_set<string>& sequences, string& path, vector<bool>& used){
        for (int i = 0; i < tiles.size(); ++i) {
        if (used[i]) continue; // 跳過已使用的字母瓦片
        used[i] = true; // 標記當前字母瓦片為已使用
        path.push_back(tiles[i]); // 將當前字母瓦片添加到當前序列
        sequences.insert(path); // 將當前序列添加到集合中
        backtrack(tiles, sequences, path, used); // 遞歸構建剩餘字母瓦片的序列
        path.pop_back(); // 回溯，移除當前字母瓦片
        used[i] = false; // 取消標記當前字母瓦片
        }
    }
    int numTilePossibilities(string tiles) {
        unordered_set<string> sequences; // 用於存儲所有可能的非空序列
        string path;
        vector<bool> used(tiles.size(), false); // 布爾數組標記每個字母瓦片是否已使用
        backtrack(tiles, sequences, path, used);
        return sequences.size(); 
    }
};
```
