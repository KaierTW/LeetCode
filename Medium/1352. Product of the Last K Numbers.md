# 1352. Product of the Last K Numbers
Problem : [HERE](https://leetcode.com/problems/product-of-the-last-k-numbers/description/)

>[!TIP]
>這題目要求我們設計一個類別來處理一連串的整數，並能夠計算最後 K 個數字的乘積。這裡有一個高效的解法：
>
>### 解題思路
>我們可以使用前綴乘積（prefix product）的概念來解決這個問題。具體步驟如下：
>
>1. **初始化**：我們使用一個列表來存儲前綴乘積，初始值為 1，表示空乘積。
>2. **添加數字**：每次添加一個數字時，如果這個數字是 0，我們需要重置前綴乘積列表，因為 0 會使得任何乘積為 0。如果數字不是 0，我們將這個數字與前一個前綴乘積相乘並添加到列表中。
>3. **計算乘積**：當我們需要計算最後 K 個數字的乘積時，我們可以通過前綴乘積列表快速計算。如果列表長度小於 K，說明在這 K 個數字中有 0，乘積為 0。否則，我們可以通過前綴乘積的除法來計算。
>
>### 主要操作
>- `add(num: int)`: 添加一個數字到數列中。
>- `getProduct(k: int)`: 返回最後 K 個數字的乘積。
>
>這種方法的時間複雜度是 O(1)，因為每次添加和計算乘積的操作都是常數時間

```CPP
class ProductOfNumbers {
private:
    vector<int> number;
public:
    ProductOfNumbers() {
        
    }
    
    void add(int num) {
        number.push_back(num);
    }
    
    int getProduct(int k) {
        int ans = 1;        
        for(int i = 0 ; i < k ; i++){
            ans *= number[number.size() - 1 - i];
        }
        return ans;
    }
};

/**
 * Your ProductOfNumbers object will be instantiated and called as such:
 * ProductOfNumbers* obj = new ProductOfNumbers();
 * obj->add(num);
 * int param_2 = obj->getProduct(k);
 */
```
