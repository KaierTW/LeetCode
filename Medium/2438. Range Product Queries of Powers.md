# 2438. Range Product Queries of Powers
Problem : [HERE](https://leetcode.com/problems/range-product-queries-of-powers/description/)

>---
>
>## **題目重點**
>
>1. **powers 陣列的定義**
>
>   * 把 `n` 拆成最少個數的 2 的冪（就是它的二進位表示法），
>     例如 `n = 13` → 二進位 `1101` → `powers = [1, 4, 8]`（排序非遞減）。
>
>2. **查詢要求**
>
>   * 給定 `(l, r)`，要計算 `powers[l] × powers[l+1] × ... × powers[r] (mod 1e9+7)`。
>
>3. **取模 (mod)**
>
>   * 在運算過程中 `%MOD` 是為了防止數字溢位並保持結果在 `0 ~ MOD-1`。
>   * 模運算中的「除法」不能直接用 `/`，要用 **模反元素**（modInverse）。
>
>4. **為什麼不能 `(a/b) % MOD`**
>
>   * 因為普通除法和模運算下的除法不是同一回事，
>     正確公式是 `(a × modInverse(b)) % MOD`。
>   * 而且 `(a × ... )` 直接算可能會溢位。
>
>---
>
>## **避開除法的方法 — 預先算表法**
>
>### 原理
>
>* 因為 `powers` 最長不會超過 `log₂(n)`，區間數量 `m(m+1)/2` 很小。
>* 可以先用雙迴圈把每個 `(l, r)` 的乘積（已取模）算好存起來。
>* 查詢時直接 O(1) 回傳，不需要除法、模反元素。
>
>---
>
>## **解題思路**
>
>1. **生成 powers 陣列**
>
>   * 用 n 的二進位分解法，從最低位到最高位：
>
>     * 若該位是 1，加入對應的 2^k。
>   * 排序（題目要求非遞減，其實自然就是遞增）。
>
>2. **預計算 product 表**
>
>   * 建立 `product[l][r]`：
>
>     ```cpp
>     for (int i = 0; i < m; i++) {
>         long long p = 1;
>         for (int j = i; j < m; j++) {
>             p = (p * powers[j]) % MOD;
>             product[i][j] = p;
>         }
>     }
>     ```
>
>3. **回答 queries**
>
>   * 直接 `answers[k] = product[l][r]`。
>
>---
>
>## **C++ 範例**
>
>```cpp
>#include <bits/stdc++.h>
>using namespace std;
>const long long MOD = 1e9 + 7;
>
>int main() {
>    long long n;
>    cin >> n;
>    int q;
>    cin >> q;
>
>    // 1. 生成 powers 陣列
>    vector<long long> powers;
>    for (int i = 0; (1LL << i) <= n; i++) {
>        if (n & (1LL << i)) {
>            powers.push_back(1LL << i);
>        }
>    }
>    sort(powers.begin(), powers.end()); // 其實自然是遞增
>
>    int m = powers.size();
>
>    // 2. 預計算 product 表
>    vector<vector<long long>> product(m, vector<long long>(m, 1));
>    for (int i = 0; i < m; i++) {
>        long long p = 1;
>        for (int j = i; j < m; j++) {
>            p = (p * powers[j]) % MOD;
>            product[i][j] = p;
>        }
>    }
>
>    // 3. 查詢
>    while (q--) {
>        int l, r;
>        cin >> l >> r;
>        cout << product[l][r] << "\n";
>    }
>
>    return 0;
>}
>```
>
>---
>
>## **流程圖概覽**
>
>```
>n → powers陣列(2的冪) → 預算product表 → queries直接查 → 輸出結果
>```
>
>---
>
>✅ **優點**
>
>* 查詢 O(1)
>* 不用 `modInverse`
>* 不會溢位（每步取模）
>* 簡單易懂
>
>⚠️ **缺點**
>
>* 需要 O(m²) 記憶體（但 m ≤ log₂(n)，非常小）
>
>---
>

```CPP
class Solution {
public:
    const long long MOD = 1e9 + 7;
    vector<int> productQueries(int n, vector<vector<int>>& queries) {
        vector<int> powers;
        // 建立powers陣列
        for(int i = 0 ; (1 << i) <= n ; i++){
            // n的第i個bit是1
            if((n & (1 << i)) != 0){
                powers.push_back(1 << i);
            }
        }        
        for(int power: powers){
            cout << power << " ";
        }
        cout<< endl;
        // 建立prefix product陣列
        vector<vector<long long>> prefixProducts(powers.size(), vector<long long>(powers.size(), 1));
        for(int i = 0 ; i < powers.size() ; i++){
            long long prefix = 1;
            for(int j = i ; j < powers.size() ; j++){
                prefix = (prefix * powers[j]) % MOD ;
                prefixProducts[i][j] = prefix;
            }
        }
        // 開始查詢
        vector<int> ans;
        for(vector<int> q : queries){
            int left = q[0], right = q[1];
            ans.push_back(prefixProducts[left][right]);
        }
        return ans;
    }
};
```
