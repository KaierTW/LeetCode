# 1405. Longest Happy String
Problem : [HERE](https://leetcode.com/problems/longest-happy-string/description/)

>[!TIP]
>### 題目簡述：
>
>題目要求生成一個最長的「快樂字串」，其中每個字母的數量是已知的（即 `a`, `b`, `c`），並且「快樂字串」的定義是不能有任何連續的三個相同字母出現。
>
>給定三個整數 `a`, `b`, `c`，分別表示字母 `'a'`, `'b'`, `'c'` 可以使用的數量，我們需要生成一個最長的符合規則的字串。
>
>### 解題思路：
>這道題的核心是**貪心法**，每次選擇剩餘最多次數的字母來拼接字串，但需要避免產生三個連續的相同字母。
>
>具體解法步驟如下：
>1. 優先使用數量最多的字母，但要確保該字母不會導致三連續出現。如果當前字母已經連續兩次出現過，則選擇次多的字母。
>2. 每次選擇一個字母後，將其可用數量減一，並更新字串。
>3. 重複步驟1和2，直到無法再添加合法的字母。
>
>### 具體實現：
>使用一個最大堆（`priority_queue`），將 `a`, `b`, `c` 及其數量按照剩餘次數排序，優先選擇剩餘最多的字母，並動態更新。
>
>### 解釋：
>1. **使用最大堆 (priority_queue)**：每次選擇剩餘最多的字母來嘗試拼接字串。
>2. **避免三連續**：當字串末尾已經有兩個相同字母時，選擇次多的字母。
>3. **動態更新**：每次使用一個字母後，減少該字母的剩餘次數，並將其重新放回堆中（如果其次數大於 0）。
>
>### 時間複雜度：
>- 每次操作的時間複雜度為 `O(log 3)`，因為最大堆最多有 3 個元素，所以在整個過程中操作次數最多為 `a + b + c`，總時間複雜度是 `O((a + b + c) log 3)`，相當於 `O(a + b + c)`。
>
>### 結論：
>這個解法利用貪心策略，保證了每次都使用剩餘最多的字母來拼接最長合法的字串，同時避免三個連續相同的字母，是一個高效且簡潔的解法。

>[!TIP]
>`priority_queue` 是 C++ 標準模板庫（STL）中的一種容器，屬於**堆**的實現，特別是**最大堆**（Max Heap）。它是一種特殊的隊列，當你從中提取元素時，會按照優先順序提取而不是按照插入順序。默認情況下，`priority_queue` 按照從大到小的順序（最大值優先）排列，但你也可以通過自定義比較函數來實現從小到大的排列（最小堆）。
>
>### 特點：
>1. **優先級最高的元素在最前面**：每次從隊列中提取的元素是優先級最高的。
>2. **默認是最大堆**：這意味著優先級最高的元素是值最大的元素。
>
>### 用法：
>```cpp
>#include <iostream>
>#include <queue>
>#include <vector>
>
>int main() {
>    // 默認為最大堆 (Max Heap)
>    std::priority_queue<int> pq;
>
>    // 插入元素
>    pq.push(10);
>    pq.push(30);
>    pq.push(20);
>    pq.push(5);
>
>    // 取出元素
>    std::cout << "Priority Queue Top Element: " << pq.top() << std::endl;  // 輸出 30 (最大值)
>
>    // 移除最大元素
>    pq.pop();
>   
>    std::cout << "Priority Queue Top Element after pop: " << pq.top() << std::endl;  // 輸出 20
>
>    return 0;
>}
>```
>
>### 主要函數：
>1. **`push()`**：插入元素到隊列中。
>2. **`pop()`**：移除當前最大（優先級最高）的元素。
>3. **`top()`**：返回當前最大（優先級最高）的元素，但不移除它。
>4. **`empty()`**：檢查隊列是否為空。
>5. **`size()`**：返回隊列中元素的數量。
>
>### 默認情況：最大堆
>當我們使用 `priority_queue<int>` 時，插入的元素會自動按照從大到小的順序排列，所以 `top()` 返回的是當前隊列中最大值。
>
>### 最小堆（Min Heap）：
>如果想要實現最小堆，可以使用 `std::greater<T>` 作為比較函數，或者通過自定義比較函數來改變元素的排序方式。
>
>#### 最小堆示例：
>```cpp
>#include <iostream>
>#include <queue>
>#include <vector>
>
>int main() {
>    // 最小堆 (Min Heap)，使用 greater<int> 來實現
>    std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;>
>
>    // 插入元素
>    minHeap.push(10);
>    minHeap.push(30);
>    minHeap.push(20);
>    minHeap.push(5);
>
>    // 取出最小元素
>    std::cout << "Min Heap Top Element: " << minHeap.top() << std::endl;  // 輸出 5 (最小值)
>
>    minHeap.pop();
>   
>    std::cout << "Min Heap Top Element after pop: " << minHeap.top() << std::endl;  // 輸出 10
>
>    return 0;
>}
>```
>
>### 自定義比較函數：
>你也可以通過定義一個結構來自定義比較規則。例如，如果你想在結構中比較兩個元素的某個屬性，可以通過這種方式實現。
>
>```cpp
>#include <iostream>
>#include <queue>
>#include <vector>
>
>struct Compare {
>    bool operator()(int a, int b) {
>        return a > b;  // 則成為最小堆
>    }
>};
>
>int main() {
>    // 自定義比較規則的 priority_queue
>    std::priority_queue<int, std::vector<int>, Compare> customPQ;
>
>    customPQ.push(10);
>    customPQ.push(30);
>    customPQ.push(20);
>    customPQ.push(5);
>
>    std::cout << "Top element: " << customPQ.top() << std::endl; // 輸出 5 (最小值)
>
>    return 0;
>}
>```
>
>### 何時使用 `priority_queue`：
>`priority_queue` 特別適合用於那些需要頻繁插入和提取「最大值」或「最小值」的情況，例如：
>1. **任務調度**：按優先級調度任務。
>2. **Dijkstra 最短路徑算法**：優先選擇當前最短路徑的點。
>3. **事件驅動模擬**：按時間排序事件。
>
>希望這些信息能幫助你理解 `priority_queue` 的概念與使用方式！

>[!TIP]
>你把數字放在前面的原因是因為 `priority_queue` 的**比較規則**。在 C++ 中，`priority_queue` 是基於**最大堆**的資料結構，也就是說，隊列中最頂端的元素總是「最大」的。當你要用 `priority_queue` 儲存 `std::pair<int, char>` 這樣的資料時，C++ 會自動根據 `pair` 的**第一個元素**來比較大小。
>
>### 原因詳解：
>
>1. **`priority_queue` 以第一個元素進行比較：**
>   在 `std::priority_queue<std::pair<int, char>>` 中，`priority_queue` 預設會比較 `pair` 的第一個元素（這裡是 `int`）。也就是說，當你將 `std::pair<int, char>` 放入 `priority_queue` 時，它會根據 `int` 的值進行排序，`int` 值越大，這個 `pair` 就越靠近隊列的頂部。由於我們希望**優先處理次數最多的字母**，所以必須把次數 `int` 放在前面。
>
>2. **如何進行比較：**
>   在 `std::pair<int, char>` 中，`priority_queue` 會先比較 `int`（字母的剩餘次數），如果兩個 `int` 相同，則會進一步比較 `char`（字母本身）。但在這裡，我們主要依賴 `int` 來排序，所以 `priority_queue` 會自動按字母剩餘次數來排序。
>
>   例如：
>   ```cpp
>   std::priority_queue<std::pair<int, char>> pq;
>   pq.push({5, 'a'});
>   pq.push({3, 'b'});
>   pq.push({2, 'c'});
>   ```
>   這時，`priority_queue` 會自動將次數最多的字母（即 `{5, 'a'}`）放在頂端，因為 `priority_queue` 會優先比較 `int`。
>
>3. **如果把 `char` 放在前面：**
>   如果你把 `char` 放在前面，例如 `std::pair<char, int>`，那麼 `priority_queue` 會根據字母的字母順序（ASCII 值）來進行比較。例如，`'a'` 的 ASCII 值是 97，`'b'` 是 98，`'c'` 是 99，所以這樣的 `priority_queue` 就會優先處理字母順序，而不是根據次數來選擇字母。這會導致邏輯錯誤，因為你的目標是每次選擇剩餘次數最多的字母。
>
>   例如：
>   ```cpp
>   std::priority_queue<std::pair<char, int>> pq;
>   pq.push({'a', 5});
>   pq.push({'b', 3});
>   pq.push({'c', 2});
>   ```
>   這種情況下，`priority_queue` 會根據字母排序，`'c'` 優先於 `'b'`，`'b'` 優先於 `'a'`，而忽略了你實際希望根據次數來選擇的需求。
>
>### 小結：
>你需要將數字（次數）放在 `pair` 的第一個位置，因為這樣 `priority_queue` 才會根據字母的剩餘次數來排序，讓你每次能夠優先選擇次數最多的字母。這符合問題的需求，並且保證了生成字串的正確性。如果你將 `char` 放在前面，優先隊列將無法正確地根據次數>進行排序。


```CPP
class Solution {
public:
    string longestDiverseString(int a, int b, int c) {
        // 使用 priority_queue 優先處理次數最多的字母
        //int要放前面，priority_queue 的比較規則最頂端的元素總是「最大」的。
        //當你要用 priority_queue 儲存 std::pair<int, char> 這樣的資料時，C++ 會自動根據 pair 的第一個元素來比較大小。
        priority_queue<std::pair<int, char>> pq;
        
        // 將所有字母加入堆中，次數為0的不加入
        if (a > 0) pq.push({a, 'a'});
        if (b > 0) pq.push({b, 'b'});
        if (c > 0) pq.push({c, 'c'});
        
        string result = "";
        
        while (!pq.empty()) {
            auto [count1, char1] = pq.top();
            pq.pop();
            
            // 檢查是否可以加入該字母
            if (result.size() >= 2 && result.back() == char1 && result[result.size() - 2] == char1) {
                // 如果已經有兩個連續相同的字母，選擇次多的字母
                if (pq.empty()) break; // 如果沒有其他字母可選，則直接退出
                
                auto [count2, char2] = pq.top();
                pq.pop();
                
                // 加入次多的字母
                result += char2;
                if (--count2 > 0) {
                    pq.push({count2, char2});
                }
                
                // 然後把之前次數最多的字母放回堆中
                pq.push({count1, char1});
            } else {
                // 如果不會造成三連續，則直接加入該字母
                result += char1;
                if (--count1 > 0) {
                    pq.push({count1, char1});
                }
            }
        }
        
        return result;
    }
};
```
