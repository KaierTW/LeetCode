# 1894. Find the Student that Will Replace the Chalk
Problem : [HERE](https://leetcode.com/problems/find-the-student-that-will-replace-the-chalk/description)

>[!TIP]
>要用找餘數的方法比較快，不然會超時
>
>然後accumulate後面要用0LL，那樣才是long long

```CPP
class Solution {
public:
    int chalkReplacer(vector<int>& chalk, int k) {
        int index = 0;
        long long sum = 0;        
        sum = accumulate(chalk.begin() , chalk.end() , 0LL);
        k %= sum;
        while(k > 0){            
            k -= chalk[index++];
            if(k < 0) index--;
            if(index == chalk.size()) index = 0;            
        }
        return index;
    }
};
```
