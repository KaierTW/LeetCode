# 14. Longest Common Prefix
Problem : [HERE](https://leetcode.com/problems/longest-common-prefix/description/)

>[!TIP]
>
>Longest Common Prefix這題的解題思路可以分為以下幾個步驟：
>
>1. **題目理解**：
>   - 題目要求找出一組字串陣列中最長的共用前綴。
>   - 如果沒有共用前綴，則返回空字串。
>
>2. **基本思路**：
>   - 可以先拿第一個字串作為初始的共用前綴（prefix）。
>   - 然後逐個字串與這個初始前綴進行比對，逐步縮短前綴直到找到最長的共用前綴。
>
>3. **具體步驟**：
>   - 先檢查字串陣列是否為空，若是空則返回空字串。
>   - 取第一個字串作為初始前綴。
>   - 從第二個字串開始，逐個字串與前綴進行比對：
>     - 如果當前字串不包含前綴，則縮短前綴（去掉末尾字符），繼續比對。
>     - 重複上述步驟直到找到最長的共用前綴。
>

```CPP
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {        
        for(int i = 0 ; i < strs[0].size() ; i++){
            char c = strs[0][i];
            for(int j = 1 ; j < strs.size() ; j++){
                if(i == strs[j].size() || strs[j][i] != c) return strs[0].substr(0, i);
            }
        }
        return strs[0];
    }
};
```
