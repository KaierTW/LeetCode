# 2264. Largest 3-Same-Digit Number in String
Problem : [HERE](https://leetcode.com/problems/largest-3-same-digit-number-in-string/description/)

>[!TIP]
>LeetCode 第 2264 題 **Largest 3-Same-Digit Number in String** 的題目是：
>
> 給你一個字串 `num`，裡面只包含數字。請你找出字串中出現的所有 **三個相同數字連在一起** 的子字串，並回傳其中最大的那一個（以字串形式回傳）。如果沒有這樣的子字串，回傳空字串 `""`。
>
>---
>
>### 🧠 解題思路
>
>這題的關鍵是：
>
>1. **掃描整個字串**，找出所有連續三個相同數字的子字串。
>2. **記錄最大值**（以字串或整數都可以）。
>3. **回傳最大值**（以字串形式）。
>
>---
>
>### ✅ 解法步驟
>
>1. 從第 0 到第 `num.size() - 3` 的位置開始掃描。
>2. 每次檢查 `num[i] == num[i+1] == num[i+2]`。
>3. 如果符合條件，就把這個三位數字記錄下來。
>4. 最後回傳最大的一個。
>
>---
>
>### ✅ C++ 範例程式碼
>
>```cpp
>class Solution {
>public:
>    string largestGoodInteger(string num) {
>        string maxStr = "";
>        for (int i = 0; i <= num.size() - 3; ++i) {
>            if (num[i] == num[i+1] && num[i] == num[i+2]) {
>                string current = num.substr(i, 3);
>                if (current > maxStr) {
>                    maxStr = current;
>                }
>            }
>        }
>        return maxStr;
>    }
>};
>```
>
>---
>
>### 🔍 範例說明
>
>```cpp
>Input: num = "6777133339"
>Output: "777"
>```
>
>- 有三個符合條件的子字串：`777`, `333`, `999`
>- 最大的是 `"777"`
>
>---
>
>這題其實不難，但要注意：
>- 比較字串大小時，字串 `"999"` > `"888"` 是正確的。
>- 不需要轉成整數也可以比較大小，因為字串長度固定為 3。
>
>---
>



```CPP
class Solution {
public:
    string largestGoodInteger(string num) {
        vector<string> candi;
        for(int i = 0 ; i < num.size() - 2 ; i++){
            if(num[i] == num[i + 1] && num[i] == num[i + 2] && num[i + 1] == num[i + 2]){
                candi.push_back(num.substr(i, 3));
            }            
        }
        if(candi.size() > 1){
            int temp = INT_MIN, ans = 0;            
            for(int i = 0 ; i < candi.size() ; i++){
                if(stoi(candi[i]) > temp) {
                    temp = stoi(candi[i]);
                    ans = i;
                }
            }
            return candi[ans];
        }
        else if(candi.size() == 1) return candi[0];
        else return "";

    }
};
```
