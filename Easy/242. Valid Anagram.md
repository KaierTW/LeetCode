# 242. Valid Anagram
Problem : [HERE](https://leetcode.com/problems/valid-anagram/description/)

>[!TIP]
>LeetCode 242題「Valid Anagram」的解題思路主要有兩種方法：
>
>1. **排序法**：
>   - **思路**：將兩個字串分別排序，然後比較排序後的字串是否相同。如果相同，則表示兩個字串是字母異位詞（anagram）。
>   - **時間複雜度**：$$O(N \log N)$$
>   - **空間複雜度**：$$O(1)$$
>   - **示例代碼**：
>     ```cpp
>     class Solution {
>     public:
>         bool isAnagram(string s, string t) {
>             sort(s.begin(), s.end());
>             sort(t.begin(), t.end());
>             return s == t;
>         }
>     };
>     ```
>
>2. **哈希表法**：
>   - **思路**：使用哈希表記錄每個字元出現的次數，然後比較兩個字串中每個字元的出現次數是否相同。如果相同，則表示兩個字串是字母異位詞。
>   - **時間複雜度**：$$O(N)$$
>   - **空間複雜度**：$$O(N)$$
>   - **示例代碼**：
>     ```cpp
>     class Solution {
>     public:
>         bool isAnagram(string s, string t) {
>             short hmap[26] = {0};
>             for(const auto& c: s) ++hmap[c-'a'];
>             for(const auto& c: t) --hmap[c-'a'];
>             for(const auto& num: hmap) if(num != 0) return false;
>             return true;
>         }
>     };
>     ```
>

```CPP
class Solution {
public:
    bool isAnagram(string s, string t) {
        unordered_map<char, int>counter;
        for(char c : s){
            counter[c]++;
        }
        for(char c : t){
            if(counter.find(c) != counter.end()) counter[c]--;
            else return false;
        }
        for(const auto& pair : counter){
            if(pair.second != 0) return false;
        }
        return true;
    }
};
```
