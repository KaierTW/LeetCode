# 168. Excel Sheet Column Title

>[!TIP]
>LeetCode 168（Excel Sheet Column Title）的核心概念是「十進位轉二十六進位」，但它有一個非常關鍵的陷阱：**沒有 0 的概念**。
>
>一般的 10 進位或 26 進位是從 $0 \sim 25$ 代表字母，但 Excel 的欄位是從 $1 \sim 26$ 對應到 `A` $\sim$ `Z`。這導致直接用取餘數（`% 26`）和整除（`/ 26`）時，遇上 `Z`（即 26 的倍數）會出錯。
>
>這裡提供幾個逐步推導的提示：
>
>### 提示 1：解開「1-indexed」的陷阱
>
>因為字母是從 `1` 開始（`1` $\rightarrow$ `'A'`, `26` $\rightarrow$ `'Z'`），為了讓標準的進位制餘數運算（$0 \sim 25$）成立，**每一輪處理前，先將當前的數字減 1**。
>
>* 減 1 之後，範圍就會變成 $0 \sim 25$：
>* `0` 對應到 `'A'`
>* `25` 對應到 `'Z'`
>
>
>
>### 提示 2：如何拿到當前最低位的字元？
>
>當你把 `columnNumber` 減 1 之後：
>
>1. **取餘數**：`(columnNumber - 1) % 26` 可以拿到當前最後一位對應的偏移量。
>2. **轉字元**：`'A' + ((columnNumber - 1) % 26)` 就能得到對應的 C++ `char`。
>3. **前移一位**：處理完最後一位後，要將數字縮小，更新為 `columnNumber = (columnNumber - 1) / 26`。
>
>### 提示 3：字串拼接的方向
>
>因為我們每次算出來的都是最右邊（最低位）的字元，所以字串拼接時：
>
>* 你可以每次把字元加在 `std::string` 的末尾（`push_back`），最後再將整個字串反轉（`std::reverse`）。
>* 或者每次把新字元加在字串最前面（但這會頻繁搬移記憶體，效率較低）。
>
>---
>
>### 虛擬碼思考方向
>
>```cpp
>string result = "";
>while (columnNumber > 0) {
>    columnNumber--; // 核心：先減 1 offset
>    
>    // 算出當前字元並放入 result
>    char c = 'A' + (columnNumber % 26);
>    result.push_back(c);
>    
>    // 前進到下一位
>    columnNumber /= 26;
>}
>
>// 記得 reverse，因為我們是從個位數開始加進去的
>
>`
>``
>


```CPP
class Solution {
public:
    string convertToTitle(int columnNumber) {
        string result;
        while(columnNumber > 0){
            columnNumber--;
            result.push_back('A' + columnNumber % 26);
            columnNumber /= 26;
        }
        reverse(result.begin(), result.end());
        return result;
    }
};
```
