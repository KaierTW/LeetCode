# 104. Maximum Depth of Binary Tree
Problem : [HERE](https://leetcode.com/problems/maximum-depth-of-binary-tree/description/)

>[!TIP]
>用遞迴的方式，先找左邊再找右邊
>
>如果node是NULL回傳0，上一層就會+1，一直回傳上去。

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int findDepth(TreeNode* node ){
        if(node == NULL) return 0;
        else{
            int leftDepth = findDepth(node -> left) + 1;
            int rightDepth = findDepth(node -> right) + 1;
            if(leftDepth > rightDepth) return leftDepth;
            else return rightDepth;
        }
    }
    int maxDepth(TreeNode* root) {
        return findDepth(root);
    }
};
```

>[!TIP]
>LeetCode 第 104 題「Maximum Depth of Binary Tree」的解題思路如下：
>
>---
>
>### 🧩 題目描述：
>給定一個二元樹（Binary Tree），請找出其最大深度（Maximum Depth）。
>
>- 最大深度是從根節點到最遠葉節點的最長路徑上的節點數。
>
>---
>
>### ✅ 解題思路：
>
>這題可以用 **遞迴（DFS）** 或 **層序遍歷（BFS）** 來解。
>
>---
>
>#### 方法一：遞迴（DFS）
>
>**核心概念：**
>- 對每個節點，最大深度 = 左子樹最大深度與右子樹最大深度的最大值 + 1。
>
>**程式邏輯：**
>1. 如果節點是 `null`，回傳 0。
>2. 否則，遞迴計算左子樹和右子樹的深度。
>3. 回傳 `max(左深度, 右深度) + 1`。
>
>---
>
>#### 方法二：層序遍歷（BFS）
>
>**核心概念：**
>- 使用 queue 進行層層遍歷，每遍歷一層就將深度加一。
>
>**程式邏輯：**
>1. 如果根節點是 `null`，回傳 0。
>2. 使用 queue 儲存每層的節點。
>3. 每次迴圈處理一層，深度加一。
>
>---
>
>### 🆚 DFS vs BFS 比較：
>
>| 方法 | 優點 | 缺點 |
>|------|------|------|
>| DFS | 寫法簡潔、直觀 | 遞迴深度可能導致 stack overflow（極端情況） |
>| BFS | 不會有遞迴問題 | 需要額外的 queue 空間 |
>
>---
>


DFS:
```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(root == NULL) return 0;
        else return 1 + max(maxDepth(root -> left), maxDepth(root -> right));
    }
};
```

BFS:
```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(root == NULL) return 0;
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        while(!q.empty()){
            depth++;
            int thisDepthNode = q.size();
            for(int i = 0 ; i < thisDepthNode ; i++){
                TreeNode* node = q.front();
                q.pop();

                if(node -> left != NULL){
                    q.push(node -> left);
                }

                if(node -> right != NULL){
                    q.push(node -> right);
                }
            }
        }
        return depth;
    }
};
```
