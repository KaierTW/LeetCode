# 2185. Counting Words With a Given Prefix
Problem : [HERE](https://leetcode.com/problems/counting-words-with-a-given-prefix/description/)

>[!TIP]
>一樣用find就可以了

```CPP
class Solution {
public:
    int prefixCount(vector<string>& words, string pref) {
        int ans = 0;
        for(int i = 0 ; i < words.size() ; i++){
            if(words[i].find(pref) == 0) ans++;
        }
        return ans;
    }
};
```
