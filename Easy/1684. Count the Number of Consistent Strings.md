# 1684. Count the Number of Consistent Strings
Problem : [HERE](https://leetcode.com/problems/count-the-number-of-consistent-strings/description/)

>[!TIP]
>先把可通過的字母記錄起來，然後去檢查

```CPP
class Solution {
public:
    int countConsistentStrings(string allowed, vector<string>& words) {
        vector<int> check(26 , 0);
        for(char c : allowed){
            check[c - 'a'] = 1;
        }
        int ans = 0;
        for(string word : words){
            int allow = 1;
            for(char c : word){
                if(check[c - 'a'] == 0) {                    
                    allow = 0;
                    break;
                }
            }            
            ans += allow;
        }
        return ans;
    }
};
```
