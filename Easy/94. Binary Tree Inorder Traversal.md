# 94. Binary Tree Inorder Traversal
Problem : [HERE](https://leetcode.com/problems/binary-tree-inorder-traversal/description)

>[!TIP]
>Inorder走法就是第一次返回到節點才讀這個值
>
>可以參考這裡 https://ithelp.ithome.com.tw/articles/10271719


因為題目說The number of nodes in the tree is in the range [0, 100].
所以可以給固定大小的陣列

```C
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
void AddAnswer(struct TreeNode* root , int* ans , int* count)
{
    if(root != NULL){
        AddAnswer(root -> left , ans , count);
        ans[(*count)++] = root -> val;
        AddAnswer(root -> right , ans , count);
    }
}

int* inorderTraversal(struct TreeNode* root, int* returnSize) {
    int* ans = malloc(150 * sizeof(int));
    int count = 0;
    AddAnswer(root , ans , &count);
    *returnSize = count;
    return ans;
}
```

如果是用在recursion裡面使用realloc的話
就要傳入ans的地址(ans本來就是pointer，所以要傳入pointer的pointer)
原因是因為如果只傳ans(就是pointer)的話
傳遞到AddAnswer函數的時候他只是傳遞值(只是一個副本)
所以如果改的話也只是改那個副本 不會改到真正的值 也就是說對應不到真正的pointer
所以要傳入pointer的pointer，這樣改的話才能真正改到裡面的值

```C
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
void AddAnswer(struct TreeNode* root , int** ans , int* count)
{
    if(root != NULL){
        AddAnswer(root -> left , ans , count);
        (*ans)[(*count)++] = root -> val;
        (*ans) = realloc((*ans) , ((*count) + 1) * sizeof(int));
        AddAnswer(root -> right , ans , count);
    }
}

int* inorderTraversal(struct TreeNode* root, int* returnSize) {
    int* ans = malloc(sizeof(int));
    int count = 0;
    AddAnswer(root , &ans , &count);
    *returnSize = count;
    return ans;
}
```
