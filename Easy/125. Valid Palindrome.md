# 125. Valid Palindrome
Problem : [HERE]()

>[!TIP]
>解題思路如下：
>
>題目要求我們判斷一個字符串是否為回文，即忽略大小寫和非字母數字字符後，該字符串正讀和反讀是否相同。這裡有一個常見的解題方法：
>
>1. **預處理字符串**：將所有字母轉換為小寫，並移除所有非字母數字字符。
>2. **使用雙指針法**：設置兩個指針，一個從字符串的開頭開始（左指針），另一個從字符串的末尾開始（右指針）。逐步向中間移動這兩個指針，並比較它們指向的字符。
>3. **比較字符**：如果兩個指針指向的字符不相同，則字符串不是回文；如果相同，則繼續移動指針直到它們相遇或交錯。


```CPP
class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0, right = s.size() - 1;
        while(left < right){
            while(!isalnum(s[left]) && left < right) left++;
            while(!isalnum(s[right]) && left < right) right--;
            if(tolower(s[left++]) != tolower(s[right--])) return false;
        }
        return true;
    }
};
```
