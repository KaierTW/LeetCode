# 226. Invert Binary Tree
Problem : [HERE](https://leetcode.com/problems/invert-binary-tree/description)

>[!TIP]
>LeetCode 第 226 題「Invert Binary Tree」是一題非常經典的二元樹操作題，也常被用來作為面試題。這題的目標是：**將一棵二元樹左右子樹「對調」**，也就是把整棵樹「鏡像翻轉」。
>
>---
>
>### 🧩 題目描述：
>給定一棵二元樹，請將它「反轉」，也就是對每個節點，把它的左子樹和右子樹交換。
>
>---
>
>### ✅ 解題思路：
>
>這題可以用 **遞迴（DFS）** 或 **迴圈（BFS）** 來解。
>
>---
>
>#### 方法一：遞迴（DFS）
>
>**核心概念：**
>- 對每個節點，交換它的左右子節點。
>- 然後遞迴處理左右子節點。
>
>**程式邏輯：**
>1. 如果節點是 `None`，直接回傳。
>2. 否則，交換左右子節點。
>3. 遞迴處理左右子節點。
>
>---
>
>#### 方法二：迴圈（BFS）
>
>**核心概念：**
>- 使用 queue 進行層序遍歷。
>- 每遇到一個節點就交換它的左右子節點。
>
>---
>
>| 方法 | 優點 | 缺點 |
>|------|------|------|
>| DFS 遞迴 | 寫法簡潔、直觀 | 深度太深可能造成 stack overflow |
>| BFS 迴圈 | 不用遞迴，適合大樹 | 程式稍微複雜一點 |
>
>---
>


DFS:
```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if(root == NULL) return NULL;
        TreeNode* temp = root -> left;
        root -> left = root -> right;
        root -> right = temp;
        invertTree(root -> left);
        invertTree(root -> right);
        return root;
    }
};
```

BFS:
```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if(root == NULL) return NULL;
        queue<TreeNode*> q;
        q.push(root);
        while(!q.empty()){
            TreeNode* node = q.front();
            q.pop();
            swap(node -> left, node -> right);
            if(node -> left != NULL) q.push(node -> left);
            if(node -> right != NULL) q.push(node -> right);
        }
        return root;
    }
};
```
