# 100. Same Tree
Problem : [HERE](https://leetcode.com/problems/same-tree/description/)

>[!TIP]
>用遞迴的方式，如果當前節點有同樣的值，兩邊就繼續從左邊開始找

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if(p == NULL && q == NULL) return true;
        else if(p == NULL || q == NULL) return false;
        else if(p->val == q->val) return isSameTree(p->left , q->left) && isSameTree(p->right,q->right);
        else return false;
    }
};
```

>[!TIP]
>LeetCode 第 100 題「Same Tree」的解題思路其實滿直觀的，這題主要是考你對 **遞迴（DFS）** 的理解與應用。
>
>---
>
>### 🧩 題目描述：
>給你兩棵二元樹 `p` 和 `q`，請判斷這兩棵樹是否「完全相同」。
>
>**兩棵樹相同的條件是：**
>1. 結構完全一樣。
>2. 對應節點的值也完全一樣。
>
>---
>
>### ✅ 解題思路（使用 DFS 遞迴）：
>
>我們可以用一個遞迴函數來比較兩棵樹的每一個對應節點。
>
>#### 步驟如下：
>
>1. **如果兩個節點都是 `None`（空節點）**，代表這部分結構相同，回傳 `True`。
>2. **如果其中一個是 `None`，另一個不是**，代表結構不同，回傳 `False`。
>3. **如果兩個節點的值不同**，回傳 `False`。
>4. 否則，遞迴比較左右子樹是否相同。
>
>---
>
>### 🧠 補充說明：
>
>這題的核心是「同步地」比較兩棵樹的每一個節點，確保：
>- 結構一致（左右子樹都對應得上）
>- 值一致（每個節點的值都相同）
>
>---
>

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if(p == NULL && q == NULL) return true;
        if(p != NULL && q != NULL && p -> val == q -> val){
            return(isSameTree(p -> left, q -> left) && isSameTree(p -> right, q -> right));
        }
        else return false;
    }
};
```
