# 88. Merge Sorted Array
Problem : [HERE](https://leetcode.com/problems/merge-sorted-array/description/)

>[!TIP]
>
>### 解題思路
>我們可以使用雙指針法從後向前合併兩個數組，這樣可以避免移動元素。具體步驟如下：
>1. 初始化三個指針：`i` 指向 `nums1` 的最後一個有效元素（`m-1`），`j` 指向 `nums2` 的最後一個元素（`n-1`），`k` 指向 `nums1` 的最後一個位置（`m+n-1`）。
>2. 比較 `nums1[i]` 和 `nums2[j]`，將較大的元素放到 `nums1[k]`，並移動相應指針。
>3. 重複上述步驟直到所有元素合併完成。


```CPP
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        while(m > 0 && n > 0){
            if(nums2[n - 1] > nums1[m - 1]){
                nums1[m + n - 1] = nums2[n - 1];
                n--;
            }
            else{
                nums1[m + n - 1] = nums1[m - 1];
                m--;
            }
        }
        while(n > 0){
            nums1[m + n - 1] = nums2[n - 1];
            n--;
        }
    }
};
```
