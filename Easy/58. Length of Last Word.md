# 58. Length of Last Word
Problem : [HERE](https://leetcode.com/problems/length-of-last-word/description/)



```CPP
class Solution {
public:
    int lengthOfLastWord(string s) {
        int ans = 0;
        bool find = false;
        for(int i = s.size() - 1 ; i >= 0 ; i--){
            if(s[i] != ' ') {
                ans++;
                find = true;
            }
            else{
                if(find) break;
                else continue;
            }
        }
        return ans;
    }
};
```
