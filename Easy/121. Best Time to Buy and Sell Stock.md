# 121. Best Time to Buy and Sell Stock
Problem : [HERE](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/)

>[!TIP]
>
>### 解題思路
>1. **初始化變量**：設置兩個變量 `min_price` 為無限大（表示尚未買入），`max_profit` 為 0（表示初始利潤為 0）。
>2. **遍歷價格數組**：對於每一天的價格 `price`：
>   - 更新 `min_price` 為當前價格和之前最低價格中的較小值。
>   - 計算當前價格賣出時的潛在利潤，即 `price - min_price`，並更新 `max_profit` 為當前最大利潤。

```CPP
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int buy = INT_MAX, profit = INT_MIN;
        for(int price : prices){
            if(price < buy) buy = price;
            profit = max(profit, price - buy);
        }
        return profit;
        
    }
};
```
