# 21. Merge Two Sorted Lists
Problem : [HERE](https://leetcode.com/problems/merge-two-sorted-lists/description/)

>[!TIP]
>兩個節點先比大小，比較小的那個位址給ans
>
>比較小的next再和剛剛比較大的那個比較
>
>用遞迴

```C
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2) {
    struct ListNode* ans;
    if(list1 == NULL) return list2;
    else if(list2 == NULL) return list1;
    else if(list1 == NULL && list2 == NULL) return NULL;
    else{
        if(list1 -> val > list2 -> val){
            ans = list2;
            ans -> next = mergeTwoLists(list1 , list2 -> next);
        }
        else{
            ans = list1;
            ans -> next = mergeTwoLists(list1 -> next , list2);
        }
    }
    return ans;
}
```

>[!TIP]
>LeetCode 第 21 題「Merge Two Sorted Lists」的解題思路主要是處理兩個已排序的單向鏈結串列，將它們合併成一個新的排序好的鏈結串列。這題是典型的鏈結串列操作題，考察的是指標操作與遞迴或迴圈的使用。
>
>### 🧠 解題思路
>
>#### 方法一：迴圈（Iterative）
>
>1. **建立虛擬頭節點（dummy node）**：這個節點不存放實際資料，只是為了方便操作。
>2. **使用一個指標 `current` 指向 dummy**，用來逐步建立新的鏈結串列。
>3. **比較兩個鏈結串列的頭節點值**：
>   - 如果 `l1.val < l2.val`，將 `l1` 接到 `current.next`，並移動 `l1`。
>   - 否則將 `l2` 接到 `current.next`，並移動 `l2`。
>4. **移動 `current` 到下一個節點**。
>5. **重複步驟 3-4，直到其中一個鏈結串列為空**。
>6. **將剩下的鏈結串列接到 `current.next`**（因為剩下的部分已經是排序好的）。
>
>#### 方法二：遞迴（Recursive）
>
>1. **終止條件**：如果 `l1` 或 `l2` 為空，直接回傳另一個鏈結串列。
>2. **比較 `l1.val` 和 `l2.val`**：
>   - 如果 `l1.val < l2.val`，則 `l1.next = merge(l1.next, l2)`，回傳 `l1`。
>   - 否則 `l2.next = merge(l1, l2.next)`，回傳 `l2`。
>
>### ✅ 時間與空間複雜度
>
>- **時間複雜度**：$$O(n + m)$$，其中 $$n$$ 和 $$m$$ 是兩個鏈結串列的長度。
>- **空間複雜度**：
>  - 迴圈版本是 $$O(1)$$（除了輸出鏈結串列外）。
>  - 遞迴版本是 $$O(n + m)$$（因為遞迴呼叫堆疊）。
>

```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode* ans = new ListNode();
        ListNode* temp = ans;
        while(list1 && list2){
            int num1 = list1 -> val;
            int num2 = list2 -> val;
            if(num1 < num2){
                temp -> next = list1;
                list1 = list1 -> next;                
            }
            else{
                temp -> next = list2;
                list2 = list2 -> next;
            }
            temp = temp -> next;
        }
        if(list1 == NULL) temp -> next = list2;
        if(list2 == NULL) temp -> next = list1;
        return ans -> next;
    }
};
```
