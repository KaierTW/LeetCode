# 326. Power of Three
Problem : [HERE](https://leetcode.com/problems/power-of-three/description/)

>[!TIP]
>LeetCode 第 326 題 **Power of Three** 的目標是判斷一個整數 `n` 是否為 3 的冪次方（即是否存在整數 `x` 使得 $$3^x = n$$）。這題可以用幾種不同的方法來解決，以下是幾種常見且效率高的方法：
>
>---
>
>### ✅ 方法一：迴圈除法（Loop Division）
>這是最直觀的方法，不斷地除以 3，直到不能整除為止。
>
>```cpp
>class Solution {
>public:
>    bool isPowerOfThree(int n) {
>        if (n < 1) return false;
>        while (n % 3 == 0) {
>            n /= 3;
>        }
>        return n == 1;
>    }
>};
>
>```
>
>- **時間複雜度**： $$O(\log_3 n)$$
>- **空間複雜度**： $$O(1)$$
>
>---
>
>### ✅ 方法二：數學法（最大 3 的冪）
>因為 32-bit 整數中最大的 3 的冪是 $$3^{19} = 1162261467$$，所以只要這個數能被 `n` 整除，`n` 就是 3 的冪。
>
>```cpp
>class Solution {
>public:
>    bool isPowerOfThree(int n) {
>        // 3^19 = 1162261467 是 int 範圍內最大的 3 的冪
>        return n > 0 && 1162261467 % n == 0;
>    }
>};
>
>```
>
>- **時間複雜度**： $$O(1)$$
>- **空間複雜度**： $$O(1)$$
>- **優點**：非常快，無需迴圈
>
>---
>
>### ✅ 方法三：使用對數（Logarithmic Method）
>利用對數的性質： $$\log_b a = \frac{\log_k a}{\log_k b}$$，檢查是否為整數。
>
>```cpp
>#include <cmath>
>
>class Solution {
>public:
>    bool isPowerOfThree(int n) {
>        if (n <= 0) return false;
>        double logVal = log10(n) / log10(3);
>        return fabs(logVal - round(logVal)) < 1e-10;
>    }
>};
>
>```
>
>- **注意**：浮點數誤差可能導致錯誤結果，建議加上誤差容忍度：
>```python
>return abs(round(log_val) - log_val) < 1e-10
>```
>
>---
>
>### 哪個方法最快？
>- **方法二（最大 3 的冪）** 是最快的，因為它是常數時間。
>- 如果你不喜歡硬編碼最大值，**方法一（迴圈除法）** 是最穩定且簡潔的選擇。
>



```CPP
class Solution {
public:
    bool isPowerOfThree(int n) {
        if(n <= 0) return false;
        while(n % 3 == 0){
            n /= 3;
        }
        return (n == 1) ? true : false;
    }
};
```
