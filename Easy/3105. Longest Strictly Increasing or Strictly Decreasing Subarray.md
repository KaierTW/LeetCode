# 3105. Longest Strictly Increasing or Strictly Decreasing Subarray
Problem : [HERE](https://leetcode.com/problems/longest-strictly-increasing-or-strictly-decreasing-subarray/description/)

>[!TIP]
>題目要求我們找到一個整數數組中最長的嚴格遞增或嚴格遞減的子數組的長度。讓我們來看看如何解決這個問題。
>
>### 解題思路
>1. **初始化變量**：
>   - `max_len` 用來記錄最長子數組的長度。
>   - `current_len` 用來記錄當前子數組的長度。
>   - `direction` 用來記錄當前子數組的方向（1 表示遞增，-1 表示遞減，0 表示未確定）。
>
>2. **遍歷數組**：
>   - 從第二個元素開始，與前一個元素比較。
>   - 如果當前元素大於前一個元素，則表示遞增；如果小於前一個元素，則表示遞減。
>   - 根據比較結果更新 `current_len` 和 `direction`。
>   - 如果方向改變，則重置 `current_len` 並更新 `max_len`。
>
>3. **更新最長子數組長度**：
>   - 在遍歷結束後，確保 `max_len` 包含最長的子數組長度。
>
>
```CPP
class Solution {
public:
    int longestMonotonicSubarray(vector<int>& nums) {
        int increase = 1, decrease = 1, ans = 1;
        for(int i = 0 ; i < nums.size() - 1 ; i++){
            if(nums[i] > nums[i + 1]) {
                decrease++;
                increase = 1;
            }
            else if(nums[i] < nums[i + 1]){
                increase++;
                decrease = 1;
            }
            else{
                increase = 1;
                decrease = 1;
            }
            ans = max({ans, increase, decrease});
        }
        return ans;
    }
};
```
