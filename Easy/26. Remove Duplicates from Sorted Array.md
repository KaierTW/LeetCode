# 26. Remove Duplicates from Sorted Array
Problem : [HERE](https://leetcode.com/problems/remove-duplicates-from-sorted-array/description/)

>[!TIP]
>要記錄總共有幾個只有唯一的數字，然後把原本的陣列改成只有唯一的數字的

```C
int removeDuplicates(int* nums, int numsSize) {
    int ans = 1;
    int index = 1;
    for(int i = 0 ; i < numsSize - 1 ; i++){
        if(nums[i] != nums[i + 1]){
            ans++;
            nums[index++] = nums[i + 1];
        }
    }
    return ans;
}
```

Update (2025/03/28)

>[!TIP]
>
>1. 初始化指針 `k` 為0，表示唯一元素的最後位置。
>2. 遍歷數組，當遇到不重複的元素時，將其移動到 `k` 的位置，並將 `k` 增加1。
>3. 最後返回 `k + 1`，即唯一元素的數量。
>

```CPP
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int count = 1;        
        for(int i = 0 ; i < nums.size() - 1 ; i++){                        
            if(nums[i] != nums[i + 1]){
                nums[count++] = nums[i + 1];
            }
        }
        return count;
    }
};
```
