# 27. Remove Element
Problem : [HERE](https://leetcode.com/problems/remove-element/description/)

>[!TIP]
>跟[26. Remove Duplicates from Sorted Array](./26.%20Remove%20Duplicates%20from%20Sorted%20Array.md)類似

```C
int removeElement(int* nums, int numsSize, int val) {
    int index = 0 , ans = 0;
    for(int i = 0 ; i < numsSize; i++){
        if(nums[i] != val)
        {
            ans++;
            nums[index++] = nums[i];
        }         
    }
    return ans;
}
```

Update(2025/03/27)

>[!TIP]
>當然會！這題是 LeetCode 上的第 27 題 "Remove Element"。題目要求我們從一個整數數組中移除所有指定的數值，並返回移除後數組的長度。這個操作需要在原地進行，也就是說不能使用額外的數組空間。
>
>這裡有一個簡單的解法，使用雙指針技術：
>
>1. 初始化一個指針 `k` 為 0，這個指針用來標記非目標值的位置。
>2. 遍歷數組中的每一個元素：
>   - 如果當前元素不等於目標值 `val`，則將其移動到 `k` 指針的位置，並將 `k` 增加 1。
>3. 最後，`k` 的值就是移除目標值後的數組長度。


```CPP
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int count = 0;
        for(int i = 0 ; i < nums.size() ; i++){
            if(nums[i] != val){
                nums[count++] = nums[i];
            }
        }
        return count;
    }
};
```
