# 27. Remove Element
Problem : [HERE](https://leetcode.com/problems/remove-element/description/)

>[!TIP]
>跟[26. Remove Duplicates from Sorted Array](./26.%20Remove%20Duplicates%20from%20Sorted%20Array.md)類似

```C
int removeElement(int* nums, int numsSize, int val) {
    int index = 0 , ans = 0;
    for(int i = 0 ; i < numsSize; i++){
        if(nums[i] != val)
        {
            ans++;
            nums[index++] = nums[i];
        }         
    }
    return ans;
}
```
