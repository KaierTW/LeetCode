# 1957. Delete Characters to Make Fancy String
Problem : [HERE](https://leetcode.com/problems/delete-characters-to-make-fancy-string/description)

>[!TIP]
>這題在 LeetCode 中的目標是刪除一些字元，使字串不包含三個或更多相同的連續字元。要達到這個目標，可以採用線性掃描的方式遍歷字串，並用簡單的計數邏輯來判斷當前的字元是否已經重複了兩次，如果是就忽略它，否則就將它保留。
>
>### 方法：線性掃描與條件計數
>
>我們可以使用一個變數來計算當前的字元連續出現的次數。當發現連續字元超過兩個時，我們就忽略該字元；如果次數不超過兩個，就將字元加入結果字串中。
>
>### 實作步驟
>
>1. 初始化一個空的結果字串 `result`，以及一個計數器 `count`，用來計算當前連續字元的數量。
>2. 使用一個迴圈遍歷原始字串的每個字元。
>3. 檢查當前字元是否與上個字元相同：
>   - 若相同，增加 `count`。
>   - 若不同，則將 `count` 重置為 1（表示這是一個新的連續字元）。
>4. 若 `count` 小於等於 2，則將該字元加入 `result`。
>5. 最後，`result` 就是符合條件的結果。
>
>### 解釋
>
>- 當 `s[i] == s[i-1]` 時，我們增加 `count`。
>- 當 `s[i] != s[i-1]` 時，將 `count` 重設為 1，表示新的字元序列開始。
>- 只有當 `count <= 2` 時才將當前字元加入結果字串中。
>
>### 時間與空間複雜度
>- **時間複雜度**：O(n)，其中 n 是字串的長度，只需掃描一次字串。
>- **空間複雜度**：O(n)，因為我們需要一個新字串來儲存結果。

```CPP
class Solution {
public:
    string makeFancyString(string s) {
        int count = 1;
        string ans;
        ans += s[0];
        for(int i = 1 ; i < s.size() ; i++){
            if(s[i] == s[i - 1]){
                count++;
            }
            else{
                count = 1;
            }

            if(count < 3){
                ans += s[i];
            }
        }
        return ans;
    }
};
```
