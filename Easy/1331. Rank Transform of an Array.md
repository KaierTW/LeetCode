# 1331. Rank Transform of an Array
Problem : [HERE](https://leetcode.com/problems/rank-transform-of-an-array/description/)

>[!TIP]
>題目 **1331. Rank Transform of an Array** 的目的是對一個整數數組進行排名轉換，將每個數字轉換為它在排序後的排名。具體要求如下：
>
>- 對於給定數組中的每個數字，找到它在排序數組中的**相對排名**。排名從 1 開始，並且相等的數字應該有相同的排名。
>
>### 例子
>
>**輸入**：
>```
>arr = [40, 10, 20, 30]
>```
>
>**輸出**：
>```
>[4, 1, 2, 3]
>```
>
>在這個例子中，經過排序後，數組變成 `[10, 20, 30, 40]`，它們的排名依次為 `1, 2, 3, 4`，所以對應的結果是 `[4, 1, 2, 3]`。
>
>---
>
>### 解題思路
>
>1. **複製並排序數組**：首先，我們需要將數組 `arr` 進行排序，這樣才能確定每個元素的相對順序。
>  
>2. **消除重複元素**：排序後，我們需要確保相同的元素獲得相同的排名。
>
>3. **建立哈希表 (map)**：用一個哈希表來存儲每個元素對應的排名。鍵是數字，值是它的排名。
>
>4. **替換原始數組中的數字**：使用哈希表，將原數組中的每個數字替換成它對應的排名。
>
>### 步驟
>
>1. **排序並消除重複元素**。
>2. **建立哈希表**，將每個唯一數字與其排名對應。
>3. **遍歷原數組**，用哈希表將每個數字替換成排名。
>
>---
>
>### 解法步驟詳解：
>
>1. **排序數組**：
>   ```cpp
>   vector<int> sortArr = arr;
>   sort(sortArr.begin(), sortArr.end());
>   ```
>   將原數組進行排序。
>
>2. **消除重複**：
>   ```cpp
>   sortArr.erase(unique(sortArr.begin(), sortArr.end()), sortArr.end());
>   ```
>   使用 `unique()` 函數移除相鄰的重複元素，然後 `erase()` 移除它們。
>
>3. **建立排名**：
>   ```cpp
>   for (int i = 0; i < sortArr.size(); i++) {
>       rank[sortArr[i]] = i + 1;
>   }
>   ```
>   使用 `unordered_map` 來存儲每個數字對應的排名，鍵是數字，值是排名。
>
>4. **替換數組**：
>   ```cpp
>   for (int i = 0; i < arr.size(); i++) {
>       ans[i] = rank[arr[i]];
>   }
>   ```
>   遍歷原數組，將每個數字替換成其排名。
>
>---
>
>### 時間複雜度分析
>- **排序**：對數組進行排序的時間複雜度是 **O(n log n)**，其中 `n` 是數組的大小。
>- **消除重複**：使用 `unique()` 和 `erase()` 消除重複元素的時間複雜度是 **O(n)**。
>- **建立哈希表**：遍歷唯一元素來建立哈希表的時間複雜度是 **O(n)**。
>- **替換原數組**：遍歷原數組將每個元素替換為排名，時間複雜度也是 **O(n)**。
>
>總的時間複雜度為 **O(n log n)**，因為排序是最耗時的部分。
>
>### 總結
>這道題主要考慮排序、去重、和使用哈希表來快速查找排名。這樣可以將問題轉換為一個典型的排序和映射問題，有效地解決相對排名的需求。
>

```CPP
class Solution {
public:
    vector<int> arrayRankTransform(vector<int>& arr) {
        unordered_map<int , int> rank;
        vector<int> ans(arr.size());
        vector<int> sortArr = arr;

        //排序
        sort(sortArr.begin() , sortArr.end());

        //消除重複
        sortArr.erase(unique(sortArr.begin() , sortArr.end()) , sortArr.end());

        for(int i = 0 ; i < sortArr.size() ; i++){
            rank[sortArr[i]] = i + 1;
        }

        for(int i = 0 ; i < arr.size() ; i++){
            ans[i] = rank[arr[i]];
        }
        return ans;
    }
};
```
