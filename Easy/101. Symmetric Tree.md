# 101. Symmetric Tree

>[!TIP]
>也是一樣用遞迴，判斷有沒有平衡，而且值要一樣
>

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool symmetric (TreeNode* left , TreeNode* right){
        if(left == NULL && right == NULL) return true;
        else if(left == NULL || right == NULL) return false;
        else return (left -> val == right -> val) && symmetric(left -> left , right -> right) && symmetric(left -> right , right -> left);
    }

    bool isSymmetric(TreeNode* root) {
        if(root -> left == NULL && root -> right == NULL) return true;
        else return symmetric(root -> left , root -> right);
    }
};
```

>[!TIP]
>LeetCode 第 101 題「Symmetric Tree」的解題思路是判斷一棵二元樹是否是**對稱的（鏡像的）**。這題和第 100 題（Same Tree）有點類似，但這次我>們要比較的是「左右子樹是否互為鏡像」。
>
>---
>
>### 🧩 題目描述：
>給定一棵二元樹，請判斷它是否是**對稱的**，也就是說，**它的左子樹和右子樹是鏡像對稱的**。
>
>---
>
>### ✅ 解題思路：
>
>這題可以用 **遞迴（DFS）** 或 **迴圈（BFS）** 來解。
>
>---
>
>#### 方法一：遞迴（DFS）
>
>**核心概念：**
>- 定義一個函式 `isMirror(t1, t2)`，用來比較兩棵樹是否互為鏡像。
>- 鏡像的條件是：
>  1. `t1.val == t2.val`
>  2. `t1.left` 與 `t2.right` 是鏡像
>  3. `t1.right` 與 `t2.left` 是鏡像
>
>**程式碼：**
>
>```cpp
>bool isMirror(TreeNode* t1, TreeNode* t2) {
>    if (!t1 && !t2) return true;
>    if (!t1 || !t2) return false;
>    return (t1->val == t2->val) &&
>           isMirror(t1->left, t2->right) &&
>           isMirror(t1->right, t2->left);
>}
>
>bool isSymmetric(TreeNode* root) {
>    if (!root) return true;
>    return isMirror(root->left, root->right);
>}
>```
>
>---
>
>#### 方法二：BFS（使用 queue）
>
>**核心概念：**
>- 使用 queue 同時儲存成對的節點（左、右）。
>- 每次從 queue 中取出兩個節點，比較它們是否相等。
>- 然後把它們的子節點「交叉」加入 queue：
>  - `t1->left` 和 `t2->right`
>  - `t1->right` 和 `t2->left`
>
>**程式碼：**
>
>```CPP
>    if (!root) return true;
>    queue<TreeNode*> q;
>    q.push(root->left);
>    q.push(root->right);
>
>    while (!q.empty()) {
>        TreeNode* t1 = q.front(); q.pop();
>        TreeNode* t2 = q.front(); q.pop();
>
>        if (!t1 && !t2) continue;
>        if (!t1 || !t2) return false;
>        if (t1->val != t2->val) return false;
>
>        q.push(t1->left);
>        q.push(t2->right);
>        q.push(t1->right);
>        q.push(t2->left);
>    }
>
>    return true;
>}
>```
>
>---
>
>###- 這題的關鍵是「交叉比較」：左子樹的左邊要對應右子樹的右邊，左子樹的右邊要對應右子樹的左邊。
>- 如果你已經會寫「Same Tree」，這題只是比較方式稍微不同。
>
>---


DFS:
```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isMirror(TreeNode* tn1, TreeNode* tn2){
        if(tn1 == NULL && tn2 == NULL) return true;
        if(tn1 == NULL || tn2 == NULL) return false;
        if(tn1 -> val != tn2 -> val)return false;
        return isMirror(tn1 -> left, tn2 -> right) && isMirror(tn1 -> right, tn2 -> left);
    }
    
    bool isSymmetric(TreeNode* root) {
        return isMirror(root -> left, root -> right);
    }
};
```

BFS:
```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root -> left);
        q.push(root -> right);

        while(!q.empty()){
            TreeNode* tn1 = q.front();
            q.pop();
            TreeNode* tn2 = q.front();
            q.pop();
            if(tn1 == NULL && tn2 == NULL) continue;
            if(tn1 == NULL || tn2 == NULL)return false;
            if(tn1 -> val != tn2 -> val) return false;
            q.push(tn1 -> left);
            q.push(tn2 -> right);
            q.push(tn1 -> right);
            q.push(tn2 -> left);
        }
        return true;
    }
};
```
