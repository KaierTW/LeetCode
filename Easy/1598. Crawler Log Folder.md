# 1598. Crawler Log Folder
Problem : [HERE](https://leetcode.com/problems/crawler-log-folder/description/)

>[!TIP]
>按照順序找，遇到"./"就繼續，遇到"../"就看是不是在根目錄

>[!IMPORTANT]
>strcmp如果相等會回傳0

```C
int minOperations(char** logs, int logsSize) {
    int ans = 0;
    for(int i = 0 ; i < logsSize ; i++){
        if(strcmp(logs[i] , "./") == 0) continue;
        else if(strcmp(logs[i] , "../") == 0) {
            if(ans == 0) continue;
            else ans--;
        }
        else ans++;
    }
    return ans;
}
```
