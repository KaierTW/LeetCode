# 3174. Clear Digits
Problem : [HERE](https://leetcode.com/problems/clear-digits/description/)

>### 題目要求
>從字串中移除所有數字，並且每次移除數字時，同時刪除其左邊最近的一個非數字字符。
>
>### 解題思路
>1. **初始化結果字串**：我們需要一個空的結果字串來存儲最終的結果。
>2. **遍歷輸入字串**：逐個字符地遍歷輸入字串。
>3. **判斷字符類型**：
>   - 如果字符是數字：
>     - 檢查結果字串是否為空。如果不為空，則刪除結果字串中的最後一個字符（即最近的非數字字符）。
>   - 如果字符不是數字：
>     - 將該字符添加到結果字串中。
>4. **返回結果字串**：遍歷完成後，結果字串即為所需的答案。
>
>### 解釋
>1. **初始化結果字串**：`std::string result;` 初始化一個空的結果字串。
>2. **遍歷輸入字串**：`for (char c : s)` 使用範圍循環遍歷輸入字串 `s` 中的每個字符。
>3. **判斷字符類型**：
>   - `if (isdigit(c))` 判斷當前字符是否為數字。
>   - `if (!result.empty()) result.pop_back();` 如果結果字串不為空，則刪除結果字串中的最後一個字符。
>   - `else result.push_back(c);` 如果當前字符不是數字，則將其添加到結果字串中。
>4. **返回結果字串**：遍歷完成後，返回結果字串 `result`。
>


```CPP
class Solution {
public:
    string clearDigits(string s) {
        string stack;
        for(char c : s){
            if(isdigit(c)){
                if(!stack.empty()) stack.pop_back();
            }
            else{
                stack.push_back(c);
            }
        }
        return stack;
    }
};
```
