# 383. Ransom Note
Problem : [HERE](https://leetcode.com/problems/ransom-note/description/)

>[!TIP]
>
>1. **字母計數**：首先，我們需要計算`magazine`中每個字母的出現次數。這可以使用哈希表或字典來完成。
>2. **字母匹配**：接著，遍歷`ransomNote`中的每個字母，檢查在`magazine`中是否有足夠的該字母。如果某個字母在`magazine`中的數量不足，則返回`false`。
>3. **更新計數**：每次匹配成功後，減少`magazine`中該字母的計數。
>
>這樣，我們可以確保`ransomNote`中的所有字母都能在`magazine`中找到並且數量足夠


```CPP
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        unordered_map<char, int> charTimes;
        for(char c : magazine){
            charTimes[c]++;
        }
        for(char c : ransomNote){
            if(charTimes.find(c) != charTimes.end()){
                int appearTimes = charTimes[c];
                if(appearTimes == 0) return false;
                else charTimes[c] = --appearTimes;
            }
            else return false;
        }
        return true;
    }
};
```
