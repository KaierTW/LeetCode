# 2206. Divide Array Into Equal Pairs
Problem : [HERE](https://leetcode.com/problems/divide-array-into-equal-pairs/description/)

>[!TIP]
>當然可以！這題目要求我們將一個整數數組分成若干對，使得每對中的兩個元素相等。具體來說，給定一個包含 \(2 \times n\) 個整數的數組，我們需要將它分成 \(n\) 對，使得每對中的兩個元素相等。如果可以做到，返回 `true`，否則返回 `false`。
>
>解題思路如下：
>
>1. **計數每個元素的出現次數**：我們可以使用一個哈希表（或字典）來計數數組中每個元素的出現次數。
>2. **檢查每個元素的出現次數是否為偶數**：因為我們需要將每個元素配對，所以每個元素的出現次數必須是偶數。如果所有元素的出現次數都是偶數，則可以將數組分成所需的對數，否則不能。
>
>以下是這個思路的實現代碼（以 C++ 為例）：
>
>```cpp
>#include <vector>
>#include <unordered_map>
>
>bool divideArray(std::vector<int>& nums) {
>    std::unordered_map<int, int> count;
>    for (int num : nums) {
>        count[num]++;
>    }
>    for (const auto& pair : count) {
>        if (pair.second % 2 != 0) {
>            return false;
>        }
>    }
>    return true;
>}
>```
>
>在這段代碼中，我們首先遍歷數組 `nums`，並使用哈希表 `count` 記錄每個元素的出現次數。然後，我們檢查哈希表中的每個元素，如果有任何一個元素的出現次數不是偶數，則返回 `false`；否則返回 `true`[1](https://leetcode.com/problems/divide-array-into-equal-pairs/)[2](https://algo.monster/liteproblems/2206)。
>
>希望這個解題思路對你有幫助！如果還有其他問題，隨時告訴我。

```CPP
class Solution {
public:
    bool divideArray(vector<int>& nums) {
        vector<int> count(501, 0);
        for(int num : nums){
            count[num]++;
        }
        for(int c : count){
            if(c % 2 != 0) return false;
        }
        return true;
    }
};
```
