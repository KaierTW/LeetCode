# 1790. Check if One String Swap Can Make Strings Equal
Problem : [HERE](https://leetcode.com/problems/check-if-one-string-swap-can-make-strings-equal/description/)

>[!TIP]
>這題目要求我們檢查兩個等長的字符串是否可以通過在其中一個字符串上進行最多一次字符交換來使它們相等。以下是解題思路：
>
>1. **檢查字符串長度**：首先確認兩個字符串的長度是否相等，如果不相等，直接返回 `false`。
>2. **找出不同字符的位置**：遍歷兩個字符串，找出所有不同字符的位置。如果不同字符的位置數量不是 0 或 2，則返回 `false`。
>3. **檢查可交換性**：如果有兩個不同字符的位置，檢查這兩個位置的字符是否可以交換使兩個字符串相等。

```CPP
class Solution {
public:
    bool areAlmostEqual(string s1, string s2) {
        int lens1 = s1.size();
        int lens2 = s2.size();
        vector<pair<char, char>> diff;
        if(lens1 != lens2) return false;
        for(int i = 0 ; i < lens1 ; i++){
            if(s1[i] != s2[i]) {
                diff.push_back(make_pair(s1[i], s2[i]));
            }
        }
        if(diff.size() == 0) return true;
        if(diff.size() != 2) return false;
        return ((diff[0].first == diff[1].second) && (diff[0].second == diff[1].first));
    }
};
```
