# 3477. Fruits Into Baskets II
Problem : [HERE](https://leetcode.com/problems/fruits-into-baskets-ii/description/)

>[!TIP]
>這題是經典的**貪心分配問題**，規則雖然簡單，但有點「模擬題」的味道，我們可以用直覺的方式高效解。
>
>---
>
>## ✅ 題目重點
>
>你有兩個陣列：
>
>* `fruits[i]`: 第 `i` 種水果的數量
>* `baskets[j]`: 第 `j` 個籃子的容量（每個籃子只能放一種水果）
>
>---
>
>### 🔁 配置規則（**從左到右**）：
>
>1. 對每個水果 `fruits[i]`，從左到右掃 `baskets[j]`：
>
>   * 找**第一個尚未使用過**且 `baskets[j] >= fruits[i]` 的籃子
>2. 如果找不到這樣的籃子，那這個水果 **無法放置**
>3. 籃子一旦被用過，就不能再用
>
>---
>
>## 🎯 目標
>
> 回傳最後有幾種水果**沒被放進任何籃子**
>
>---
>
>## ✅ 解法思路：模擬 + 使用狀態記錄
>
>### 🧠 思維：
>
>* 因為條件是「從左到右」，不能先排序或用 binary search
>* 所以只能按順序處理水果，對每個水果找第一個「夠大且未使用」的籃子
>
>---
>
>## ✅ 時間複雜度
>
>* 最壞情況每個水果都掃一次籃子 → **O(n²)**，但對 `n ≤ 10⁴` 還可以接受（也可用 BIT 優化）
>
>---
>
>## ✅ C++ 實作（簡單明瞭）
>
>```cpp
>int unplacedFruits(vector<int>& fruits, vector<int>& baskets) {
>    int n = fruits.size();
>    vector<bool> used(n, false);  // 標記籃子是否已被用過
>    int unplaced = 0;
>
>    for (int i = 0; i < n; ++i) {
>        bool placed = false;
>        for (int j = 0; j < n; ++j) {
>            if (!used[j] && baskets[j] >= fruits[i]) {
>                used[j] = true;  // 用掉這個籃子
>                placed = true;
>                break;
>            }
>        }
>        if (!placed) unplaced++;
>    }
>
>    return unplaced;
>}
>```
>
>---
>
>## 🧪 範例解析
>
>### Input:
>
>```cpp
>fruits = [4,2,5]
>baskets = [3,5,4]
>```
>
>* `fruits[0] = 4` → 放進 `baskets[1] = 5`
>* `fruits[1] = 2` → 放進 `baskets[0] = 3`
>* `fruits[2] = 5` → `baskets[2] = 4` 不夠，沒籃子可放 → ❌
>
>✅ 回傳：`1`
>
>---
>
>## ✅ 進階優化（如果 `n` 很大）
>
>如果你希望最佳化到 `O(n log n)`：
>
>* 用 multiset 來記錄還沒使用的籃子
>* 但這不適用於本題，因為題目強調 **從左到右** 的順序匹配，排序會破壞這一點
>
>---
>
>## 🧩 想延伸優化（可討論）
>
>如果放寬限制（例如可以任意選籃子、或者放多種水果），就可以用：
>
>* 二分搜尋
>* Multiset or TreeMap
>* Matching 演算法
>
>但這題屬於**模擬型**，按題目順序走就好～
>
>---




```CPP
class Solution {
public:
    int numOfUnplacedFruits(vector<int>& fruits, vector<int>& baskets) {                
        int ans = 0;
        for(int i = 0 ; i < fruits.size() ; i++){
            bool sufficient = false;
            for(int j = 0 ; j < baskets.size() ; j++){
                cout << "Fruit: " << fruits[i] << " Baskets: " << baskets[j] << endl;
                if(fruits[i] <= baskets[j]){
                    baskets.erase(baskets.begin() + j);
                    sufficient = true;
                    break;                    
                }                
            }
            if(!sufficient) ans++;            
        }
        return ans;
    }
};
```
