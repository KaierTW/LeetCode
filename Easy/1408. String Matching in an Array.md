# 1408. String Matching in an Array
Problem : [HERE](https://leetcode.com/problems/string-matching-in-an-array/description/)

>[!TIP]
>先把words從最長的排到最短的，然後依次找包含的字串，加入答案之前先檢查是否存在

```CPP
class Solution {
public:
    static bool stringSort(const string &a, const string &b){
        return a.size() > b.size();
    }
    vector<string> stringMatching(vector<string>& words) {
        vector<string> ans;
        sort(words.begin(), words.end(), stringSort);
        for(int i = 0 ; i < words.size() ; i++){
            printf("%s\n", words[i].c_str());
            for(int j = i + 1 ; j < words.size() ; j++){
                if(words[i].find(words[j]) != string::npos){
                    // not contain in ans
                    if(find(ans.begin(), ans.end(), words[j]) == ans.end()){
                        ans.push_back(words[j]);
                    }
                    
                }
            }
        }
        return ans;
    }
};
```
