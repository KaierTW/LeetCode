# 205. Isomorphic Strings
Problem : [HERE](https://leetcode.com/problems/isomorphic-strings/description/)

>[!TIP]
>205. Isomorphic Strings這題的解題思路是判斷兩個字符串是否是同構的。具體步驟如下：
>
>1. **建立映射**：我們需要為每個字符串建立一個字符到字符的映射。可以使用兩個哈希表來分別記錄`string s`到`string t`的映射和`string t`到`string s`的映射。
>
>2. **遍歷字符串**：同時遍歷兩個字符串的每個字符，檢查以下條件：
>   - 如果字符在映射中已經存在，則檢查映射是否一致。如果不一致，則返回`false`。
>   - 如果字符在映射中不存在，則建立新的映射。
>
>3. **返回結果**：如果遍歷完所有字符後，所有映射都一致，則返回`true`，否則返回`false`。
>
>這個方法的時間複雜度是O(n)，其中n是字符串的長度


```CPP
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        unordered_map<char, char>uom_s_to_t;
        unordered_map<char, char>uom_t_to_s;
        for(int i = 0 ; i < s.size() ; i++){
            char cs = s[i];
            char ct = t[i];
            if(uom_s_to_t.find(cs) != uom_s_to_t.end() && uom_s_to_t[cs] != ct) return false;
            if(uom_t_to_s.find(ct) != uom_t_to_s.end() && uom_t_to_s[ct] != cs) return false;
            uom_s_to_t[cs] = ct;
            uom_t_to_s[ct] = cs;
        }
        return true;
    }
};
```
