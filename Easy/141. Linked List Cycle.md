# 141. Linked List Cycle
Problem : [HERE](https://leetcode.com/problems/linked-list-cycle/description/)

>[!TIP]
>LeetCode 第 141 題：「**Linked List Cycle**」的解題思路是判斷一個**單向鏈結串列（singly linked list）是否有環（cycle）**。
>
>---
>
>### 🧠 解題思路：使用「快慢指針」（Floyd’s Cycle Detection Algorithm）
>
>這是一種經典且高效的方法：
>
>1. **定義兩個指針**：
>   - `slow`：每次走一步
>   - `fast`：每次走兩步
>
>2. **同時移動兩個指針**：
>   - 如果 `fast` 或 `fast->next` 為 `null`，代表走到底了，**沒有環**。
>   - 如果 `slow` 和 `fast` 相遇了，代表有環。
>
>---
>
>### 📌 為什麼這方法有效？
>
>- 如果有環，`fast` 會比 `slow` 多走一步，最終一定會在環中追上 `slow`。
>- 如果沒有環，`fast` 會先走到 `null`，代表結束。
>
>---
>
>### 🧪 範例：
>
>假設鏈結串列是：
>
>```
>1 → 2 → 3 → 4 → 5
>         ↑     ↓
>         ← ← ←
>```
>
>這裡 `5` 指向 `3`，形成一個環。快慢指針最終會在環中相遇。
>
>---
>


```CPP
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode *fast = head;
        ListNode *slow = head;
        while(fast != NULL && fast -> next != NULL){
            fast = fast -> next -> next;
            slow = slow -> next;
            if(fast == slow) return true;
        }
        return false;
    }
};
```
