# 392. Is Subsequence
Problem : [HERE](https://leetcode.com/problems/is-subsequence/description)


```CPP
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int s_index = 0;
        for(int i = 0 ; i < t.size() ; i++){
            if(t[i] == s[s_index]) s_index++;
        }
        return (s_index == s.size()) ? true : false;
    }
};
```
