# 219. Contains Duplicate II
Problem : [HERE](https://leetcode.com/problems/contains-duplicate-ii/description/)

>[!TIP]
>題目219. Contains Duplicate II的解題思路如下：
>
>**題目描述**：
>給定一個整數數組`nums`和一個整數`k`，如果存在兩個不同的索引`i`和`j`使得`nums[i] == nums[j]`且`abs(i - j) <= k`，則返回`true`；否則返回`false`。
>
>**解題思路**：
>
>1. **使用哈希表**：
>   - 使用哈希表來存儲每個元素的最新索引。
>   - 當遍歷數組時，檢查當前元素是否已經存在於哈希表中。
>   - 如果存在，檢查其索引差是否小於或等於`k`。
>
>2. **迭代數組**：
>   - 遍歷數組`nums`，對每個元素進行以下操作：
>     - 如果當前元素已存在於哈希表中，且索引差小於或等於`k`，則返回`true`。
>     - 否則，更新哈希表中該元素的索引。
>
>3. **返回結果**：
>   - 如果遍歷完數組後未找到符合條件的元素對，則返回`false`。
>

```CPP
class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        unordered_map<int, vector<int>>uom;
        for(int i = 0 ; i < nums.size() ; i++){
            uom[nums[i]].push_back(i);
        }
        for(const auto& pair : uom){
            vector<int> temp = pair.second;
            for(int i = 0 ; i < temp.size() - 1 ; i++){
                if(temp[i + 1] - temp[i] <= k) return true;
            }
        }
        return false;
    }
};
```
