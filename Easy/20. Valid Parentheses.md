# 20. Valid Parentheses
Problem : [HERE](https://leetcode.com/problems/valid-parentheses/description/)

>[!TIP]
>LeetCode 第 20 題「Valid Parentheses」（有效的括號）是一道經典的 **堆疊（Stack）** 題目，主要考驗你對資料結構的理解。這題的解題思路如下：
>
>---
>
>### 🧩 題目描述
>
>給你一個只包含 `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'` 的字串，請判斷這個字串是否是**有效的括號組合**。
>
>有效的定義是：
>1. 每個開括號都有對應的閉括號。
>2. 括號的順序必須正確（例如 `"(]"` 是錯的）。
>
>---
>
>### 💡 解題思路：使用 Stack（堆疊）
>
>1. 建立一個空的堆疊 `stack`。
>2. 建立一個對應表 `mapping = {')': '(', ']': '[', '}': '{'}`。
>3. 遍歷字串中的每個字元：
>   - 如果是閉括號（例如 `')'`），檢查堆疊頂部是否是對應的開括號。
>     - 如果是，就把堆疊頂部移除（代表這對括號是有效的）。
>     - 如果不是，或堆疊是空的 → 無效。
>   - 如果是開括號，就把它推入堆疊。
>4. 最後檢查堆疊是否為空：
>   - 如果是空的 → 所有括號都配對成功 → 有效。
>   - 如果不是空的 → 有未配對的括號 → 無效。
>
>---
>
>### 🧠 時間與空間複雜度
>
>- **時間複雜度**： $$O(n)$$，每個字元只處理一次。
>- **空間複雜度**： $$O(n)$$，最壞情況下堆疊會存所有開括號。
>
>---

```C
bool isValid(char* s) {
    int len = strlen(s);
    if(len < 2) return false;
    char* stack = malloc(len * sizeof(char));
    int stackIndex = 0;
    for(int i = 0 ; i < len ; i++){
        if (s[i] == '('){
            stack[stackIndex++] = '(';
        }
        else if (s[i] == '['){
            stack[stackIndex++] = '[';
        }
        else if (s[i] == '{'){
            stack[stackIndex++] = '{';
        }
        else if (s[i]==')'){
            if(i == 0 || stackIndex == 0) return false;
            else if(stack[--stackIndex] == '(') continue;
            else return false;
        }
        else if (s[i]==']'){
            if(i == 0 || stackIndex == 0) return false;
            else if(stack[--stackIndex] == '[') continue;
            else return false;
        }
        else if (s[i]=='}'){
            if(i == 0 || stackIndex == 0) return false;
            else if(stack[--stackIndex] == '{') continue;
            else return false;
        }
    }
    if(stackIndex == 0) return true;
    else return false;
    
}
```

```CPP
class Solution {
public:
    bool isValid(string s) {
        stack<char> stk;
        for(char c : s){
            if(c == '(' || c == '[' || c == '{') stk.push(c);
            else{
                if(c == ')'){
                    if(!stk.empty() && stk.top() == '(') stk.pop();
                    else return false;
                }
                if(c == ']'){
                    if(!stk.empty() && stk.top() == '[') stk.pop();
                    else return false;
                }
                if(c == '}'){
                    if(!stk.empty() && stk.top() == '{') stk.pop();
                    else return false;
                }
            }
        }
        return (stk.empty() ? true : false);
    }
};
```
