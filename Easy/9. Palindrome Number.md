# 9. Palindrome Number
Problem : [HERE](https://leetcode.com/problems/palindrome-number/description/)

>[!TIP]
>暫存一個從後面算起來的，先*10再加餘數
>
```C
bool isPalindrome(int x) {
    long int temp = x;
    long int y = 0;
    if(x < 0) return false;
    else{        
        while(x > 0){
            y = y * 10 + x % 10;
            x /= 10;
        }
    }
    if(temp == y) return true;
    else return false;
}
```
