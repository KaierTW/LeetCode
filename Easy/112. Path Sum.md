# 112. Path Sum
Problem : [HERE](https://leetcode.com/problems/path-sum/description/)

>[!TIP]
>走到哪個節點就先把他加到sum，然後判斷他是不是最後的節點，如果是的話再比較有沒有和targetSum一樣，然後改答案。

```C
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */

int sum;
bool CheckSum(struct TreeNode* r, int sum, int target){
    if(r == NULL) return false;
    sum += r -> val;
    if(r -> left == NULL && r -> right == NULL && sum == target) return true;
    else return (CheckSum(r -> left, sum, target) || CheckSum(r -> right, sum, target));
}
bool hasPathSum(struct TreeNode* root, int targetSum) {
    return CheckSum(root, 0, targetSum);
}
```

```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void findSum(TreeNode * node , int sum , int targetSum , bool* ans){
        if(node == NULL) return;
        sum += node -> val;
        if (node -> left == NULL && node -> right == NULL){
            printf("Sum : %d\n" , sum);
            if(sum == targetSum) *ans = true;
        }
        else{            
            findSum(node -> left , sum , targetSum , ans);
            findSum(node -> right , sum , targetSum , ans);
        }                
    }
    
    bool hasPathSum(TreeNode* root, int targetSum) {        
        bool ans = false;
        findSum(root , 0 , targetSum , &ans);
        return ans;
    }
};
```

>[!TIP]
>LeetCode 第 112 題 **Path Sum** 是一道經典的二元樹題目，屬於 DFS（深度優先搜尋）類型。這題的目標是判斷是否存在一條從根節點到葉節點的路徑，使得路徑上的節點值總和等於給定的目標值 `targetSum`。
>
>---
>
>### 🧠 解題思路
>
>**題目描述：**
>給定一棵二元樹和一個整數 `targetSum`，判斷是否存在一條從根節點到葉節點的路徑，使得路徑上所有節點的值加總等於 `targetSum`。
>
>---
>
>### ✅ 解法一：DFS（遞迴）
>
>這是最直覺的解法，從根節點開始遞迴地往下走，每次減去當前節點的值，直到走到葉節點為止。
>
>```CPP
>class Solution {
>public:
>    bool hasPathSum(TreeNode* root, int targetSum) {
>        if (!root) return false;
>
>        // 如果是葉節點，檢查是否剛好等於 targetSum
>        if (!root->left && !root->right) {
>            return root->val == targetSum;
>        }
>
>        // 遞迴檢查左右子樹
>        return hasPathSum(root->left, targetSum - root->val) ||
>               hasPathSum(root->right, targetSum - root->val);
>    }
>};
>```
>
>---
>
>### ✅ 解法二：DFS（使用 Stack）
>
>如果你不想用遞迴，也可以用迭代方式實作 DFS。
>
>```CPP
>class Solution {
>public:
>    bool hasPathSum(TreeNode* root, int targetSum) {
>        if (!root) return false;
>
>        // 使用 stack 儲存節點與目前累積的總和
>        stack<pair<TreeNode*, int>> nodeStack;
>        nodeStack.push({root, root->val});
>
>        while (!nodeStack.empty()) {
>            auto [node, currSum] = nodeStack.top();
>            nodeStack.pop();
>
>            // 如果是葉節點且總和等於 targetSum，回傳 true
>            if (!node->left && !node->right && currSum == targetSum) {
>                return true;
>            }
>
>            // 將右子節點加入 stack
>            if (node->right) {
>                nodeStack.push({node->right, currSum + node->right->val});
>            }
>
>            // 將左子節點加入 stack
>            if (node->left) {
>                nodeStack.push({node->left, currSum + node->left->val});
>            }
>        }
>
>        return false;
>    }
>};
>
>```
>
>---
>
>### 🔍 關鍵點整理
>
>- **葉節點**：必須是沒有左右子節點的節點。
>- **DFS 遞迴**：每次呼叫都減去當前節點的值。
>- **終止條件**：走到葉節點且剩餘值剛好為 0。
