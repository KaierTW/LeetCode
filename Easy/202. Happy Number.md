# 202. Happy Number
Problem : [HERE](https://leetcode.com/problems/happy-number/description/)

>[!TIP]
>解題思路如下：
>
>1. **理解快樂數的定義**：
>   - 快樂數是指一個數字，通過反覆將其每個數字的平方和替換，最終能變為1。
>   - 如果進入一個不包含1的循環，則該數字不是快樂數。
>
>2. **使用集合來檢測循環**：
>   - 使用集合（`set`）來存儲每次計算得到的數字。如果某個數字已經存在於集合中，則表示進入了循環，該數字不是快樂數。
>
>3. **實現平方和計算**：
>   - 編寫一個輔助函數來計算一個數字的每個數字的平方和。
>
>4. **迭代計算**：
>   - 從初始數字開始，不斷計算其平方和，並檢查是否已經出現在集合中。
>   - 如果最終得到1，則該數字是快樂數；如果進入循環，則不是快樂數。

```CPP
class Solution {
public:
    int getNext(int n){
        int sum = 0;
        while(n > 0){
            int digit = n % 10;
            sum += digit * digit;
            n /= 10;
        }
        return sum;
    }
    
    bool isHappy(int n) {
        unordered_set<int> uos;
        while(n != 1 && uos.find(n) == uos.end()){
            uos.insert(n);
            n = getNext(n);
        }
        return n == 1;
    }
};
```
