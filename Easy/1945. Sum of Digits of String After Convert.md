# 1945. Sum of Digits of String After Convert
Problem : [HERE](https://leetcode.com/problems/sum-of-digits-of-string-after-convert/description/)

>[!TIP]
>先把題目的字串轉換成數字，然後再相加

```CPP
class Solution {
public:
    int getLucky(string s, int k) {
        string number;
        for(char c : s){
            number += to_string(c - 'a' + 1);
        }
        while(k > 0){
            int sum = 0;
            for(char c : number){
                sum += c - '0';
            }
            number = to_string(sum);
            k--;
        }
        return stoi(number);
    }
};
```
