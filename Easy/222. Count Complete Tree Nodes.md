# 222. Count Complete Tree Nodes
Problem : [HERE](https://leetcode.com/problems/count-complete-tree-nodes/description/)

>[!TIP]
>當然可以！這裡是 LeetCode 第 222 題 **Count Complete Tree Nodes** 的兩種 C++ 解法：**暴力解法** 和 **優化解法**，並附上解題思路。
>
>---
>
>## ✅ 解法一：暴力 DFS（時間複雜度 O(n)）
>
>### 思路：
>直接使用遞迴遍歷整棵樹，每遇到一個節點就加一。
>
>### C++ 程式碼：
>```cpp
>class Solution {
>public:
>    int countNodes(TreeNode* root) {
>        if (!root) return 0;
>        return 1 + countNodes(root->left) + countNodes(root->right);
>    }
>};
>```
>
>### 時間複雜度：
>- 每個節點都訪問一次 → **O(n)**
>- 空間複雜度（遞迴堆疊） → 最壞情況 **O(n)**，平均 **O(log n)**
>
>---
>
>## ✅ 解法二：利用完全二元樹特性（時間複雜度 O(log²n)）
>
>### 思路：
>1. 完全二元樹的左子樹和右子樹高度可以用 `getHeight()` 計算。
>2. 若左右高度相同，左子樹是滿的 → 節點數為 \(2^h - 1\)，加上右子樹遞迴。
>3. 若左右高度不同，右子樹是滿的 → 節點數為 \(2^h - 1\)，加上左子樹遞迴。
>
>### C++ 程式碼：
>```cpp
>class Solution {
>public:
>    int countNodes(TreeNode* root) {
>        if (!root) return 0;
>
>        int leftHeight = getHeight(root->left);
>        int rightHeight = getHeight(root->right);
>
>        if (leftHeight == rightHeight) {
>            // 左子樹是滿的
>            return (1 << leftHeight) + countNodes(root->right);
>        } else {
>            // 右子樹是滿的
>            return (1 << rightHeight) + countNodes(root->left);
>        }
>    }
>
>private:
>    int getHeight(TreeNode* node) {
>        int height = 0;
>        while (node) {
>            height++;
>            node = node->left;
>        }
>        return height;
>    }
>};
>```
>
>### 時間複雜度：
>- 每層計算高度 O(log n)，最多遞迴 log n 層 → **O(log² n)**
>- 空間複雜度 → **O(log n)**（遞迴堆疊）
>

>


```CPP
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void count(TreeNode* node, int &ans){
        if(node != NULL) {
            ans++;
            count(node -> left, ans);
            count(node -> right, ans);
        }
        else return;        
    }
    int countNodes(TreeNode* root) {
        int ans = 0;
        count(root, ans);
        return ans;
    }
};
```
