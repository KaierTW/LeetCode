# 228. Summary Ranges
Problem : [HERE](https://leetcode.com/problems/summary-ranges/description/)

>[!TIP]
>這道題目要求將一個已排序且不含重複元素的整數數組轉換為一個更緊湊的範圍列表。解題思路如下：
>
>1. **初始化變量**：創建一個空列表來存儲範圍字符串，並設置兩個指針 `i` 和 `j`，初始值都為 0。
>2. **遍歷數組**：使用 `i` 作為當前範圍的起點，`j` 用來找到範圍的終點。
>3. **擴展範圍**：當 `nums[j + 1]` 恰好比 `nums[j]` 大 1 時，將 `j` 向前移動，直到不再連續。
>4. **記錄範圍**：當找到一個完整的範圍後，根據 `i` 和 `j` 的位置生成範圍字符串，並將其添加到結果列表中。
>5. **更新指針**：將 `i` 設置為 `j + 1`，繼續尋找下一個範圍，直到遍歷完整個數組。
>
>具體步驟如下：
>
>1. 創建一個空列表 `ans` 來存儲範圍字符串，並初始化指針 `i` 和 `j` 為 0。
>2. 使用 `while` 循環遍歷數組，當 `i` 小於數組長度時：
>   - 設置 `j` 為 `i`。
>   - 當 `j + 1` 小於數組長度且 `nums[j + 1]` 恰好比 `nums[j]` 大 1 時，將 `j` 向前移動。
>   - 根據 `i` 和 `j` 的位置生成範圍字符串，並將其添加到 `ans` 中。
>   - 將 `i` 設置為 `j + 1`，繼續尋找下一個範圍。
>
>這樣的算法保證了線性時間複雜度 $$O(n)$$

```CPP
class Solution {
public:
    vector<string> summaryRanges(vector<int>& nums) {        
        vector<string> ans;
        int start = 0;
        for(int i = 0 ; i < nums.size() ; i++){            
            if(i != nums.size() - 1 && nums[i] + 1 == nums[i + 1]) continue;
            else{
                if(i == start) ans.push_back(to_string(nums[i]));
                else ans.push_back(to_string(nums[start]) + "->" + to_string(nums[i]));                    
                start = i + 1;                
            }
        }
        return ans;
    }
};
```
