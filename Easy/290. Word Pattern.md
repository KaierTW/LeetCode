# 290. Word Pattern
Problem : [HERE](https://leetcode.com/problems/word-pattern/description/)

>[!TIP]
>LeetCode 290題「Word Pattern」的解題思路主要是利用雙向映射來檢查給定的字串 `pattern` 是否與字串 `s` 遵循相同的模式。
>
>具體來說，每個 `pattern` 中的字元應唯一地對應到 `s` 中的單詞，並且這種對應應該是雙向的。解題的關鍵步驟如下：
>
>1. **分割字串**：使用 `stringstream` 將字串 `s` 按空格分割成單詞。
>2. **檢查長度**：如果 `pattern` 的長度與分割後的單詞數量不一致，則直接返回 `false`。
>3. **雙向映射**：使用兩個 `unordered_map`，一個記錄 `pattern` 到單詞的映射，另一個記錄單詞到 `pattern` 的映射。
>4. **遍歷檢查**：遍歷 `pattern` 和單詞，檢查每個字元和單詞的映射是否一致。如果不一致，則返回 `false`。
>
>這樣的解法可以有效地檢查 `pattern` 和 `s` 是否遵循相同的模式


```CPP
class Solution {
public:
    bool wordPattern(string pattern, string s) {
        unordered_map<char, string>uom_pat_to_s;
        unordered_map<string, char>uom_s_to_pat;
        istringstream iss(s);
        string word;
        vector<string>words;        
        while(iss >> word){
            words.push_back(word);
        }
        if(pattern.size() != words.size()) return false;
        
        for(int i = 0 ; i < pattern.size() ; i++){
            printf("%c : %s\n", pattern[i], words[i].c_str());
            if(uom_pat_to_s.find(pattern[i]) != uom_pat_to_s.end() && uom_pat_to_s[pattern[i]] != words[i]) return false;
            else uom_pat_to_s[pattern[i]] = words[i];
            if(uom_s_to_pat.find(words[i]) != uom_s_to_pat.end() && uom_s_to_pat[words[i]] != pattern[i]) return false;
            else uom_s_to_pat[words[i]] = pattern[i];
        }
        return true;
    }
};
```
