# 2290. Minimum Obstacle Removal to Reach Corner
Problem : [HERE](https://leetcode.com/problems/minimum-obstacle-removal-to-reach-corner/description/)

>[!TIP]
>
>這題 "2290. Minimum Obstacle Removal to Reach Corner" 是一道 LeetCode 的問題，目標是從左上角 (0,0) 到右下角 (m-1,n-1) 的過程中，找到移除最少障礙物的路徑。以下是題目的概要：
>
>---
>
>## 題目描述
>
>給定一個 `m x n` 的二維網格 `grid`，其中：
>- `grid[i][j] == 0` 表示該格是空的，可以自由通行。
>- `grid[i][j] == 1` 表示該格有障礙物，需要移除才能通行。
>
>你需要從左上角 `(0,0)` 移動到右下角 `(m-1,n-1)`，可以上下左右移動，返回最少需要移除的障礙物數量。
>
>---
>
>### 解法思路
>
>這題可以使用 **優先隊列（Priority Queue）** 或 **0-1 BFS** 來解決。
>
>#### 為什麼選擇 0-1 BFS？
>由於移動到障礙物的成本是 `1`，而移動到空格的成本是 `0`，這種情況非常適合用 0-1 BFS 來解決。
>
>#### 解題步驟
>1. 建立一個優先隊列（`deque`），用來處理當前的狀態（位置和已移除障礙物數量）。
>2. 建立一個二維陣列 `dist`，用來記錄從起點到每個位置的最小移除障礙物數。
>3. 從起點開始，進行廣度優先搜尋：
>   - 如果下一步是空格，將其加入隊列的「前端」。
>   - 如果下一步是障礙物，將其加入隊列的「後端」。
>4. 當抵達終點時，輸出對應的障礙物移除數量。
>
>### 時間與空間複雜度
>- **時間複雜度**: \(O(m \times n)\)，每個節點最多訪問一次。
>- **空間複雜度**: \(O(m \times n)\)，用於存儲 `dist` 和隊列。

>[!TIP]
>### 0-1 BFS 的概念
>
>**0-1 BFS** 是一種處理 **邊權值只有 0 和 1** 的圖的優化版廣度優先搜索（BFS）。  
>傳統 BFS 使用普通的隊列，而 0-1 BFS 使用雙端隊列（`deque`），以此來高效處理邊權值不同的情況：
>
>- 如果當前移動的邊權值是 `0`，意味著這是一個「廉價」的移動，這個節點應該放入隊列的**前端**，以便優先處理。
>- 如果當前移動的邊權值是 `1`，意味著這是一個「昂貴」的移動，這個節點應該放入隊列的**後端**，以便延後處理。
>
>這樣，訪問順序就保證了「移動成本小的節點」會優先被處理，類似於 Dijkstra 算法中的優先級隊列。
>
>---
>
>### 具體步驟
>1. 使用 `deque` 作為雙端隊列。
>2. 初始化所有節點的距離為無窮大（`INT_MAX`），起點的距離設為 0。
>3. 每次處理一個節點，根據鄰邊的權值（障礙與否），決定將鄰接節點加入到 `deque` 的前端或後端。
>4. 當隊列清空時，距離陣列中記錄的即為從起點到所有點的最小障礙物移除數。
>
>---
>
>### 關鍵點解釋
>
>1. **雙端隊列 (`deque`)**
>   - 這裡的 `deque` 允許從前端插入「成本低」的節點，確保它們優先被處理。
>   - 障礙物節點因為成本較高，放入後端，延遲處理。
>
>2. **距離更新條件**
>   - 當新的距離 `new_dist` 小於已知的 `dist[nx][ny]` 時，更新距離並將該點加入隊列。
>
>3. **時間複雜度**
>   - 每個節點最多進隊一次，每條邊最多處理一次，因此時間複雜度為 \(O(m \times n)\)。
>
>4. **空間複雜度**
>   - 使用了額外的 `dist` 和 `deque`，空間複雜度也是 \(O(m \times n)\)。

>[!TIP]
>當我們用 **0-1 BFS** 解這類問題時，**最短距離陣列（`dist`）** 和 **雙端隊列（`deque`）** 是實現的核心部分。下面詳細解釋它們的作用：
>
>---
>
>### **1. 最短距離陣列（`dist`）的用途**
>**目的：記錄從起點到每個節點的最小移除障礙數量（或最小代價）。**
>
>在 0-1 BFS 的過程中，我們需要知道到達某個點的最優解（最小障礙數）。為了避免重複處理已經有更優解的節點，需要一個數據結構來記錄每個節點的「最短距離」，這就是 `dist`。
>
>#### 為什麼需要 `dist`？
>1. **避免重複計算：**  
>   假如某個節點 `(x, y)` 已經用代價 `2` 到達過，並且現在嘗試用代價 `3` 再次到達，那麼就沒必要處理這個更差的情況。
>   
>2. **確認更優路徑：**  
>   如果發現新的路徑可以以更低的代價到達某點，就更新 `dist`，並重新安排這個節點的處理順序。
>
>#### 怎麼使用 `dist`？
>- 初始化：所有節點的 `dist` 初始值設為無窮大（`INT_MAX`），代表還沒有到達。
>- 更新：當找到更小的代價到達某點時，更新 `dist`。
>- 判斷：每次處理某點前，先檢查新的代價是否小於 `dist` 的值，避免不必要的操作。
>
>---
>
>### **2. 雙端隊列（`deque`）的用途**
>**目的：實現按「代價」處理節點，保證低代價的節點優先。**
>
>#### 為什麼用雙端隊列？
>- 在 0-1 BFS 中，我們的移動邊有兩種代價：
>  - **邊權值為 0（空格）：** 無需移除障礙，代價低，應優先處理。
>  - **邊權值為 1（障礙）：** 需要移除障礙，代價高，應延後處理。
>- 雙端隊列允許我們將低代價的節點加入隊列前端（高優先級處理），而將高代價的節點加入隊列後端（低優先級處理）。
>
>#### 怎麼使用 `deque`？
>- **空格（`grid[nx][ny] == 0`）:**  
>  當移動到空格時，將該點加入隊列的前端（`push_front`），因為它是「廉價」的移動。
>  
>- **障礙（`grid[nx][ny] == 1`）:**  
>  當移動到障礙物時，將該點加入隊列的後端（`push_back`），因為它是「昂貴」的移動。
>
>這樣保證了低代價的節點會更早被處理，類似於 Dijkstra 算法中使用優先級隊列的效果，但這裡因為邊權只有兩種，雙端隊列更高效。
>
>---
>
>### **配合使用的流程**
>
>1. **`dist` 保證「每個節點只更新更優的解」：**
>   - 我們在處理某個節點時，如果發現這次的代價不如以前計算的代價小，那麼不需要更新或重新處理。
>
>2. **`deque` 保證「低代價的節點先被處理」：**
>   - 雙端隊列會將廉價的邊優先處理，確保在探索過程中，最優解總是會先浮現。
>
>---
>
>### 直觀理解
>
>你可以把 **最短距離陣列（`dist`）** 想像成是我們探索的「記錄本」，隨時記錄已經找到的最小代價。  
>而 **雙端隊列（`deque`）** 就像是一個「優先處理的任務列表」，保證代價低的路徑會優先被嘗試。
>
>---
>
>如果用「排隊買票」來類比：
>- **`dist` 是每個人手上的票價記錄表：** 每個人知道自己的票應該花多少錢，總是保留最便宜的選項。
>- **`deque` 是排隊的隊伍：** 如果有快速通道（免費票），他們可以插隊到最前面，而普通票則乖乖排到後面。
>

```CPP
class Solution {
public:
    int minimumObstacles(vector<vector<int>>& grid) {        
        //二維陣列，先row再column
        int row = grid.size(), column = grid[0].size();

        //定義方向，上下左右
        vector<pair<int, int>> direction={{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        //最短距離陣列
        vector<vector<int>> dist(row, vector<int>(column, INT_MAX));

        //雙端隊列
        deque<pair<int, int>> dq;

        //起點距離
        dist[0][0] = 0;
        //起點加入deque
        dq.push_front({0, 0});

        //開始走
        while(!dq.empty()){
            //當下位置
            auto [x, y] = dq.front();
            //移除當下位置
            dq.pop_front();

            //往不同方向移動
            for(auto [dx, dy] : direction){
                //移動過後的位置
                int nx = x + dx , ny = y + dy;

                //確保沒有超過邊界
                if(nx >= 0 && nx < row && ny >= 0 && ny < column){
                    //計算新的距離
                    int newDist = dist[x][y] + grid[nx][ny];

                    //找到更短距離
                    if(newDist < dist[nx][ny]){
                        dist[nx][ny] = newDist;
                        if(grid[nx][ny] == 0) dq.push_front({nx, ny});
                        else dq.push_back({nx,ny});
                    }
                }
            }
        }
        return dist[row - 1][column - 1];
    }
};
```
