# 2290. Minimum Obstacle Removal to Reach Corner
Problem : [HERE](https://leetcode.com/problems/minimum-obstacle-removal-to-reach-corner/description/)

>[!TIP]
>
>這題 "2290. Minimum Obstacle Removal to Reach Corner" 是一道 LeetCode 的問題，目標是從左上角 (0,0) 到右下角 (m-1,n-1) 的過程中，找到移除最少障礙物的路徑。以下是題目的概要：
>
>---
>
>## 題目描述
>
>給定一個 `m x n` 的二維網格 `grid`，其中：
>- `grid[i][j] == 0` 表示該格是空的，可以自由通行。
>- `grid[i][j] == 1` 表示該格有障礙物，需要移除才能通行。
>
>你需要從左上角 `(0,0)` 移動到右下角 `(m-1,n-1)`，可以上下左右移動，返回最少需要移除的障礙物數量。
>
>---
>
>### 解法思路
>
>這題可以使用 **優先隊列（Priority Queue）** 或 **0-1 BFS** 來解決。
>
>#### 為什麼選擇 0-1 BFS？
>由於移動到障礙物的成本是 `1`，而移動到空格的成本是 `0`，這種情況非常適合用 0-1 BFS 來解決。
>
>#### 解題步驟
>1. 建立一個優先隊列（`deque`），用來處理當前的狀態（位置和已移除障礙物數量）。
>2. 建立一個二維陣列 `dist`，用來記錄從起點到每個位置的最小移除障礙物數。
>3. 從起點開始，進行廣度優先搜尋：
>   - 如果下一步是空格，將其加入隊列的「前端」。
>   - 如果下一步是障礙物，將其加入隊列的「後端」。
>4. 當抵達終點時，輸出對應的障礙物移除數量。
>
>### 時間與空間複雜度
>- **時間複雜度**: \(O(m \times n)\)，每個節點最多訪問一次。
>- **空間複雜度**: \(O(m \times n)\)，用於存儲 `dist` 和隊列。

```CPP
class Solution {
public:
    int minimumObstacles(vector<vector<int>>& grid) {        
        //二維陣列，先row再column
        int row = grid.size(), column = grid[0].size();

        //定義方向，上下左右
        vector<pair<int, int>> direction={{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        //最短距離陣列
        vector<vector<int>> dist(row, vector<int>(column, INT_MAX));

        //雙端隊列
        deque<pair<int, int>> dq;

        //起點距離
        dist[0][0] = 0;
        //起點加入deque
        dq.push_front({0, 0});

        //開始走
        while(!dq.empty()){
            //當下位置
            auto [x, y] = dq.front();
            //移除當下位置
            dq.pop_front();

            //往不同方向移動
            for(auto [dx, dy] : direction){
                //移動過後的位置
                int nx = x + dx , ny = y + dy;

                //確保沒有超過邊界
                if(nx >= 0 && nx < row && ny >= 0 && ny < column){
                    //計算新的距離
                    int newDist = dist[x][y] + grid[nx][ny];

                    //找到更短距離
                    if(newDist < dist[nx][ny]){
                        dist[nx][ny] = newDist;
                        if(grid[nx][ny] == 0) dq.push_front({nx, ny});
                        else dq.push_back({nx,ny});
                    }
                }
            }
        }
        return dist[row - 1][column - 1];
    }
};
```
